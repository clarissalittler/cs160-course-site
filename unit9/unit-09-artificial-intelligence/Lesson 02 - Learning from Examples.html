Lesson 2 - Learning from Examples

At the end of this lesson, you will be able to:

  • Explain how machine learning flips the usual approach to programming — from writing rules to showing examples
  • Describe what "training data" is and why labeled examples matter
  • Tell the difference between supervised, unsupervised, and reinforcement learning in plain language
  • Explain, in everyday terms, what "finding the pattern" actually means inside the machine

The big flip

In the Python units, we wrote programs by spelling out the rules. If a balance is below zero, print a warning. If a value meets a threshold, take a specified action. The programmer decides each step, and the computer follows it.

That works beautifully for some things. Tax forms, for instance — the rules are written down, they're fussy but finite, and a human could (in principle) follow them too. You can spell those out.

Now consider a task that sounds easier: write rules that distinguish a cat photo from a dog photo.

A rule such as "a dog has pointy ears" immediately encounters dogs with floppy ears and cats with pointy ones. Size, fur color, whiskers, and tail shape all produce similar exceptions under different poses and lighting. The categories are recognizable, but they are difficult to capture as a complete list of explicit rules.

Sorting spam from legitimate email and flagging fraudulent transactions pose the same problem. Their patterns cannot be handed to a computer as a tidy set of if statements.

So we stop writing rules

The central idea of machine learning is to learn a rule from examples rather than write that rule directly. We might supply cat photos labeled "cat" and dog photos labeled "dog," then train the computer to distinguish patterns associated with each label.

Those examples are the training data. Their quantity, quality, coverage, and labels all affect what the computer can learn. The programmer still chooses the data, model, objective, and training process, but does not specify every decision rule.

There is a loose analogy to the way a child learns the word "dog": repeated examples can support recognition even when a precise verbal definition is difficult. Machine learning is not the same as human learning, but both illustrate the value of examples.

Three common forms of learning

One way to distinguish machine-learning methods is to ask what kind of feedback accompanies the examples.

  • Supervised learning uses an answer key. Examples are paired with target labels—such as "cat," "spam," or "fraud"—and the model learns to predict those targets.
  • Unsupervised learning has no supplied answer key. The model looks for structure in the data, perhaps by grouping similar purchase histories without being told in advance what the groups should be.

Reinforcement learning uses feedback in the form of rewards: an agent takes actions, observes their consequences, and adjusts its behavior. We will return to this idea when discussing how some chatbots are tuned.

But what does "find the pattern" actually mean?

The phrase can sound mysterious, but we can make one common version of it concrete.

A model contains adjustable numbers called parameters. Those parameters help determine its predictions. During training, an algorithm repeatedly adjusts them so that the model's predictions better match the examples. The process may be large and complicated, but the basic operation is numerical.

We will begin with a version small enough to inspect directly: fitting a straight line through a scatter of points.

Try it: Think of a task that people perform readily but would find difficult to express as complete step-by-step rules—for example, recognizing a familiar voice. Write down one task and identify what examples a learning system might need.
