Lesson 6 - Backpropagation: Assigning the Blame

At the end of this lesson, you will be able to:

  • Explain the problem backpropagation solves: efficiently calculating how the loss changes with each parameter.
  • Describe backpropagation as passing the "blame" for a mistake backward through the layers.
  • Connect backpropagation, which computes gradients, to gradient descent, which uses them to update parameters.

One piece remains. We have a network with many parameters, and gradient descent tells us to update them in a direction that lowers the loss. The practical question is how to calculate an appropriate direction for each of millions of parameters.

Why checking each parameter is impractical

One approach would change a parameter, measure whether the loss increased or decreased, restore it, and then move to the next parameter. Repeating those measurements across a very large model for every training step would be impractical. Backpropagation, often shortened to backprop, instead computes the relevant gradients efficiently in a backward pass.

The kitchen at the end of a bad night

Here is an analogy. A restaurant sends out a dish that is too salty. The head chef traces the problem backward through the preparation process: the sauce contained too much salt, and the stock feeding that sauce may also have contributed. Each stage receives a correction related to its contribution.

Backpropagation performs a mathematical version of that tracing process. It starts at the output, where the loss is measured, and uses the chain rule to carry information backward through the layers. The result tells us how a small change in each parameter would affect the loss. One backward pass can calculate these gradients for all the parameters much more efficiently than testing them separately.

The whole machine, in one breath

Across many neural-network training systems, the core loop has the following form:

  1. Guess. Run an example through the network and see what comes out.
  2. Measure the miss. Compare the output to the right answer - that's the wrongness.
  3. Blame the knobs (backprop). Ripple that miss backward to find which way each knob should move.
  4. Nudge (gradient descent). Take one small step downhill on every knob.
  5. Repeat. A few million times.

This loop is central, but the architecture, data, loss function, and many other training choices also shape the resulting model. When a report says that a model was trained for an extended period, this cycle of prediction, measurement, gradient calculation, and update is part of what occurred.
