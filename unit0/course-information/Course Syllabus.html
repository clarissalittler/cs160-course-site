Course Description

This class introduces students to the breadth of computer science and concepts of programming. Explores concepts including the importance and impact of computing and technology, computability, computational complexity, algorithm analysis and design, abstraction, data and information, the Internet, programming concepts, application development, computational thinking, and the global impact of computing.

We will explore programming concepts using the Python Programming Language. Python is designed to be easy to understand and fun to use. Python reads like English, which takes a lot of syntax-learning stress off coding beginners. 

Intended Outcomes for the Course

On completion of this course the student should be able to:

  • IO 1:  Create computer programs to implement algorithms that solve problems.
  • IO 2:  Assess the computational complexity and computability of algorithms and their implementations.
  • IO 3:  Demonstrate a computing culture that is collaborative and ethical.
  • IO 4:  Evaluate computing innovations, computing systems, and career opportunities in computer science and other related disciplines.
  • IO 5:  Analyze questions or problems that impact the community and/or environment using quantitative information.

For more information, please go to the Course Content and Outcome Guide for this course.

Course Topics

Course Topics
Unit Description Learning Outcomes
1 Digital Information Explore computer hardware basics. Explore how computers store complex information like numbers, text, images and sound as binary data. Talk about the impacts of digitizing information.
  1. Describe how computers represent information. (IO 4)
  2. Represent numbers using the binary number system. (IO 4)
  3. Explain how bits can be arranged to represent text and digital images. (IO 2)
  4. Determine if lossless or lossy compression should be used for a given situation. (IO 2)
  5. Explain how copyright and Creative Commons Licenses can be applied to digital works of creativity. (IO 3)
2 The Internet Explore how the Internet works and discuss its impacts on politics, culture, and the economy.
  1. Describe the problems the internet was designed to solve and how it solves these problems. (IO 4)
  2. Explain how the design of the internet allowed it to grow or evolve. (IO 4)
  3. Explain how different protocol layers are involved in an internet request. (IO 2)
  4. Discuss how we might resolve dilemmas caused by the structure and continuing growth of the internet. (IO 3)
3 Intro to Python Programming Introduce programming concepts, including variables, input and output, using the Python programming language. Explore algorithm development and parallel computing concepts.
  1. Develop an algorithm to solve a problem. (IO 1)
  2. Create a Python program using input, output, and computational processes. (IO 1, 2)
  3. Explain how variables are used to store information. (IO 1)
  4. Use the Software Development Life Cycle to design, code, and test a program. (IO 1, 2, 4)
  5. Use pair programming to develop a program. (IO 3)
4 Selection Explore relational operators and Boolean expressions and learn how to alter the flow of a program with selection structures.
  1. Learn how to alter the flow of programs using the selection structure. (IO 1)
  2. Create conditional expressions resulting in boolean results (true or false). (IO 1, 2)
  3. Use pair programming to develop a program. (IO 3)
  4. Explain how logic gates direct the flow of information. (IO 4)
  5. Use logical operators to build complex boolean expressions. (IO 1)
5 Iteration Learn how to use loops to create iteration structures. Logic gates, logical operators, counters, accumulators, and input validation loops are also introduced.
  1. Use while and for loops to perform repetition (iteration). (IO 1)
  2. Use loops to perform input validation. (IO 1)
  3. Use pair programming to develop a program. (IO 3)
6 Arrays Learn how to define and use an array data structure called a list. Perform operations on lists including inserting and removing objects from a list, iterating over a list, and searching for items in a list.
  1. Create simple lists in Python. (IO 1)
  2. Access and process data in lists using loops. (IO 1, 2)
  3. Understand how to pass a list to a function. (IO 1)
  4. Use parallel lists to hold related information of different types. (IO 1)
  5. Use pair programming to develop a program. (IO 3)
7 Algorithms and Algorithm Efficiency Learn how to write and analyze algorithms by discussing the characteristics of a good algorithm. Part of learning computer science is learning to think in terms of these algorithms - to recognize common patterns that can be solved with known algorithms and how to express new ones. You will be comparing several sorting algorithms to illustrate algorithm efficiency and algorithm analysis. 
  1. Write simple algorithms. (IO 1)
  2. Define Algorithm Requirements. (IO 1)
  3. Understand and Analyze simple searching and sorting algorithms. (IO 1, 2)
  4. Describe and evaluate Algorithm Efficiency - how quickly can the computer calculate my solution? (IO 1, 2)
  5. Quantify the efficiency of the different algorithms using Big-O classification. (IO 2)
8 Data Explore and visualize datasets from a wide variety of topics as you hunt for patterns, make predictions, and try to learn more about the world around you.
  1. Create bar charts, histograms, scatter plots, and crosstab charts using Python libraries. (IO 1, 5)
  2. Draw conclusions from data by using quantitative reasoning and reading charts. (IO 5)
  3. Explain the reasons that someone would create a bar chart, histogram, scatter plot, or crosstab chart in order to explore one or two columns of data. (IO 5)
  4. Explain why data needs to be cleaned. (IO 5)
9 Artificial Intelligence Explore fundamental concepts of AI and Machine learning. Examine issues of bias and the societal and ethical implications.
  1. Explain key terminology associated with the field of AI. (IO 4)
  2. Understand, at a high level, how machine learning works. (IO 4)
  3. Define the different Machine Learning algorithms and their applications. (IO 1, 3)
  4. Differentiate between Machine Learning and Deep Learning. (IO 1, 3)
  5. Identify the societal impacts of AI. (IO 4)
  6. Describe career opportunities in the AI field. (IO 4)
10 Cybersecurity and Global Impact Research and debate current events at the intersection of data, public policy, law, ethics, and social impact.
  1. Describe data that is used and collected by computing innovations. (IO 4)
  2. Explain risks to privacy from using modern technology. (IO 3, 4)
  3. Explain security risks and their impact on society. (IO 3, 4)
  4. Explain encryption. (IO 2, 4)
  5. Explain the benefits of multi-factor authentication. (IO 2, 4)

Instructional Approach

This course is arranged chronologically and employs a modular design. Each week, students should complete the discussions, assignment or lab, and quiz listed in that week's unit module. These modules are available by clicking "Content" on the course navigation bar.

Due dates for each week's discussions, assignment or lab, and quiz will be listed within the module itself. Activities within the modules may direct students to use many of the tools contained in Brightspace, including Assignments, Discussions, or Quizzes. These tools will be accessible from within the weekly content modules, as well as from the course navigation bar in the Coursework drop-down menu.

Weekly Structure

Each week you will complete a Unit module. The unit and learning activities are listed on the Weekly Announcement, Course Schedule, and Unit Overview pages.

At the beginning of each week, read the Unit Overview page and start on the lesson pages. Lesson pages contain videos, interactive activities, and discussion prompts (both individual and partner). After completing the lessons, you will have a Quiz, and either an Assignment or Lab, and a Unit Summary page to review. Do not skip the summary pages - they contain additional resources for the unit!

  • Assignments, Labs, Quizzes, Discussions, and the Midterm Exam will all be due on Sunday of each week.
  • Assignment resubmissions and late work will be due Friday before the Final Exam week.
  • Final Exam will be due on Wednesday of Final Exam week.

Release Conditions

There are several important release conditions you need to be aware of:

  • The course content will not open until you have received 100% on the Course Information Quiz
  • The Final Exam will not be available until you have completed the Post-Survey in Unit 11, AND scored at least a 1 on all four Assignments. You can resubmit Assignments until Friday before Final Exam week.

Pair Programming, Collaboration, and Group Work

You will be required to complete some work with your study group and submit it on a discussion forum for feedback. In the programming units, you will be developing programs with a partner. We will be using a practice in the industry called pair programming. Pair programming consists of two programmers working on the same program at the same time. Both partners will be able to see the same screen at the same time and one programmer will be the driver and the other will be the navigator. The programmer using the keyboard is the driver, while the navigator tells the driver what to do. It is expected the programmers swap roles every three to five minutes.

I also expect and encourage you to work with a study group on Labs assigned during each unit. Please follow these group guidelines:

  • When working on Labs, please discuss the problems as a group, but you must do your own work, on your own document, in your own words. 
  • If a group works on a Lab and you are unable to join, you may NOT ask to be sent the answers. You will need to complete it on your own.
  • For problems that ask “What will the program display?” it is critical for you to step through the code and “predict” the answer, before typing up the code and asking the computer to show you the answer - don’t let the computer do the thinking for you!
  • You may NOT collaborate on Assignments. All Assignments must be completed on your own.

Students will be required to form a study group and meet at an agreed-upon time, to complete course activities outside of our scheduled meeting times.

Graded Activities & Feedback

Assignments: 40%

There will be 4 programming Assignments to complete this term. All Assignments can be accessed from the Coursework drop-down menu on the navigation bar and in the Content Unit module to which they relate. You should plan to upload your solutions to the Assignment folder on or before the due date. Assignments will be graded using a 0-4 scale rubric. Submitted Assignments will be given feedback and an opportunity to make changes for full credit with no late penalty. All Assignments must be completed on your own. You must score at least a 1 on all Assignments to unlock the Final Exam. The purpose of these Assignments is to assess your command of the problem-solving, computational thinking, and programming skills introduced in the particular unit. Mastery of these skills is critical for building a solid foundation for success in the next course, CS161A/B. 

Labs: 40%

There will be 6 labs through this term. Labs include questions from the unit lessons. After submitting, you may change your answers based on feedback and resubmit one time for full credit. Lab solutions will be released after the due date and after your lab has been graded. You will check your answers for correctness. Labs will be graded with a 0-4 point rubric. The last lab will include a presentation on a computing innovation. The purpose of these labs is to give you an opportunity to practice with the material we have covered in a particular unit and learn how to self-assess your work. They will also provide practice for key concepts you will need to demonstrate mastery of in the programming Assignments. 

Discussions: 0%

There will be discussions within each unit. Some discussions you will complete on your own, others you will complete with your study group or a partner. You must first post to the discussion before you can view other posts.  The purpose of the discussions and peer reviews is to give you a forum for critically thinking about the topics within the unit, give feedback to peer work, and share your insights within a small group. 

Quizzes: 0%

There will be a quiz for each unit. They will consist of multiple-choice, short answers, and true or false questions from the unit lessons. Please complete the quiz before attempting the Lab within the same unit - you will be more prepared! Quizzes are not graded and you have unlimited opportunities to retake them. Quiz questions will continue to appear on subsequent quizzes to help you prepare for the midterm and final exams. You must score 100% on the Course Information quiz to gain access to the first content unit. The purpose of these quizzes is to assess your command of the material we have covered in a particular unit. 

Midterm and Final Exam: 10% each (20% total)

There will be a Midterm and Final exam. The Midterm will consist of 20 multiple-choice, short answer, and true or false questions from the weekly quizzes and you have 60 minutes and one attempt to complete the exam. The Final will consist of 30 multiple-choice, short answer, and true or false questions from the weekly quizzes and you have 90 minutes and one attempt to complete the exam. The purpose of these exams is to assess your command of the material we have covered in the course.

Grading Scale

This course uses a 4.0 grading scale because it:

  • Is mathematically accurate - Your score will tell you exactly how you are doing and how you can improve. With a 0-100 scale, 60% of the grade is weighted towards failure. With a 4.0 scale, each gradation is weighted more evenly.
  • Values knowledge - Your grade will reflect what you know and can do.
  • Uses a feedback loop - Your score will be based on a rubric, encouraging mistakes as necessary for learning. Using a feedback loop with the rubric, you will be expected to make the required changes to improve your understanding of the material. It is important to remember that I have high expectations, and I believe you can learn how to code. Feedback is meant to help improve your learning, not to criticize, so please assume positive intention when reading!
Grading Scale
Letter Grade 4.0 Score Level
A 3.4 - 4.0 Exceeds
B 2.8 - 3.3 Meets
C 2.0 - 2.7 Approaching
D 1.2 - 1.9 Not Yet
F 0.0 - 1.1 No Evidence
  • 0 (No evidence). This isn't a grade as much as a mark to indicate there is no basis for assigning a grade.
  • 1 (Not yet). The evidence shows insufficient learning to pass the course in most areas.
  • 2 (Approaching). The evidence shows learning is sufficient in many areas to pass the course, but some gaps remain.
  • 3 (Meets). The evidence shows learning is sufficient to pass the course in all areas.
  • 4 (Exceeds). The evidence shows learning in all areas is beyond what is required to pass the course.

Academic Integrity (rules about cheating, plagiarism, or sharing work)

Students are required to complete this course in accordance with the Student Rights and Responsibilities Handbook. Cheating includes any attempt to defraud, deceive, or mislead the instructor in arriving at an honest grade assessment, and may include copying answers from other students or using unauthorized notes during tests. Plagiarism is a particular form of cheating that involves presenting as one's own the ideas or work of another, and may include using other people's ideas without proper attribution and submitting another person's work as one's own. Dishonest activities such as cheating on exams and submitting or copying work done by others will result in disciplinary actions including but not limited to receiving a failing grade. For further information, review the institution's Academic Integrity Policy.

As a reminder, learning to code can be difficult and frustrating and takes LOTS of practice. Our academic integrity policy for this course states that when completing programming assignments you may:

  • review course materials
  • look things up in the Python documentation
  • google specific questions online, such as "syntax for Python while loops"
  • use the sample program as a starting idea only - you must start with a blank algorithmic design planning document and Python file

You may NOT, under any circumstances, begin a programming assignment by:

  • looking for completed code which you can then modify
  • starting with a copy of the actual sample program and modify
  • asking a more experienced friend or family member to outline a solution for you

For individual-designated problems or exercises copying, sharing, or using improper resources is a violation of course principles. 

For multi-person-designated problems or exercises, copying, sharing, or using improper resources outside of one's group is a violation of course principles.

I do encourage the discussion of ideas with other students in the course and with your study group. Collaboration in the form of pair programming is an effective learning practice. One person sharing an assignment or test solution with another would not be collaboration and is not permitted.

The only way to learn to code is to do it yourself. The assignments will be built from examples during the lectures, so ask for clarification during class if something seems confusing. If you start with code from another source and change the variable names or other content to make it look original, you will receive a zero on the assignment.

I may ask you to explain your assignment verbally. If you cannot satisfactorily explain what your code does, and answer questions about why you wrote it in a particular way, then you should also expect a zero.
