# Exam Drafts

These drafts implement the exam structure described in the course syllabus. Every question is copied from a weekly quiz bank so students can prepare by practicing the unit quizzes.

## Midterm Exam

- **Coverage:** Units 1–4
- **Length:** 20 questions
- **Time limit:** 60 minutes
- **Question mix:** 12 multiple-choice, 4 true/false, and 4 short-answer questions
- **Distribution:** 5 questions from each covered unit

## Final Exam

- **Coverage:** Units 1–10
- **Length:** 30 questions
- **Time limit:** 90 minutes
- **Question mix:** 18 multiple-choice, 6 true/false, and 6 short-answer questions
- **Distribution:** 8 questions from Units 1–4 and 22 questions from Units 5–10

The final is comprehensive but weighted toward material taught after the midterm. Units 5–8 receive four questions each because they contain the course's later Python, computation, and data foundations. Units 9–10 receive three questions each.

The student-facing drafts are in this directory. Instructor answer keys also record the source unit and original quiz-question number for every selected item; those files are excluded from Git by the repository's answer-key rule.
