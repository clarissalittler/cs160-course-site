Unit 7 Overview

In this unit you'll step back from writing programs to ask what computation actually is. You'll see that an algorithm is an idea separate from any one programming language - the same algorithm can be written many different ways - and that we can measure how efficiently an algorithm works, using Big-O, no matter what language it's in. You'll also get a taste of two of the deepest ideas in all of computer science: that some things can't be computed at all, and that a full-blown computer can emerge from almost nothing.

Learning objectives

At the end of this learning module, you will be able to:

  1. Define an algorithm and explain why it is separate from any one programming language.
  2. Recognize the same algorithm expressed in several different languages.
  3. Describe linear and binary search and measure an algorithm's efficiency using Big-O classification.
  4. Describe, in plain terms, the limits of computation and the idea of universal computation.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

  1. Complete Lessons 1 - 6 (LOs 1-4)
  2. Complete Quiz 7 (LOs 1-3)
  3. Complete and submit Week 7 Assignment (LOs 1-3)
  4. Complete and share the Week 7 Activity Discussion: Beat the Computer
