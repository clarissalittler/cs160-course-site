Unit 7 Summary

Wrap up

In this unit, we stepped back from writing programs to think about what computation is. An algorithm is an idea separate from any programming language; its efficiency can be measured independently of a particular implementation; and computation has both hard limits and remarkable reach.

Summary

  • An algorithm is a step-by-step method for solving a problem - and it is an idea separate from any programming language. The same algorithm can be written in Python, JavaScript, Lisp, or plain pseudocode, and it's still the same computation.
  • We can describe an algorithm's efficiency - how its work grows as the input gets bigger - without picking a language, using Big-O notation. Common growth classes are Constant O(1), Logarithmic O(log n), Linear O(n), and Quadratic O(n²).
  • Linear search is O(n) and binary search is O(log n): binary search is dramatically faster, but only works on a sorted list.
  • Some problems can't be solved by any algorithm at all - the halting problem is a real limit on computation itself.
  • And computation is so fundamental that a universal computer can emerge from three simple rules, as in Conway's Game of Life.
