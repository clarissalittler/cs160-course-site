# Archived eight-lesson Unit 2 sequence

These pages preserve the eight-lesson version of Unit 2 that was active through July 2026. They were archived when the unit was reorganized into five longer lessons with a clearer technical progression and social questions integrated throughout.

The archived sequence is:

1. What the Internet Is (and Isn't)
2. Designed to Survive: Packets and Redundancy
3. Addresses and Names
4. Layers, Protocols, and the Roads Not Taken
5. The Pull Toward the Center
6. When the Center Breaks
7. Who's On, Who's Not
8. Who Controls the Pipes

The pages remain usable from this directory; each includes a base URL so its styles and images resolve from the active Unit 2 asset folders. For the repository state immediately before this archive, see commit `538e086`.
