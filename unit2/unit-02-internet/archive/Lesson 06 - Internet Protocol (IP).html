How to play Battleship


You're going to play a slightly unhinged version of this game: instead of one opponent, you'll be running multiple games against multiple people at the same time. For this first part of the lesson, you can play with friends or family. Later, you'll develop a protocol with four students in the class.

Crazy Battleship Rules

Binary Battleship

Now that you’ve played Battleship a few times, we're going to create an efficient binary protocol for playing a 4-person game of Battleship with no 'talking' allowed. By 'efficient' we mean your protocol uses the smallest reasonable number of bits (0s and 1s) that still carries all of the information needed to play the game. Think back to the games you played verbally - what did you actually have to "say" to keep the game going?

Let's brainstorm ideas for your protocol:

  • Remember, we need to send all of the information to play the game using only 0’s and 1s.
  • How will we standardize the recipient and sender addresses?
  • Should we encode people's names or use a number?
  • How would a recipient of your message know where one address ends and the other begins?
  • What other information do we need to include?

How does this activity have anything to do with the Internet? It turns out computers on the Internet are addressed in a similar way for many of the same reasons. The real addresses used on the Internet are called “Internet Protocol Addresses” or IP Addresses for short. 

Internet protocol

The Internet Protocol (IP) is a protocol, or set of rules, for routing and addressing packets of data so that they can travel across networks and arrive at the correct destination.

An IP address is a unique identifier assigned to a device or domain that connects to the Internet. There are two types of IP addresses, v4 and v6. Each IPv4 address is a string of four eight-bit values represented in decimal form (i.e., numbers between 0 and 255) and separated by dots, such as '192.168.1.1'. Thankfully, you don't have to memorize strings like that to visit a website - DNS resolvers translate human-readable domain names into IP addresses for you.

The routers at every connection point on the Internet run IP, which transmits packets from one IP address to another. Watch the video below for more information on IP addresses and the difference between IPv4 and IPv6 (the video will stop before DNS at 4:09).
