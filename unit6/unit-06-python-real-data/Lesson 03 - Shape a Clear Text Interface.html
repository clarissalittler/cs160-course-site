Lesson 3 - Shape a Clear Text Interface

By the end of this lesson, you will be able to:

  • Create multi-line output with triple-quoted strings.
  • Insert changing values into a multi-line f-string.
  • Turn a collection of words into readable text with join.
  • Design a small command vocabulary that is visible, consistent, and keyboard-friendly.

Three quotes make room for multiple lines

A string surrounded by three quotation marks can continue across line breaks. This is useful whenever the arrangement of several lines belongs to one message:

announcement = """
COMMUNITY RADIO 91.7 FM
Tonight at 8: Songs for a Rainy Bus Ride
Requests open after the weather report.
"""

print(announcement)

Triple quotes are still ordinary Python strings. They can hold instructions, a recipe card, dialogue, a poem, a status panel, a title screen, or any other multi-line text.

Multi-line f-strings can display changing data

event = {
    "title": "Repair Café",
    "when": "Saturday, 10:00–2:00",
    "where": "Community Center Studio",
    "tags": ["repair", "tools", "all ages"],
    "cost": 0,
}

tag_words = ", ".join(event["tags"])

card = f"""
+--------------------------------------+
EVENT: {event["title"]}
WHEN:  {event["when"]}
WHERE: {event["where"]}
TAGS:  {tag_words}
COST:  ${event["cost"]}
+--------------------------------------+
"""

print(card)

The fixed labels and punctuation come from the f-string. The details come from the event dictionary. A different dictionary can reuse the same display structure.

join turns several words into one string

access_features = ["step-free entrance", "captions", "quiet room"]
print("ACCESS: " + "; ".join(access_features))

The result places a semicolon and space between neighboring phrases. join does not change the original list; it produces one new string for display.

Put repeated presentation in a function

def show_event(event):
    tag_words = ", ".join(event["tags"])

    if event["cost"] == 0:
        cost_words = "free"
    else:
        cost_words = f'${event["cost"]}'

    print(f"""
EVENT: {event["title"]}
WHEN: {event["when"]}
WHERE: {event["where"]}
TAGS: {tag_words}
COST: {cost_words}
""")

This function's job is presentation. It reads an event record but does not edit its title, tags, or cost. A resource directory, recipe collection, character roster, or travel guide could use the same separation between data and display.

A command vocabulary is an agreement

Interactive text programs only understand comparisons their authors wrote. Make the supported vocabulary visible:

def show_help():
    print("Commands: next, previous, details, save, help, quit")

command = input("Choose a command: ").strip().lower()

.strip().lower() makes capitalization and extra outside spaces harmless. It does not make the computer understand every phrase. If the program checks for next, then show me another one remains a different string unless the author deliberately supports it.

Clarity matters more than decoration

Borders and text art can be fun, but rows of punctuation may sound tedious through a screen reader and wrap on a phone. Use explicit labels such as EVENT, WHEN, and COST. Never communicate status only through color, emoji, spacing, or capitalization. Important information should remain understandable when copied as plain text.

Interface studio. Choose an event card, transit display, recipe card, playlist panel, character sheet, room card, or another small display. Then:

  1. Create one triple-quoted heading or instruction block.
  2. Store the changing details in a dictionary.
  3. Use a multi-line f-string to display the dictionary with labels.
  4. Use join to display one list.
  5. Ask another person to identify the important facts and available actions without explanation.
