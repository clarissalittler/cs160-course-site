Unit 6 Overview - Files, Databases, and Software in the Real World

Unit 5 built an information tool that lived entirely in memory. This unit asks what changes when the records have to survive, when they arrive in imperfect files, when your code leans on code written by other people, when the questions start sounding like database questions, and when the program has to stay understandable through revision after revision. It's a compact taste of data management and software engineering—not just another week of Python syntax.

Required examples use Python's Standard Library and run in a browser-based interpreter. File behavior differs by environment—Colab files last for the current runtime unless you download them or connect persistent storage, while an online IDE may save project files with an account. The assignment accepts either environment and asks for the generated CSV alongside the code when that's practical.

Learning objectives

  1. Read, write, append, and safely load UTF-8 text files.
  2. Read and write CSV records with explicit type conversion, quality checks, and provenance.
  3. Use Standard Library documentation and evaluate dependency source, version, maintenance, license, and trust.
  4. Translate selection, filtering, sorting, and aggregation between plain language, Python, and basic SQL.
  5. Separate responsibilities, write acceptance examples and regression checks, refactor, and maintain a change log.
  6. Explain privacy, access, and responsibility created by persistent data and borrowed code.

Five-lesson path

  1. Persistence and Files: memory versus storage, paths, modes, encoding, line endings, and missing files.
  2. CSV, Types, and Provenance: tabular structure, conversions, imperfect values, data dictionaries, and source notes.
  3. Libraries, Documentation, and Dependencies: import reusable code without confusing convenience with understanding or trust.
  4. Querying Data with Python and SQL: express row, field, sort, and summary questions in two forms.
  5. Software as an Evolving Artifact: requirements, functions, tests, version history, review, refactoring, and responsible reuse.

Learning activities and assessment

  1. Complete Lessons 1–5 and Python Practice Problems.
  2. Complete Unit 6 Quiz.
  3. Complete Week 6 Assignment: extend or recreate the information tool with CSV persistence, validation, filtering, summary, tests, and a change log.
  4. Complete and share the Week 6 Activity Discussion: Build a Tiny Dataset and Ask It a Question.
