Unit 6 Overview

This unit points everything you've learned at the real world. Up to now your programs have worked with data you typed in by hand; here you'll learn to work with data that already exists. You'll read and write files so your programs can remember things, open up CSV files (the format behind every spreadsheet), pull in libraries of code other people have written, and organize messy real-world information as lists of dictionaries. It all comes together in a mini-project where you take an actual dataset from a file to a finished report.

Learning objectives

At the end of this learning module, you will be able to:

  1. Read data from and write data to files. 
  2. Read tabular data from a CSV file into your program. 
  3. Import and use modules from the Standard Library, and explain how third-party packages are installed with pip. 
  4. Organize structured data as a list of dictionaries, and loop over it to filter and summarize. 
  5. Combine these skills to analyze a real dataset end to end.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

  1. Complete Lessons 1 - 5 and Python Practice Problems (LOs 1-5)
  2. Complete Quiz 6 (LOs 1-4)
  3. Complete and submit Week 6 Assignment (LOs 1-4)
  4. Complete and share the Week 6 Activity Discussion: Collection Tracker
