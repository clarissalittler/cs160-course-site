Question #1

Write a program that asks the user for their five favorite movies, one at a time, and saves them to a file called movies.txt - one movie per line. Then, in the same program, read the file back and print each movie with a number in front of it. (This proves your file actually got written.)

Solution 
def main():
    # Write the five movies out, one per line
    with open("movies.txt", "w") as out_file:
        for number in range(1, 6):
            movie = input(f"Enter favorite movie #{number}: ")
            out_file.write(movie + "\n")

    # Read them back and print them numbered
    print("\nYour list:")
    count = 1
    with open("movies.txt", "r") as in_file:
        for line in in_file:
            print(f"{count}. {line.strip()}")
            count += 1

main()

Question #2

Create a CSV file called weather.csv with this data (a week of high temperatures):

day,high
Monday,54
Tuesday,58
Wednesday,49
Thursday,61
Friday,66
Saturday,63
Sunday,57

Write a program that reads the file with csv.DictReader and reports the average high temperature and the warmest day (by name). Remember that the temperatures come in as text!

Solution 
import csv

def main():
    total = 0
    count = 0
    warmest_day = ""
    warmest_high = -1000

    with open("weather.csv", "r") as data_file:
        reader = csv.DictReader(data_file)
        for row in reader:
            high = int(row["high"])   # text -> number
            total += high
            count += 1
            if high > warmest_high:
                warmest_high = high
                warmest_day = row["day"]

    print(f"Average high: {total / count:.1f}")
    print(f"Warmest day: {warmest_day} ({warmest_high})")

main()

Question #3

The random module can do more than randint. Look up random.choice (it picks a random item out of a list) and use it to write a "Magic 8-Ball" program: store a handful of answers in a list ("Definitely," "Ask again later," "No way," &c.), then let the user ask a yes/no question and print one answer at random. Keep answering until they type quit.

Solution 
import random

def main():
    answers = ["Definitely", "Ask again later", "No way",
               "It is certain", "Very doubtful", "Signs point to yes"]

    print("Ask the Magic 8-Ball a question (or 'quit' to stop).")
    question = input("\nYour question: ")
    while question != "quit":
        print("  ->", random.choice(answers))
        question = input("\nYour question: ")

    print("Goodbye!")

main()

Question #4

Here is a list of dictionaries, each describing a book:

books = [
    {"title": "The Left Hand of Darkness", "author": "Le Guin", "year": 1969, "pages": 304},
    {"title": "Parable of the Sower",      "author": "Butler", "year": 1993, "pages": 352},
    {"title": "Kindred",                   "author": "Butler", "year": 1979, "pages": 288},
    {"title": "A Wizard of Earthsea",      "author": "Le Guin", "year": 1968, "pages": 208},
]

Write a program that (a) prints every book's title and year, (b) prints the title of the longest book by page count, and (c) prints only the books written by "Butler."

Solution 
def main():
    books = [
        {"title": "The Left Hand of Darkness", "author": "Le Guin", "year": 1969, "pages": 304},
        {"title": "Parable of the Sower",      "author": "Butler", "year": 1993, "pages": 352},
        {"title": "Kindred",                   "author": "Butler", "year": 1979, "pages": 288},
        {"title": "A Wizard of Earthsea",      "author": "Le Guin", "year": 1968, "pages": 208},
    ]

    # (a) every title and year
    print("All books:")
    for book in books:
        print(f"  {book['title']} ({book['year']})")

    # (b) the longest book
    longest = books[0]
    for book in books:
        if book["pages"] > longest["pages"]:
            longest = book
    print(f"\nLongest: {longest['title']} ({longest['pages']} pages)")

    # (c) just Butler's books
    print("\nBy Butler:")
    for book in books:
        if book["author"] == "Butler":
            print(f"  {book['title']}")

main()
