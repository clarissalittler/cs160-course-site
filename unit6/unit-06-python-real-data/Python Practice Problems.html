2. Add and verify a connection

Start with this small community guide:

guide = {
    "library": {"name": "Library", "connections": {"east": "park"}},
    "park": {"name": "River Park", "connections": {"west": "library"}},
}

Add a market record. Connect the park south to the market and the market north to the park. Print both destination keys. Explain what would happen if one connection used "Market" but the outer key were "market".

Check one solution
guide["market"] = {
    "name": "Saturday Market",
    "connections": {"north": "park"},
}
guide["park"]["connections"]["south"] = "market"

print(guide["park"]["connections"]["south"])
print(guide["market"]["connections"]["north"])

Dictionary keys are case-sensitive. Market would not find the market key.

3. Format an event card

Write a function that accepts one event dictionary and prints a labeled multi-line f-string containing its title, time, and comma-separated tags. Use .get() to display not listed when the location is absent.

Check one solution
def show_event(event):
    tags = ", ".join(event["tags"])
    location = event.get("location", "not listed")

    print(f"""
EVENT: {event["title"]}
TIME: {event["time"]}
LOCATION: {location}
TAGS: {tags}
""")

4. Advance a playlist selection

Complete the function. It returns the next valid index, but stays at the current index when the playlist is empty or already at the final song.

def next_index(current, songs):
    # YOUR CONDITIONS AND RETURNS HERE
    pass

songs = ["Low Tide", "Night Bus", "Paper Stars"]
selected = 0
selected = next_index(selected, songs)
print(selected)  # 1
Check one solution
def next_index(current, songs):
    if len(songs) == 0:
        return current
    if current + 1 >= len(songs):
        return current
    return current + 1

5. Trace two changing lists

available = ["Umbrella", "Chess Set"]
borrowed = []
title = "Umbrella"

if title in available:
    available.remove(title)
    borrowed.append(title)

Draw both lists before and after this block. What happens if the block runs again without resetting the lists? Why?

Check the reasoning

Before: both items are available and nothing is borrowed. After: only the chess set remains available and the umbrella is borrowed. A second run changes nothing because the title is no longer in available.

6. Debug a request menu

requests = []
running = True

while running:
    command = input("add, show, or quit? ").strip().lower()
    if command == "add":
        title = input("Song: ").strip()
        requests + [title]
    elif command == "show":
        print(requests)
    elif command == "quit":
        running == False
    else:
        print("Unknown command")

There are two state-update bugs. Identify and repair both.

Check one solution
if command == "add":
    title = input("Song: ").strip()
    requests.append(title)
elif command == "quit":
    running = False

The addition expression was never assigned; append performs the intended list change. Assignment uses one equals sign.
