Unit 6 Summary

Wrap up

In this unit, you pointed your programming skills at real-world data. You learned to read and write files so data can outlive a single run, to open CSV files that hold tables of data, to pull in libraries of code other people have written, and to organize structured information as a list of dictionaries. You finished by analyzing an actual dataset from start to finish - the real work of a data analyst. Later, in Unit 8, you'll pick this same work up with power tools: the pandas and matplotlib libraries, in ready-made notebooks, let you chart and explore datasets far larger than anything you'd want to loop over by hand - and having done it the manual way here, you'll understand exactly what those tools are doing for you.

Summary

  • Open a file with with open(name, mode) as f:; the with block closes it for you automatically.
  • File modes: "r" reads, "w" writes from scratch (erasing what was there), and "a" appends to the end.
  • You can loop over a file line by line; use .strip() to trim the trailing newline from each line.
  • A CSV file stores a table as comma-separated values; csv.DictReader reads each row as a dictionary keyed by the header row.
  • Values read from a file always arrive as strings - convert with float() or int() before doing math.
  • import brings in a module; the Standard Library ships with Python, and pip install adds third-party packages like pandas and matplotlib.
  • A list of dictionaries models a table of records - loop over it to read, filter, and summarize, the way real (and JSON) data is handled.
