Step 1: Get the data

We'll analyze a small set of day hikes near Portland. Create a file called hikes.csv, in the same folder as your program, and paste this in exactly:

name,miles,elevation_gain,difficulty
Angels Rest,4.8,1500,hard
Latourell Falls,2.4,600,easy
Dog Mountain,6.9,2800,hard
Wahclella Falls,2.4,400,easy
Mirror Lake,4.1,700,moderate
Multnomah-Wahkeena Loop,4.9,1600,moderate
Tom McCall Point,3.4,1070,moderate
Cape Horn,7.3,1300,hard

That header row matters - name, miles, elevation_gain, difficulty become the dictionary keys you'll use.

Step 2: Load it into a list of dictionaries

Start your program by reading the CSV into a list, converting the numeric columns as you go (remember: everything comes out of a file as text). Building the list up front means the rest of your program can loop over clean data as many times as it likes.

import csv

def load_hikes(filename):
    hikes = []
    with open(filename, "r") as data_file:
        reader = csv.DictReader(data_file)
        for row in reader:
            # convert the number columns from text now, once
            row["miles"] = float(row["miles"])
            row["elevation_gain"] = int(row["elevation_gain"])
            hikes.append(row)
    return hikes

Notice we tucked the loading into its own function - a habit from Unit 4 that keeps main() readable.

Step 3: Ask questions and write a report

Now the analysis. Your main() should compute and print at least:

  • how many hikes are in the dataset,
  • the average length in miles,
  • the name of the hike with the most elevation gain, and
  • a list of just the easy hikes (a filter).

Give it a try before you peek. Every piece is something you've done - accumulators, "track the best so far," a filtering loop. When you're ready, compare:

import csv

def load_hikes(filename):
    hikes = []
    with open(filename, "r") as data_file:
        reader = csv.DictReader(data_file)
        for row in reader:
            row["miles"] = float(row["miles"])
            row["elevation_gain"] = int(row["elevation_gain"])
            hikes.append(row)
    return hikes

def main():
    hikes = load_hikes("hikes.csv")

    # How many, and how long on average?
    count = len(hikes)
    mile_total = 0
    for hike in hikes:
        mile_total += hike["miles"]
    average_miles = mile_total / count

    # Which hike climbs the most?
    steepest = hikes[0]
    for hike in hikes:
        if hike["elevation_gain"] > steepest["elevation_gain"]:
            steepest = hike

    # Print the report
    print("=== Portland Day Hikes ===")
    print(f"Hikes in dataset: {count}")
    print(f"Average length:   {average_miles:.1f} miles")
    print(f"Most climbing:    {steepest['name']} ({steepest['elevation_gain']} ft)")

    print("\nEasy hikes:")
    for hike in hikes:
        if hike["difficulty"] == "easy":
            print(f" - {hike['name']} ({hike['miles']} miles)")

main()

Run it and you get a clean little report generated entirely from a data file. Change the CSV - add a hike, edit a number - rerun, and the report updates itself. That is the difference between a spreadsheet you edit by hand and a program that does the work for you.

What the data doesn't say. Your program will happily report that the "average" hike is 4.5 miles - but averages hide things. This dataset has no wheelchair-accessible trails, no note of which need a permit, no sense of which are so popular they're miserable on a Saturday. A dataset is a model of reality, shaped by whoever built it and whatever they thought was worth a column. Part of working with data honestly is naming what got left out. Who would a "best hikes near Portland" list serve well - and who would it quietly ignore?

Make it yours. Swap in a dataset you care about - your music library, a sports season, prices you're tracking, your houseplants. Build the CSV, adjust the field names and the conversions, and write three questions worth answering.
