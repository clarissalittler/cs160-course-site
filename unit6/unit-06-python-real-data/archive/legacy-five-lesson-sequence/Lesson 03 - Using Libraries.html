Modules: borrowing code that already exists

You don't have to write everything from scratch. Python comes with a huge Standard Library - collections of ready-made functions, organized into modules, that you can pull into your program with import. The random module

To use a module, put import at the top of your program. The random module's most useful function is random.randint(a, b), which gives back a random whole number between a and b (both ends included):

# This program displays a random number in the range 1 through 10.
import random

def main():
    # Get a random number 1-10 and store it in 'number'
    number = random.randint(1, 10)
    print('The number is', number)

main()

Run it a few times - you'll get a different number almost every time. Notice the shape of the call: random.randint(...) is the module name, a dot, then the function name. The dot is you saying "the randint that lives inside random." Every module works this way.

Try it! Combine what you know: wrap that random generator in a for loop so it prints 5 random numbers, each between 1 and 10. Beyond the box: third-party packages and pip

The Standard Library is generous, but it's just the beginning. Out in the wider world, hundreds of thousands of programmers have written and shared packages - libraries that don't ship with Python but that anyone can download and use for free. They live in a giant public warehouse called PyPI (the Python Package Index), and you install one with a command-line tool called pip:

pip install pandas

Run that once, and from then on your programs can import pandas just like they import random. A few packages you'll bump into constantly:

The first two on that list, pandas and matplotlib, are the exact tools professional data analysts reach for - and they're waiting for you in Unit 8, where you'll use them to slice up datasets and draw charts. Everything you're learning about reading CSVs and looping over rows is the hand-rolled version of what those libraries automate. Learning the manual version first means you'll actually understand what the fancy tools are doing for you.

Standing on other people's work. Almost all of this shared code is open source - written by volunteers and given away, free, for anyone to use, read, and improve. It's one of the quietly astonishing things about modern software: a student in Portland and a company worth billions run on much of the same donated code. Worth asking our unit's questions here too - who does the unpaid work of maintaining the tools everyone depends on, who benefits, and what happens when a critical piece is kept alive by one exhausted volunteer?

Putting it all together: a guessing game

Here's a complete program that leans on a module plus everything from the last two units - a random answer, a while loop that runs until the guess is right, counters for the accumulator pattern, and input validation. (It also uses try/except, Python's way of catching errors gracefully - here, catching when someone types something that isn't a number. You don't need to master it yet; just notice it's there.)

import random

def main():
    answer = random.randint(1, 10)
    guess = 0
    too_high = 0
    too_low = 0

    print("Guess a number between 1 and 10!")
    while guess != answer:
        valid = False
        while not valid:
            try:
                guess = int(input("\nEnter guess: "))
                if guess < 1 or guess > 10:
                    print("Guess must be 1-10")
                else:
                    valid = True
            except:
                print("Not an integer!")

        if guess == answer:
            print("Correct!!")
        elif guess > answer:
            print("Too high!")
            too_high += 1
        else:
            print("Too low!")
            too_low += 1

    print(too_high, "of your guesses were too high.")
    print(too_low, "of your guesses were too low.")
    print("\nThank you for playing!")

main()
