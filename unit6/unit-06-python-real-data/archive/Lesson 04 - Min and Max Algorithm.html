Min and max algorithm

Finding the minimum and maximum values in an array is a common algorithm. We will need to create variables to hold the min and max, and then we will compare each element of the array or list with min and max and update when we find smaller or larger values. Look at the pseudocode below and follow the logic:

  1. set min to the first element in the list
  2. set max to the first element in the list
  3. loop through the list looking at each element
  4.       if the element is bigger than max
  5.            update max
  6.       if the element is smaller than min
  7.           update min

When the array or list is done being processed, min and max will contain the smallest and largest elements!

Study the program below. (Or download the minimum.py and run in your IDE of choice.). You can add code to find the maximum in the list of nums.

#This program finds the minimum in a list of numbers
#You write code to find the maximum
def main():
  nums = [3, -2, 4, 10, -6]

  print("array:", nums)
  min = nums[0] # always set min/max to cell 0!
  length = len(nums) # get the number of elements

  # loop through all of the elements
  for index in range(length):
      if nums[index] < min:
          min = nums[index]

  #print the minimum
  print("min:", min)

main()

Bug Alert: When searching for min and max, it is a common mistake to initialize min and max to random values. For example, max = 0, initializes max to 0, the thinking is that the maximum number in the array will be bigger than 0, so we are safe to start with 0. But what if all of the numbers are negative? The max will end up being 0, which is not correct! Or setting min to a really big number to start, thinking all the numbers will be smaller.

Remember, always set min/max to cell 0 of the array or list to start - cell 0 is the smallest and largest so far - until we start comparing the remaining elements.
