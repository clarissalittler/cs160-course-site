1. Predict, write, append, and load

Write three task labels to tasks.txt, append a fourth task, then load the file into a list and number the output. Before running, write the exact expected file contents after every operation. Add a loader that returns an empty list when the file does not exist.

Show one solution
def load_lines(filename):
    lines = []
    try:
        with open(filename, "r", encoding="utf-8") as input_file:
            for line in input_file:
                lines.append(line.rstrip("\n"))
    except FileNotFoundError:
        return []
    return lines

with open("tasks.txt", "w", encoding="utf-8") as output_file:
    output_file.write("Check schedule\n")
    output_file.write("Bring notes\n")
    output_file.write("Charge laptop\n")

with open("tasks.txt", "a", encoding="utf-8") as output_file:
    output_file.write("Pack headphones\n")

tasks = load_lines("tasks.txt")
for index in range(len(tasks)):
    print(f"{index + 1}. {tasks[index]}")

2. Load an imperfect CSV with a quality log

Create a five-row CSV with a text field, categorical field, and numerical field. Include one missing name and one malformed number. Load valid records into a list of dictionaries, log skipped row numbers and reasons, and report total, loaded, and skipped counts. Write valid records to a new file.

Show a loading pattern
import csv

records = []
problems = []

with open("source.csv", "r", encoding="utf-8", newline="") as data_file:
    reader = csv.DictReader(data_file)
    for row_number, row in enumerate(reader, start=2):
        if row["name"].strip() == "":
            problems.append(f"Row {row_number}: missing name")
            continue
        try:
            amount = float(row["amount"])
        except ValueError:
            problems.append(f"Row {row_number}: amount is not numeric")
            continue
        records.append({"name": row["name"].strip(), "category": row["category"].strip(), "amount": amount})

print(f"Loaded: {len(records)}")
print(f"Skipped: {len(problems)}")
for problem in problems:
    print(problem)

Your full solution should also write a clean copy and include a data dictionary and provenance note.

4. Express one query two ways

Given a list of resource dictionaries, display the names and costs of every North-area record with cost at most $10, ordered from highest to lowest cost. Write a Python solution and then the equivalent SQL.

Show one pair
matches = []
for resource in resources:
    if resource["area"] == "North" and resource["cost"] <= 10:
        matches.append(resource)

matches.sort(key=lambda item: item["cost"], reverse=True)
for resource in matches:
    print(resource["name"], resource["cost"])
SELECT name, cost
FROM resources
WHERE area = 'North' AND cost <= 10
ORDER BY cost DESC;

The lambda is supplied here as a compact sorting key; students may instead write a small named key function. SQL mastery is not required—explain how each clause corresponds to the plain-language question.

5. Protect a refactor

Take a function that filters records. Write tests for ordinary capitalization, no matches, empty input data, and a boundary. Then rename unclear variables or remove duplicated code without changing the results. Record the change and evidence in a one-row change log.

Show a test pattern
def filter_by_area(records, area):
    matches = []
    for record in records:
        if record["area"].lower() == area.lower():
            matches.append(record)
    return matches

sample = [
    {"name": "A", "area": "North"},
    {"name": "B", "area": "Central"},
    {"name": "C", "area": "North"},
]

assert len(filter_by_area(sample, "North")) == 2
assert len(filter_by_area(sample, "north")) == 2
assert len(filter_by_area(sample, "South")) == 0
assert len(filter_by_area([], "North")) == 0
print("Tests passed.")
