The Setup

CSV stands for "Comma-Separated Values," and it's one of the most common ways data gets shared. It's just a text file where each line is a row and commas separate the columns. You can open one in Notepad and read it with your eyes. No special software required.

Step 1: Read the File

First things first — let's get the data into Python. No import csv, no libraries. We're doing this the raw way, because understanding what's actually happening matters more than convenience (for now).

data = []
with open("requests.csv", "r") as f:
    header = f.readline().strip().split(",")
    for line in f:
        row = line.strip().split(",")
        data.append(row)

print(f"Loaded {len(data)} records")
print(f"Columns: {header}")

What's happening here? We open the file, read the first line as the header (the column names), then loop through the rest. Each line gets stripped of whitespace and split on commas, giving us a list of values. Each row is a list, and data is a list of lists. That's your whole dataset, sitting in memory, ready to be interrogated.

Run it. You should see:

Question 2: Which neighborhood has the most requests?

This one's trickier. You need to count how many times each neighborhood appears. A dictionary is perfect for this — the key is the neighborhood name, and the value is the count.

Try it! Build a dictionary that maps each neighborhood to its number of requests. Then figure out which one has the highest count. (Hint: loop through the dictionary to find the maximum.)

Show Hint 
neighborhoods = {}
for row in data:
    hood = row[2]
    if hood in neighborhoods:
        neighborhoods[hood] += 1
    else:
        neighborhoods[hood] = 1

print(neighborhoods)

# Find the max
busiest = ""
busiest_count = 0
for hood, count in neighborhoods.items():
    if count > busiest_count:
        busiest = hood
        busiest_count = count
print(f"Busiest neighborhood: {busiest} ({busiest_count} requests)")
