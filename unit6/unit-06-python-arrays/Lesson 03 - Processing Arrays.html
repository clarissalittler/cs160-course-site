Looping through lists

When we store data in lists, it is common to want to look at all of the elements. The code below creates a list with 5 elements and then prints out the index and element at that index. Download the list.py and run in your IDE of choice.

def main():
    nums = [2, -3, 10, -1, 7]

    print(0, nums[0])
    print(1, nums[1])
    print(2, nums[2])
    print(3, nums[3])
    print(4, nums[4])

main()

But what if our list had 100 elements? That would be a lot of copying and pasting of code! Instead, we will use a for loop to iterate through the elements of the list. We will use two functions to help us do this, the len() function and the range() function. You may want to review the range() function presented in Unit 5 - Iteration.

len() function

The len() function is a value returning function which is passed a list name as an argument and returns the number of elements in the list. For example:

# this array has 8 elements
nums = [1, 2, 3, 4, 5, 6, 7, 8]
# len(nums) returns 8 which is stored in the variable length
length = len(nums)

Once we have the length of a list, we can pass that value to the range() function to generate the indexes for that list! If the length of a list is 8, the range() function will generate the sequence: 0, 1, 2, 3, 4, 5, 6, 7 which we will use as indexes to the list.

Run the program below (Copy from below or download the loop_list.py and run in your IDE of choice) using a for loop, len() and range() to print the the same output as the program at the top of this page.

#same list uses a for loop to print
def main():
    nums = [2, -3, 10, -1, 7]

    length = len(nums)

    for index in range(length):
        print(index, nums[index])
        
main()

Bug Alert: Slow down and walk through the code above to understand what is happening. What is index in the for loop? It is a variable to hold all of the values generated from the range() function - it will contain all of the indexes for the nums list. nums[index] is how we refer to each element. Compare this code with the code at the top to make sure you really understand!

Reading Input into lists

The above lists were already created for you. Let's see how to add colors to a list of colors. In the program below, we start with an empty list called colors, and then we add colors from the user until they hit the Enter key. Take a look at the program and see if you can make it your own by copying it and changing it to do other things. Watch the video below to see how the formatted printing works.

#reads colors from the user and appends to a list
#until the user presses the Enter key.
def main():
  colors = []
  #notice how we read one time outside the loop
  #check and then enter the loop
  aColor = input("Enter a color: ")
  while (aColor != ''):
    colors.append(aColor)
    aColor = input("Enter a color: ")

  print(colors)
  print("If you want it formatted better: ")
  for num in range(len(colors)-1):
    print(colors[num], ", ", sep = '', end = '')
  print(colors[num+1])

#call main
main()
