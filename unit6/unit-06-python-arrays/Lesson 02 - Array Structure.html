Array and list vocabulary

Let's look in detail at how arrays and lists are stored in memory and define vocabulary specific to arrays and lists!

When we create a variable to hold an integer:

num = 22

memory is allocated to hold the value 22. We refer to that location by its name - num.

Arrays behave similarly - except when we access a value in an array, we have to specify where it is in the array. We use locations in an array just like we use variables, except for the name. The name of a specific value in an array will be the name of the array and in square brackets [] we specify the index or position of the value we want.

nums[1] is referring to the value -3 located in the second position in the array. Take note that array indexes always start at 0, so the first value will be in position 0, the second value will be in position 1, etc.

Bug Alert: Because indexes start with 0, the last index will ALWAYS be 1 less than the size of the array. An array of size 5 will have indexes 0, 1, 2, 3, and 4. For an array or list of size N, the last index will be at position N - 1 !!
