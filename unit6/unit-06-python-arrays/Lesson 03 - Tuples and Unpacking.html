Lesson 3 - Tuples and Unpacking

At the end of this lesson, you will be able to:

  • Create a tuple to group related pieces of data together.
  • Unpack a tuple into separate variables.
  • Loop over a list of tuples, unpacking as you go.

What's a tuple?

A list is perfect for many things of the same kind. But sometimes you want to bundle together a few pieces that belong together - a name and a score, an x and a y, a song title and its artist. For that, Python has the tuple: an ordered group of values, written with parentheses ( ).

point = (3, 5)            # an (x, y) pair
student = ("Mary", 98)    # a (name, score) pair

print(point[0])           # 3   - index it just like a list
print(student[1])         # 98

You index a tuple with [ ] exactly like a list. The big difference: a tuple is immutable - once you make it, you can't change its contents. That sounds like a limitation, but it's actually the point: a tuple says "these pieces go together and shouldn't be split up or rearranged." A name and its score are a unit.
