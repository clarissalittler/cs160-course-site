Question #1

Question #1: Design a program that lets the user enter the total number of hours slept each night for one week (7 days). The program should calculate and display the total hours slept and the average hours slept.

Solution 
def main():
    hours_slept = []
    total = 0
    average = 0

    print("Enter your sleep hours for a week!\n")

    for index in range(7):
        prompt = "How many hours did you sleep on day # " + str(index + 1) + ": "
        hours_slept.append(float(input(prompt)))

    for index in range(7):
        total = total + hours_slept[index]
    print(f"\nYou slept {total} hours this week.")

    average = total / 7
    print(f"That is {average:.2f} hours a night on average.")

main()

Question #2

Question #2: Modify Question #1 to also find the largest and smallest number of hours slept during the week. Use the algorithm from Lesson 2: after reading all 7 days, initialize both variables to cell 0 of the list, then loop through the rest looking for anything smaller (or larger). For example:

smallest = hours_slept[0]

(One aside: Python actually has built-in min() and max() functions that do this in one step - which is exactly why we name our variables smallest and largest instead. If you name a variable min, it "shadows" the built-in, and any later call to min(...) in your program crashes.)

Solution 
def main():
    hours_slept = []
    total = 0

    print("Enter your sleep hours for a week!\n")

    for index in range(7):
        prompt = "How many hours did you sleep on day # " + str(index + 1) + ": "
        hours_slept.append(float(input(prompt)))

    for index in range(7):
        total = total + hours_slept[index]
    print(f"\nYou slept {total} hours this week.")

    average = total / 7
    print(f"That is {average:.2f} hours a night on average.")

    # start both at the first element - a real value from the list
    smallest = hours_slept[0]
    largest = hours_slept[0]

    for index in range(7):
        if hours_slept[index] < smallest:    # found something smaller?
            smallest = hours_slept[index]
        if hours_slept[index] > largest:     # found something larger?
            largest = hours_slept[index]

    print(f"Your best night was {largest} hours.")
    print(f"Your worst night was {smallest} hours.")

main()

Question #3

Question #3: Here's a little playlist stored as a list of (title, artist) tuples:

songs = [
    ("Everlong", "Foo Fighters"),
    ("Dreams", "Fleetwood Mac"),
    ("The Chain", "Fleetwood Mac"),
    ("Kickstart My Heart", "Motley Crue"),
]

Write a program that first prints every song on its own line, formatted like Everlong by Foo Fighters, using tuple unpacking in the for loop. Then ask the user for an artist and print only that artist's songs - compare fairly with .lower() on both sides so fleetwood mac still matches. (This is a warm-up for the filter in Assignment 3.)

A sample run:

Everlong by Foo Fighters
Dreams by Fleetwood Mac
The Chain by Fleetwood Mac
Kickstart My Heart by Motley Crue

Which artist? fleetwood mac
Dreams by Fleetwood Mac
The Chain by Fleetwood Mac
Solution 
def main():
    songs = [
        ("Everlong", "Foo Fighters"),
        ("Dreams", "Fleetwood Mac"),
        ("The Chain", "Fleetwood Mac"),
        ("Kickstart My Heart", "Motley Crue"),
    ]

    # print every song, unpacking each tuple as we go
    for title, artist in songs:
        print(f"{title} by {artist}")

    # filter: only the songs by the artist the user asks for
    wanted = input("\nWhich artist? ").lower()
    for title, artist in songs:
        if artist.lower() == wanted:
            print(f"{title} by {artist}")

main()

Question #4

Question #4: You're taking coffee orders for three friends before a run to the food carts. Write a program that asks for each person's name and their drink, and stores them in a dictionary - the name is the key, the drink is the value. Then ask the user for a name to look up. If the name is in the dictionary, print that person's order; if it isn't, print a friendly message instead of crashing. (Hint: check with if name in orders: before you look it up.)

A sample run:

Whose order? (person 1) Robin
What do they drink? cortado
Whose order? (person 2) Jesse
What do they drink? oat milk latte
Whose order? (person 3) Sam
What do they drink? drip, black

Look up a name: Jesse
Jesse's order: oat milk latte

And if the name isn't there:

Look up a name: Dana
Sorry, no order for Dana yet.
Solution 
def main():
    orders = {}    # start with an empty dictionary

    for person in range(1, 4):
        name = input(f"Whose order? (person {person}) ")
        drink = input("What do they drink? ")
        orders[name] = drink       # add a key/value pair

    name = input("\nLook up a name: ")
    if name in orders:
        print(f"{name}'s order: {orders[name]}")
    else:
        print(f"Sorry, no order for {name} yet.")

main()

Question #5

Question #5: Now build the playlist from Question #3 yourself, one record at a time. In a loop, ask the user for a song title and an artist, bundle them into a tuple, and append() it to a list. After each song, ask Add another? (yes/no) and stop when the answer isn't yes. Finally, print the whole playlist, one title by artist line at a time. (This add-records loop is exactly the shape Assignment 3 uses - get it working here and you're most of the way there.)

A sample run:

Song title: Dreams
Artist: Fleetwood Mac
Add another? (yes/no) yes
Song title: Everlong
Artist: Foo Fighters
Add another? (yes/no) no

Your playlist:
Dreams by Fleetwood Mac
Everlong by Foo Fighters
Solution 
def main():
    songs = []
    answer = "yes"

    while answer == "yes":
        title = input("Song title: ")
        artist = input("Artist: ")
        songs.append((title, artist))    # bundle into a tuple, add to the list
        answer = input("Add another? (yes/no) ")

    print("\nYour playlist:")
    for title, artist in songs:
        print(f"{title} by {artist}")

main()
