Parallel lists

In most programming languages, arrays can only hold the same type of data (ints, floats, strings, etc.) But think about a shopping receipt - each item has a quantity and a price. This would require 3 lists, one for the item name (string), one for the quantity (int), and one for the price (float). Elements in cell 0 will be the item, quantity, and price for the first item.

In the lists shown in Figure 6.4 below, the purchaser is buying 12 cookies at $0.25 each. The elements at index 2 in each list, relate this information.
