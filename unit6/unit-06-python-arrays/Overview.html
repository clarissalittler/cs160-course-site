Unit 6 Overview

In this unit, you will learn about collections - ways to hold lots of data in a single variable. You'll start with the list (an ordered sequence of values), then learn tuples for bundling related pieces together and dictionaries for looking things up by a meaningful key. Finally you'll combine them to build a small, searchable database of structured data.

Learning objectives

At the end of this learning module, you will be able to:

  1. Create and access lists in Python. 
  2. Process data in lists using loops, including algorithms like min and max. 
  3. Use tuples and dictionaries to store and look up related information.
  4. Use pair programming to develop a program.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

  1. Complete Lessons 1 - 5 and Python Practice Problems (LOs 1-4)
  2. Complete Quiz 6 (LOs 1-4)
  3. Complete and submit Assignment 3 (LOs 1-4)
  4. (Partner) Post to discussion Unit 6 Lesson 2 - Hobbies Program (LOs 1, 2, 3)

If you have questions, you can post them in the Course Lobby or send your instructor an email.
