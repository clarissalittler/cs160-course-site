Unit 6 Overview

In this unit, you will learn about a data structure called an array - which is a list of the same type of items. In Python, arrays are called lists and have built-in functions to manipulate the data. 

Learning objectives

At the end of this learning module, you will be able to:

  1. Create simple lists in Python. 
  2. Access and process data in lists using loops. 
  3. Use parallel lists to hold related information of different types.
  4. Use pair programming to develop a program.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

    1. Complete Lessons 1 - 6, Vocabulary Practice, and Python Practice Problems (LOs 1-4)
    2. Complete Quiz 6 (LOs 1-4)
    3. Complete and submit Assignment 3 (LOs 1-4)
    4. (Partner) Post to discussion Unit 6 Lesson 3 - Hobbies Program (LOs 1, 2, 3)

    If you have questions, you can post them in the Course Lobby or send your instructor an email.
