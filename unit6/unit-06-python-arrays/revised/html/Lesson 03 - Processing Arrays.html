Looping through lists

When we store data in lists, we almost always want to look at all of the elements at some point. The code below creates a list with 5 elements and prints out each index along with the element at that index. (You can download list.py and run it in your IDE of choice.)

def main():
    nums = [2, -3, 10, -1, 7]

    print(0, nums[0])
    print(1, nums[1])
    print(2, nums[2])
    print(3, nums[3])
    print(4, nums[4])

main()

Okay, that works. But what if our list had 100 elements? That'd be a lot of copying and pasting. Nobody wants that.

Instead, we'll use a for loop to iterate through the elements of the list. We'll lean on two built-in functions to make this work: len() and range(). You may want to review the [LMS Activity: range() function from Unit 5 - Iteration] if it's been a while.

The len() function

The len() function takes a list name as an argument and returns the number of elements in the list. For example:

# this array has 8 elements
nums = [1, 2, 3, 4, 5, 6, 7, 8]
# len(nums) returns 8 which is stored in the variable length
length = len(nums)

Once we have the length of a list, we can pass that value to range() to generate all the valid indexes for that list. If the length is 8, range() generates the sequence: 0, 1, 2, 3, 4, 5, 6, 7 — which are exactly the indexes we need. Nice and tidy.

Run the program below — it uses a for loop with len() and range() to produce the same output as the manual version above. (You can copy from here or download loop_list.py and run in your IDE of choice.)

#same list uses a for loop to print
def main():
    nums = [2, -3, 10, -1, 7]

    length = len(nums)

    for index in range(length):
        print(index, nums[index])

main()

Bug Alert: Slow down here and really walk through the code above. What is index in the for loop? It's a variable that holds each value generated by range() — which means it takes on every valid index for the nums list, one at a time. Then nums[index] is how we refer to each element. Compare this code with the manual version at the top to make sure you really see what's happening.

Reading input into lists

The lists above were already created for you. Let's see how to build a list from user input. In the program below, we start with an empty list called colors and then keep adding colors from the user until they just press Enter without typing anything. Take a look at the program and see if you can make it your own — copy it and try changing it to collect something else entirely.

#reads colors from the user and appends to a list
#until the user presses the Enter key.
def main():
  colors = []
  #notice how we read one time outside the loop
  #check and then enter the loop
  aColor = input("Enter a color: ")
  while (aColor != ''):
    colors.append(aColor)
    aColor = input("Enter a color: ")

  print(colors)
  print("If you want it formatted better: ")
  for num in range(len(colors)-1):
    print(colors[num], ", ", sep = '', end = '')
  print(colors[num+1])

#call main
main()
