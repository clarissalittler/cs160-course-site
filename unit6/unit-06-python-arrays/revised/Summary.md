# Unit 6 Summary

## Wrap Up

In this unit, we learned how to create lists of information in Python using arrays. By convention, each array holds a single type of data and is processed using iteration. When you need to store *related* data of different types, you use parallel arrays --- multiple lists that stay lined up by index.

> **Key Takeaways**
>
> - Use `[]` to access an element in an array.
> - Array cells are numbered starting at 0 through the size of the array minus 1.
> - The index of a cell is called a **subscript**.
> - When finding the minimum and maximum elements in an array, set your `min` and `max` variables to the element in cell 0.
> - Use the `append()` function to add elements to the end of an array.
> - Use the `len()` function to determine the size of the array.
