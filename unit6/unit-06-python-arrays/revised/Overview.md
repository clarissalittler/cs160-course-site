# Unit 6 Overview

![Unit 6 banner](img/banner.jpg)

In this unit, we're diving into a data structure called an **array** --- basically a list of items that all belong together. In Python, arrays are called **lists**, and they come with a bunch of handy built-in functions for wrangling your data. Lists are one of the most useful things you'll learn in this course, so let's get into it.

## **After this unit, you'll be able to:**

1. Create simple lists in Python.
2. Access and process data in lists using loops.
3. Use parallel lists to hold related information of different types.
4. Use pair programming to develop a program.
