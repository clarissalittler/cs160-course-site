Unit 6 Summary

Wrap up

In this unit, you learned how to hold collections of data in Python. Lists store an ordered sequence of values that you process with iteration. Tuples bundle related pieces together, and dictionaries let you look values up by a meaningful key. Combining them - a list of tuples or dictionaries - lets you store and search a table of structured data.

Summary

  • Use [] to access an element in a list; indexes start at 0, so the last index is the length minus 1.
  • Use append() to add an element to the end of a list and len() to find its size.
  • When finding the minimum and maximum, start min and max at the first element (index 0).
  • A tuple groups related values together and can be unpacked into separate variables (for example, name, score = student).
  • A dictionary stores key/value pairs that you look up by key.
  • Store a table of records as a list of tuples or a list of dictionaries.
