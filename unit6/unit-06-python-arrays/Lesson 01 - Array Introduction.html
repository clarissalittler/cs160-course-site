Lists of information

Lists of information are used every day and are helpful for organizing large amounts of data. Think about the lists you create - shopping lists, playlists of songs, lists of classes you need to take - we create all kinds of lists!

In programming, we can create lists of information - called arrays. In Python, arrays are actually called lists - there are implementation differences between arrays and lists, but for now, we will use list and array interchangeably.

After a list is created, Python has a function to add items to a list called append() and a function to remove items from a list called remove().

Run the program below (Copy from below or download the shoppingList.py and run in your IDE of choice) - look at the syntax to create the list and then add and remove items from the list. What happens when you try and remove an item that is not in the list? Try it and see!

def main():
    # create a list called shoppingList, notice the []
    # to create the list of items
    shoppingList = ['apples', 'la croix', 'mango', 'rice']

    print(shoppingList) # print the list

    # add an item to the list and print again
    shoppingList.append('chicken')
    print(shoppingList)

    # remove an item from the list and print again
    shoppingList.remove('mango')
    print(shoppingList)

main()
