Lesson 2 - Values, Variables, and Types

At the end of this lesson, you will be able to:

  • Store a value in a variable and trace how reassignment changes it.
  • Distinguish strings, integers, floating-point numbers, and Boolean values.
  • Choose descriptive variable names and include units where they matter.
  • Predict the final state and output of a short sequential program.

Values are the material programs work with

Last lesson, print() displayed pieces of text. Each piece of text was a value: a piece of data a program can store or use. Programs also work with numbers, yes-or-no values, images, sounds, lists, and many other forms of data. We will start with four basic Python types:

  • str (string): text such as "Vancouver" or "42"
  • int (integer): a whole number such as 42 or -7
  • float: a number that can have a decimal part, such as 42.0 or 3.75
  • bool (Boolean): one of the special values True or False

Quotation marks matter. 42 is a number; "42" is two text characters. We can do arithmetic with the first. The second might be a room label, part of an address, or text waiting to be converted.

Try it. Run this program, then change one value at a time:

print("CS 160")
print(160)
print(3.5)
print(True)

print(type("CS 160"))
print(type(160))

The type() function reports the type of a value. Its result is then handed to print(). This is a function call nested inside another function call: Python finds the inner result first.

Variables give values useful names

A variable is a name that refers to a value. The statement below assigns the value 12 to the name cupcakes:

cupcakes = 12
print(cupcakes)

The equals sign is the assignment operator. Read it from right to left: “take the value 12 and store it under the name cupcakes.” It is not asking whether two things are equal. Python uses == for that question; we will use it in Unit 4.

Programs change state

The collection of values currently stored in a program is its state. Assignment changes that state. Trace this program one line at a time:

score = 10
print(score)
score = score + 5
print(score)
score = 2
print(score)
After lineValue of scoreOutput so far
score = 1010nothing
first print1010
score = score + 51510
second print1510, then 15
score = 2210, then 15
third print210, then 15, then 2

In score = score + 5, Python first looks up the old value on the right, adds 5, and then stores the new value back under the same name. The shorter statement score += 5 has the same effect. Reassignment does not keep a secret history; unless we stored the old value somewhere else, it has been replaced.

Names are part of the explanation

Python variable names may contain letters, digits, and underscores, but cannot begin with a digit. Names are case-sensitive, so total and Total are different. Python programmers normally use lowercase words separated by underscores:

distance_miles = 12.5
travel_time_minutes = 35
route_name = "Green line"
wheelchair_accessible = True

These names do more than satisfy Python. They tell another person what the values mean. Compare d = 12.5 with distance_miles = 12.5. The second name records the unit, which helps prevent a miles-versus-kilometers mistake.

Naming is also a social choice. Names such as person, member, or account can keep code general; a name built around an unnecessary assumption can quietly make some users seem like exceptions. Clear code makes its categories visible enough to question.

Strings can be combined

The + operator adds numbers, but with strings it joins text, an operation called concatenation:

first = "Ada"
last = "Lovelace"
full_name = first + " " + last
print(full_name)

Python does not automatically join a string and a number with +. That refusal is useful: it makes us say whether 3 should be treated as a number or as the character "3". In the next lesson, f-strings will give us an easier way to place different types into a message.
