Variables: storing data

Programs are mostly about data - holding onto pieces of information and doing things with them. A variable is a name that refers to a value stored in the computer's memory. You create one with an assignment statement:

age = 30

This makes a variable named age and stores the number 30 in it. A few rules for naming variables:

  • Use only letters, digits, and the underscore _ (no spaces).
  • Don't start with a digit.
  • For names with more than one word, separate the words with underscores: num_students, pay_rate. Python programmers call this style snake_case (really!), and it's what we'll use in this class. You'll sometimes see other styles in the wild - like capitalizing the later words, numStudents, called "camel case" - but Python's convention is underscores.

The = sign is not "equals"

This trips up almost everyone at first: in programming, = does not mean "is equal to." It's the assignment operator - an instruction to store the value on the right into the variable on the left.

A shortcut: assignment operators

Very often you want to update a variable using its own current value, like adding to a running total:

num = num * 2

Python gives you shorthand for this pattern - num *= 2 means exactly the same thing. Here are the common ones:

Assignment Operators
Operator Example Meaning
=x = yStore a copy of y into x
+=x += yx = x + y
-=x -= yx = x - y
*=x *= yx = x * y
/=x /= yx = x / y

Data types: the kinds of data

Every value in Python has a type. The three you'll meet first:

  • int - a whole number, no decimal point: 30, -7, 0
  • float - a number with a decimal point: 3.14, 0.0755, 14.5
  • str (a "string") - text, wrapped in quotes: 'Hello', "Dahlia"

When you're working with floats - especially money - you usually don't want to show every decimal place. The format() function lets you control how many decimals are displayed (it rounds, it doesn't just chop):

def main():
    rate = .0755
    weight = 14.5678

    print('rate:', format(rate, '.2f'))
    print('weight:', format(weight, '.3f'))

main()

Strings

A string is a series of characters inside quotes - single or double, your choice ('Hello' and "Hello" are the same). You can join strings together with +, which is called concatenation:

first_name = "Julie"
last_name = 'Green'
full_name = first_name + " " + last_name

String Data Types

Bug Alert: A number and a string can look identical but are stored completely differently:

x = 2.3  # a float (a numeric value)
y = "2.3" # a string: the characters 2, ., and 3
z = "4"   # a string with the character 4, not the number 4

This matters because + behaves differently depending on type: with numbers it adds, with strings it joins. And you can't mix the two - if you try to glue a number directly onto a string, Python stops you. Predict what this program does, then run it:

Because num1 and num2 are strings, + glued them into "2.33.4" instead of adding them. To put a number inside a string message, convert it first with str():

message = first_name + ' is ' + str(age) + ' years old!'

Bug Alert: Trying to concatenate a number onto a string without converting it gives you a TypeError: can only concatenate str (not "int") to str. When you see that error, look for a number that needs a str() around it.
