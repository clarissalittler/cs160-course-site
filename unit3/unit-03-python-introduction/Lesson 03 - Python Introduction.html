Hello World!

Traditionally, the first program is a simple one - printing 'Hello, World!' to the console window. 

Run the program below and see what happens! Copy it directly from below (Or download the hello.py file) and run in your IDE of choice.

def main():
  print('Hello, CS160!!')

main()

Now, change the message to print something different - notice your message must be enclosed within the single quotes. Click run. You've just created your first program - congratulations!

Python rules

There are a lot of rules you must follow in Python - spacing and indentation matter! We will go into more details throughout the upcoming lessons, but just know for now, your programs will always have this line at the top:

def main():

Notice this line has NO indentation - it is all the way left-justified, and 

main()

which will go at the end of your program and is also NOT indented! This is a huge frustration for students learning to code. Remember to NOT indent these lines and remember to indent all of the statements under the def main(): line!
