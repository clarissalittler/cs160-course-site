Unit 3 Overview

In this unit, you will learn how to write your own programs - the instructions a computer follows to store and manipulate digital information. You'll start by planning a solution as an algorithm, then express it in a language the computer understands: Python. From there you'll learn to perform input, output, and calculations, organize your code into your own reusable functions, and - just as importantly - read and fix the error messages every programmer runs into along the way.

Learning objectives

At the end of this learning module, you will be able to:

  1. Develop an algorithm to solve a problem. 
  2. Create a Python program using input, output, and computational processes. 
  3. Explain how variables are used to store information. 
  4. Write your own functions using parameters and return values. 
  5. Read Python error messages and debug common mistakes. 
  6. Develop a program using pair programming. 

Learning activities

You are expected to do the following tasks to achieve the above objectives:

  1. Setting up a Python Interpreter (LO 2)
  2. Complete Lessons 1 - 7 and Python Practice Problems (LOs 1-6)
  3. Complete Quiz 3 (LOs 1, 2, 3)
  4. Complete and submit Week 3 Assignment (LOs 1-4)
  5. Complete and share the Week 3 Activity Discussion: Mad Libs Generator
