Unit 3 Overview - Introduction to Programming

The world runs on code, whether written by people or by machines, and this is the unit where we start trying to understand how code itself works! We'll be specifically using the Python language because it's one of the most popular languages in the world and, thankfully, is also pretty easy to pick up.

Everything can be done in a browser, so this unit doesn't require installing software or having administrator access to a computer. See Setting Up a Python Interpreter for workspace options, and save a plain .py copy or notebook copy of any work you want to keep.

Learning objectives

By the end of this unit, you'll be able to:

  1. Plan and test a small algorithm using inputs, processing, storage, and outputs.
  2. Run, modify, and explain a sequential Python program.
  3. Use variables, basic data types, input, conversion, arithmetic, and f-strings.
  4. Read common Python errors and use expected results to find logic errors.
  5. Use a for loop and range() to create counted repetition.
  6. Explain at least one human assumption or accessibility choice built into a program.

Five-lesson path

  1. Make Something Happen: run a program immediately, then connect source code to algorithms, interpreters, sequence, and testing.
  2. Values, Variables, and Types: name data and trace how a program's state changes.
  3. Input, Output, and Strings: make programs interactive and make their prompts and results understandable.
  4. Calculations and Debugging: compute with clear units and assumptions, read tracebacks, and test known answers.
  5. Repetition with for and range: use a small counted loop to generate a pattern without copying code.

Learning activities and assessment

  1. Complete Lessons 1–5 and the Python Practice Problems.
  2. Complete Unit 3 Quiz.
  3. Complete one Week 3 creative-programming route: the ColabTurtle drawing or a text-first mini-zine/pattern-poem notebook. You can choose which one to do, they're of equal difficulty and value!
  4. Complete and share the Week 3 Activity Discussion: Mad Libs Generator.

The Week 3 assignment asks you to make an original artifact with sequence, named values, and a counted loop. Graphical work should include a short written description or command log; text-first work includes sample output. Either route is available for access reasons or plain personal preference.
