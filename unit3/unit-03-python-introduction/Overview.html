Unit 3 Overview

In this unit, you will learn how to write your own programs - the instructions the computer executes to store and manipulate the digital information in a computer. You will first learn how to solve a problem using an algorithm, and then express the solution in a language the computer can understand, Python. Next, you will learn how to perform input, output, and calculations in your programs. Finally, you will also learn about the software development life cycle to design, code, and test a program.

Learning objectives

At the end of this learning module, you will be able to:

  1. Develop an algorithm to solve a problem. 
  2. Create a Python program using input, output, and computational processes. 
  3. Explain how variables are used to store information. 
  4. Make use of the Software Development Life Cycle to design, code, and test a program. 
  5. Develop a program using pair programming. 

Learning activities

You are expected to do the following tasks to achieve the above objectives:

    1. Setting up a Python Interpreter (LO 2)
    2. Complete Lessons 1 - 11 and Python Practice Problems (LOs 1-5)
    3. Complete Quiz 3 (LOs 1, 2, 3)
    4. Complete and submit Assignment 1 (LOs 1-4)
    5. (Individual) Post to discussion Unit 3 Lesson 1 - Legos (LO 1)
    6. (Partner) Post to Unit 3 Lesson 9 - Tax Rate Program (LOs 1-5)

    If you have questions, you can post them in the Course Lobby or send your instructor an email.
