Small Weird Project — Automating Photos in GIMP

What you'll do: Use Python with GIMP 3 to automate part of an image-editing workflow. You'll see that the Python you've been learning can control a real application instead of just printing text to a terminal.

This project is NOT graded. It's just for fun and exploration. There's nothing to turn in. If you try it and it's cool, great. If you skip it, that's fine too.

Important: This page is written for GIMP 3.x. A lot of older tutorials online were written for GIMP 2.x and use code like pdb.gimp_... or gimp.image_list(). Those examples are about an older API and often need changes before they work in current GIMP.

Why This Project Looks Different Now

Older versions of GIMP encouraged a lot of quick one-off scripting through short Python-Fu snippets. Current GIMP still has a Python-Fu console, but the menu path and the generated code style changed in GIMP 3.

So the most reliable beginner workflow now is:

  • Use the Python-Fu console to prove that Python can talk to GIMP.
  • Use the console's Browse button to let GIMP generate current procedure calls for you.
  • If you want something reusable, turn it into a tiny Python 3 plug-in.

What You'll Need

  • GIMP 3.x — a free, open-source image editor. Works on Windows, Mac, and Linux. Download it at gimp.org.
  • Any photo — something from your phone, a picture of your dog, a landscape, whatever. It doesn't matter what it is.
  • A plain-text editor if you want to try the plug-in part.

Part 1: Quick Console Experiment

1. Open GIMP and load a photo

Open GIMP and then open any photo (File → Open). Something colorful works best — you'll be able to see the effects more clearly.

2. Open the Python-Fu console

In GIMP 3, the menu path is Filters → Development → Python-Fu → Console. A new window will pop up with a Python prompt (>>>).

This is still a real Python interpreter, but in current GIMP it is better to think of it as a testing and exploration tool, not as the only way to automate the program.

3. Prove that Python is running

Type this into the console:

print("hello from GIMP")

If you see output, you've already demonstrated something important: Python code can run from inside a real image editor.

4. Let GIMP generate the procedure call

Click the Browse button in the Python-Fu console. This opens the procedure browser. When you click Apply on a procedure, GIMP pastes a Python command into the console for you.

Start with something simple: search for gimp-image-new, click it, then click Apply. GIMP will paste a command block into the console. Replace the placeholder values with real ones, for example:

config.set_property('width', 400)
config.set_property('height', 300)
config.set_property('type', Gimp.ImageBaseType.RGB)

Then press Enter to run it. That isn't photo editing yet, but it proves that the procedure browser is generating current GIMP 3 syntax for you.

5. Try a real image operation

Now use the same Browse button to search for operations such as brightness-contrast, desaturate, invert, or equalize. Let GIMP paste the current command, then fill in the parameter values it asks for.

This is the main idea: you do not need to memorize GIMP's internal API. Let the browser generate the current call, then change the numbers and run it.

Part 2: A Tiny Python 3 Plug-in

The console is good for experimenting. A plug-in is better if you want a command that keeps showing up in GIMP's menus.

1. Save this script as cs160-boost-contrast.py

#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import gi
gi.require_version('Gimp', '3.0')
from gi.repository import Gimp
from gi.repository import GLib
import sys

PROC_NAME = "plug-in-cs160-boost-contrast"

def boost_contrast_run(procedure, run_mode, image, drawables, config, data):
    if len(drawables) != 1:
        return procedure.new_return_values(
            Gimp.PDBStatusType.CALLING_ERROR,
            GLib.Error("Select exactly one layer before running this plug-in.")
        )

    drawable = drawables[0]

    image.undo_group_start()
    drawable.brightness_contrast(0.25, 0.20)
    drawable.update(0, 0, drawable.get_width(), drawable.get_height())
    image.undo_group_end()

    return procedure.new_return_values(Gimp.PDBStatusType.SUCCESS, None)

class CS160BoostContrast(Gimp.PlugIn):
    def do_query_procedures(self):
        return [PROC_NAME]

    def do_create_procedure(self, name):
        procedure = Gimp.ImageProcedure.new(
            self,
            name,
            Gimp.PDBProcType.PLUGIN,
            boost_contrast_run,
            None,
        )
        procedure.set_image_types("*")
        procedure.set_sensitivity_mask(Gimp.ProcedureSensitivityMask.DRAWABLE)
        procedure.set_menu_label("_CS160 Boost Contrast")
        procedure.set_documentation(
            "Boost brightness and contrast on the selected layer.",
            "Small classroom demo plug-in for GIMP 3.",
            None,
        )
        procedure.set_attribution("CS 160", "CS 160", "2026")
        procedure.add_menu_path("<Image>/Filters/Development/CS160")
        return procedure

Gimp.main(CS160BoostContrast.__gtype__, sys.argv)

2. Install it in GIMP's plug-ins/ folder

Current GIMP plug-ins are installed by putting the Python file inside a folder with the same base name in your plug-ins/ directory. So create a folder named cs160-boost-contrast and put cs160-boost-contrast.py inside it.

On macOS and Linux, you may also need to make the file executable:

chmod u+x cs160-boost-contrast.py

3. Restart GIMP

GIMP discovers new plug-ins when it starts. If the plug-in does not appear, double-check that the folder name and the Python filename match exactly.

4. Run it

Open a photo, select a layer, then go to Filters → Development → CS160 → CS160 Boost Contrast.

The plug-in uses the current GIMP 3 API to modify the selected layer with one method call:

drawable.brightness_contrast(0.25, 0.20)

In the current API, both values are between -1.0 and 1.0. Try changing them, saving the file, and restarting GIMP.

Experiment!

Try this:

  • Change the brightness/contrast values in the plug-in and see how the result changes.
  • Replace brightness_contrast() with another current GIMP 3 drawable method such as invert(False), desaturate(Gimp.DesaturateMode.LIGHTNESS), or equalize(False).
  • Use the Python-Fu console's Browse button to discover procedure names and argument names before you edit the plug-in.
  • Imagine what this would look like with a loop over 200 photos. You haven't learned loops yet, but this is where programming becomes genuinely useful.

What You Just Demonstrated

You just used variables, function calls, arguments, and numeric values — the same ideas from the past few lessons — to control a real application.

  • The Python-Fu console still exists in GIMP 3, but the menu path and generated code style changed.
  • Modern GIMP automation uses Python 3 and the GIMP 3 API.
  • Many older tutorials are not wrong exactly; they are just written for an older version of the software.

Programming isn't just about printing numbers to a terminal. It's a tool for controlling other software, automating repetitive tasks, and doing in seconds what would take hours by hand. The syntax you're learning right now is the foundation for all of that.
