Unit 3 Summary

Wrap up

In this unit, you learned how to design and develop programs to tell the computer what actions to perform. When we want to write a program, we must first plan out our algorithms (step by step instructions) using pseudocode and then convert to a language the computer can understand - Python. You wrote your first Python program, using input, output, and computations, and stored information in variables - locations in memory.

Summary

  • An algorithm is a step-by-step process for solving a problem.
  • It is important to design your program before you code.
  • Python is the programming language we will use in this course.
  • Data is stored in variables. 
  • The assignment operator = stores data into variables.
  • Different types of data include integers, floats (decimal numbers), and strings.
  • The print() function is used to display output in a program.
  • The input() function is used to collect input from a user. All input is read in as a string of characters. To convert the string of characters to a number, use the int() or float() functions.
  • Remember to store the data from the input() statement into a variable.
  • Modulus % is an operator which returns the remainder after performing division.
  • Constants are variables that do not change during the execution of a program.
  • The Software Development Life Cycle is used to create software.
