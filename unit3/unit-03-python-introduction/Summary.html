Unit 3 Summary

We started this unit by making Python do something and then worked backwards to understand what we'd done. Here's the shape of it: a program is an algorithm written down as source code, and the interpreter runs that code from top to bottom. Variables give values names so we can hold on to them. Input lets one run differ from the next. Expressions turn old values into new ones, output tells a person what happened, and a for loop lets us say "do this four times" instead of pasting the same line four times.

What to carry forward

  • An algorithm is a precise sequence of steps. Writing it out as pseudocode first lets you check the plan before you have to worry about syntax.
  • print(), input(), int(), float(), and range() are functions Python already knows. Writing a name with parentheses after it calls the function.
  • The assignment operator = is a command, not an equation: it stores the value on its right under the name on its left.
  • The basic types are str, int, float, and bool. Quotation marks are what make something a string.
  • input() always gives back a string. Convert number-shaped text with int() or float() before doing arithmetic with it.
  • F-strings put values and expressions into readable messages: f"Total: ${total:.2f}".
  • Arithmetic includes + - * / // % **. Parentheses, named constants, descriptive names, and units are how you show a reader what you meant.
  • Read a traceback's last line first, find the line in your code it points at, change one thing, and run again.
  • A logic error gives a wrong answer without stopping the program. The only way to catch one is a test whose expected result you wrote down ahead of time, boundary cases included.
  • for item in range(...): repeats an indented body. The stop value is never included, and the loop variable takes a new value on each iteration.
  • Every program is built out of human choices about what to collect, calculate, label, automate, and say, like whether the meal-splitting program includes the tip, or what happens when 0 people are splitting the bill.

Can you explain these programs?

distance_miles = float(input("Trip distance in miles: "))
travel_time_hours = distance_miles / 12
print(f"Estimated cycling time: {travel_time_hours:.1f} hours")

Identify the input, conversion, stored values, calculation, unit assumption, and output. What test would reveal whether 12 miles per hour is a reasonable estimate for the intended users?

for line_number in range(1, 4):
    print(f"Line {line_number}: we make the web together.")

List the three values of line_number, predict the complete output, and explain which punctuation marks define the loop.
