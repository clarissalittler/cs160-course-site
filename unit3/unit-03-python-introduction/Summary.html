Unit 3 Summary

You began this unit by making Python do something, then developed the ideas needed to make that action understandable and changeable. A program expresses an algorithm in source code. The interpreter executes that code, normally from top to bottom. Variables name values; input lets one run differ from the next; expressions transform data; output communicates a result; and a counted loop makes repetition explicit.

What to carry forward

  • An algorithm is a precise sequence of steps. Pseudocode makes the plan inspectable before syntax gets in the way.
  • print(), input(), int(), float(), and range() are functions Python already knows. Writing a name with parentheses calls a function.
  • The assignment operator = stores the value from its right side under the name on its left side.
  • Common types include str, int, float, and bool. Quotation marks turn characters into a string.
  • input() returns a string. Convert number-shaped text before arithmetic.
  • F-strings place values and expressions into readable messages: f"Total: ${total:.2f}".
  • Arithmetic includes + - * / // % **. Parentheses, named constants, descriptive names, and units make the intended model visible.
  • Read a traceback's last line first, find the relevant line in your code, form one hypothesis, change one thing, and run again.
  • A logic error produces the wrong result without stopping. Tests need expected outcomes, including boundaries.
  • for item in range(...): repeats an indented body. The stop value is excluded, and the loop variable changes each iteration.
  • Programs embody human choices about what to collect, calculate, label, automate, and communicate. Correct code can still encode a poor assumption.

Can you explain these programs?

distance_miles = float(input("Trip distance in miles: "))
travel_time_hours = distance_miles / 12
print(f"Estimated cycling time: {travel_time_hours:.1f} hours")

Identify the input, conversion, stored values, calculation, unit assumption, and output. What test would reveal whether 12 miles per hour is a reasonable estimate for the intended users?

for line_number in range(1, 4):
    print(f"Line {line_number}: we make the web together.")

List the three values of line_number, predict the complete output, and explain which punctuation marks define the loop.
