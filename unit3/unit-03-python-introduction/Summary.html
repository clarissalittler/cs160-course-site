Unit 3 Summary

Wrap up

In this unit, you learned how to design and develop programs to tell the computer what actions to perform. When we want to write a program, we must first plan out our algorithms (step by step instructions) using pseudocode and then convert to a language the computer can understand - Python. You wrote your first Python program, using input, output, and computations, and stored information in variables - locations in memory.

Summary

  • An algorithm is a step-by-step process for solving a problem, and it's worth planning one out (in pseudocode) before you code.
  • Python is the programming language we will use in this course.
  • Data is stored in variables; the assignment operator = stores a value into a variable.
  • Different types of data include integers, floats (decimal numbers), and strings.
  • The print() function displays output, and f-strings (f"...{variable}...") are a clean way to build output messages.
  • The input() function collects input from a user. All input is read in as a string of characters, so convert it to a number with int() or float() when needed - and remember to store the result in a variable.
  • Math operators include + - * / // % and **. Integer division // keeps only the whole number, and modulus % returns the remainder after division.
  • Constants are variables (written in ALL_CAPS) whose values should not change while the program runs.
  • A function lets you name and reuse a chunk of code: you define one with def and run it by calling its name.
  • Functions can take information in through parameters and hand a result back with return.
