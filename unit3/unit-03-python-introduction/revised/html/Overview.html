Unit 3 Overview

In this unit, we're getting to the good stuff — you're going to learn how to write your own programs. These are the actual instructions a computer follows to store, move, and manipulate digital information. We'll start from the very beginning: figuring out how to solve a problem using an algorithm, then expressing that solution in a language the computer actually understands — Python.

From there, you'll learn how to get input from a user, do calculations, and display output. You'll also learn about the Software Development Life Cycle, which is a fancy way of saying "the process professionals use to design, write, and test their programs." And you'll get to try pair programming — writing code with a partner, which is honestly how a lot of real software gets built.

After this lesson, you'll be able to:

  1. Develop an algorithm to solve a problem.
  2. Create a Python program that handles input, output, and computation.
  3. Explain how variables are used to store information.
  4. Use the Software Development Life Cycle to design, code, and test a program.
  5. Develop a program using pair programming.
