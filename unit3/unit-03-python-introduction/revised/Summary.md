# Unit 3 Summary

## Wrap Up

In this unit, we learned how to design and develop programs that tell the computer what to do. When we want to write a program, we first plan out our algorithms (step-by-step instructions) using pseudocode, then convert them into a language the computer understands --- Python.

You wrote your first Python programs using input, output, and computations, and stored information in variables --- named locations in memory.

## Key Takeaways

- An **algorithm** is a step-by-step process for solving a problem.
- It's important to **design your program before you code**. Planning first saves debugging later.
- **Python** is the programming language we're using in this course.
- Data is stored in **variables**.
- The **assignment operator** `=` stores data into variables.
- Different **data types** include integers, floats (decimal numbers), and strings.
- The **`print()` function** displays output in a program.
- The **`input()` function** collects input from a user. All input is read in as a string of characters --- to convert it to a number, use `int()` or `float()`.
- Don't forget to **store the data** from `input()` into a variable! (It won't save itself.)
- **Modulus `%`** is an operator that returns the remainder after performing division.
- **Constants** are variables that don't change during the execution of a program. By convention, we write them in ALL_CAPS.
- The **Software Development Life Cycle** (design, code, test, release) is the process used to create software.
