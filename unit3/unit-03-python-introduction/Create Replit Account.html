Setting Up a Python Interpreter

What's an interpreter?

The only way to learn how to code is to code! Coding can be difficult at first, but the more you practice, the easier it will become.

To write Python programs, you will need to use an interpreter: a program that reads code, understands what the code means, and then runs the code.

There are several interpreters we recommend!

In terms of entirely online options there are:

  • Online GDB which can run many different languages, not just Python, and has the easy ability to save and share your projects if you make an account. The downside is that there are ads.

In terms of offline options you can install there are:

  • IDLE, which comes with your download of Python
  • PyCharm, which is a more fully featured development environment described below

PyCharm

There are some accessibility issues with Replit if you are using a screen reader and Replit's free usage is limited to 60 hours per month, which is enough for getting started but probably not enough to work on homework seriously. So our current recommendation is to install the Community Edition of a development environment called PyCharm, which is free to download and use. Make sure to scroll down and download the version labeled PyCharm Community Edition.

If you want to program while offline, downloading and using PyCharm is a good option. The main disadvantage that it has is that it is offline and you need to make sure to upload into and download from your file storage of choice (Google Drive, Dropbox, your email inbox) in order to keep your work safe.
