Input

In this course, you will be writing programs to read input typed by the user on the keyboard. Python has a function input() to do this. When a program reads data from the keyboard, usually it stores that data in a variable so it can be used later by the program. 

One statement can be written to: 

  • prompt the user for input
  • read in the input
  • store the input into a variable

It is important to note, that any input read from the keyboard is read in as a string data type. The format for this statement will be:

variable = input(prompt)

Bug Alert:

New programmers sometimes forget to assign the user input returned from the input() function into a variable! You must remember to put it somewhere!

For example, when the following statement is executed:

name = input("Enter your name: ")

these three things happen:

  • the string "Enter your name:" is displayed on the screen
  • the program pauses and waits for the user to type something on the keyboard and end the input by pressing the Enter key
  • when the Enter key is pressed, the user input is returned as a string and assigned to the variable name

String input

Sometimes we want to compare string input later on in our programs. For example, maybe we want to test if the user entered the word Portland  - and we want to match on all cases of input: Portland, portland, PORTland, etc.

To do this, we can convert the input to all UPPER or lower case and then do a comparison.

city = input("Enter the city you live in: ")
city = city.upper() # converts string to all UPPERCASE and
                    # stores result back into city variable
city = city.lower() # converts string to all lowercase and
                    # stores result back into city variable

Numeric input

If all user input is read in as a string, how do we read in numeric data? We can convert the strings to numbers using the int() and float() functions after the data is read in and before it is assigned to the variable.

quantity = int(input('Enter the quantity: '))
cost = float(input('Enter the cost: $: '))

Tip: Python will almost always want the same number of left parentheses ( as right parentheses ) .
