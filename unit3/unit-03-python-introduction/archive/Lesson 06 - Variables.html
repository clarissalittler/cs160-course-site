Variables

Programs usually store data in the computer’s memory and perform operations on that data. Programs use variables to access and manipulate data that is stored in memory. A variable is a name that represents a value in the computer’s memory.

You use an assignment statement to create a variable and make it hold a piece of data. Here is an example of an assignment statement:

age = 30

This statement creates a variable named age and assigns the integer literal 30 to it. When you put a new value into a variable, the old value is not there - it is gone forever! There are rules to follow when creating variable names:

  • Only a-z, A-Z, 0-9, and the underscore character is allowed
  • Variables start with a lowercase letter and if the name contains more than one word, start the word with an uppercase letter, or separate words with an underscore _ :
    • num_students
    • numStudents

Hand tracing

Hand tracing is a simulation of code execution in which you step through instructions and track the values of the variables. When you hand trace code or pseudocode, you write the names of the variables on a sheet of paper, mentally execute each step of the code and update the variables.

Important! Research shows that learning how to hand trace (also called code tracing) is one of the biggest indicators of becoming a successful programmer. Hand tracing helps you learn the syntax (the rules of the language) and semantics (what the rules mean) at a deeper level of understanding. Do not attempt to hand trace in your head, instead, take the time to hand trace your code, line by line, on a piece of paper!

Assignment operators

Often, we want to perform a calculation on a variable and store the result back into the same variable:  

num = num * 2

We can shorten the syntax of the statement by using assignment operators:  

num *= 2

The table below lists the different assignment operators and their usage:

Assignment Operators
Operator Example Meaning
= x = y Simple assignment - a copy of the contents in y is stored into the variable x
+= x += y x = x + y 
-= x -= y x = x - y
*= x *= y x = x * y
/= x /= y x = x / y
//= x //= y x = x // y
%= x %= y x = x % y
