Pseudocode

In the previous lesson, you learned how to write an algorithm for solving a problem. The next step is to express this algorithm in a language a computer can understand. But before you write one line of code in any language, let's talk more about the importance of planning out the algorithms in your programs using pseudocode. Use pseudocode in the same way you would create and use an outline before writing a paper.

Pseudocode is a simple way of writing programming code in English. Pseudocode is not an actual programming language. It uses short phrases to write code for programs before you actually create it in a specific language. Once you know what the program is about and how it will function, then you can use pseudocode to create statements to achieve the required results for your program.

Understanding Pseudocode

Pseudocode makes creating programs easier. Programs can be complex and long and preparation is the key. 

To use pseudocode, all you do is write what you want your program to say in English. Pseudocode allows you to translate your statements into any language because there are no special commands and it is not standardized. Writing out programs before you code can enable you to better organize and see where you may have left out needed parts in your programs. All you have to do is write it out in your own words in short statements. Let's look at some examples.

Important! Don't skip this step when writing programs. Read the problem and think about how you would explain to someone how to solve it. Don't worry about how to phrase your steps, just make sure they are detailed enough so that someone could follow them to solve the problem. Like a recipe to make cookies!

Examples of Pseudocode

Let's look at an example to create a program to add 2 numbers together and then display the result:

Input two numbers, A, B
Compute sum = A + B
Print sum

Here is the pseudocode to compute the area of a rectangle (Note: The asterisk symbol * is commonly used to mean multiplication):

Input the length 
Input the width 
Compute area = length * width
Display area

Now, let's look at an example of pseudocode to compute the perimeter of a rectangle:

Input length 
Input width 
Compute perimeter = (2 * length) + (2 * width)
Display perimeter

Remember, writing basic pseudocode is not like writing an actual coding language. It cannot be compiled or run like a regular program. Pseudocode can be written how you want. But some companies use specific pseudocode syntax to keep everyone in the company on the same page. Syntax is a set of rules on how to use and organize statements in a programming language. By adhering to specific syntax, everyone in the company can read and understand the flow of a program. This means that more people can study the algorithm, and errors will be easier to find and correct.

In the next lesson, you will be introduced to the programming language Python, which we will be using in this course. Python has a very specific set of syntax rules that MUST be followed for the computer to understand and execute your program.
