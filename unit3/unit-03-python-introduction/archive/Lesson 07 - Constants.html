Lesson 9 - Constants

At the end of this lesson, you will be able to:

  • Declare and use constants in your programs.

Constants

A named constant is a variable that represents a value that cannot be changed during the program's execution. A magic number is an unexplained numeric value that appears in a program’s code. Example:

amount = balance * 0.075

What is the value 0.075? An interest rate? A fee percentage? Only the person who wrote the code knows for sure.

You should use named constants instead of magic numbers. Example:

INTEREST_RATE = 0.075

This creates a named constant named INTEREST_RATE, assigned the value 0.075. It can be used instead of the magic number:

amount = balance * INTEREST_RATE

Constants will always be created outside of any functions - with no indentation - so all functions have access.

Run this program as an example (copy and paste from below or download the constants.py and run in your IDE of choice). TAX_RATE is a constant:

TAX_RATE = 0.0875

def main():
    cost = 10.24
    tax = cost * TAX_RATE
    total = cost + tax

    print('Cost: $', cost)
    print('Tax: $', tax)
    print('Total: $', total)

main()

Notice that constants will be declared using all UPPERCASE letters, like TAX_RATE. When you run the program what do you notice about the output? Money should always be formatted to display only 2 decimals!
