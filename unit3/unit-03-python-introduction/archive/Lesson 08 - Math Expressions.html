Operators

Most of the algorithms you write will involve calculations. The table below lists some of the Python math operators that can be used to perform mathematical calculations.

Math Operators
Symbol Operation Description
+ Addition Adds two numbers.
- Subtraction Subtracts one number from another.
* Multiplication Multiplies one number by another.
/ Division Divides one number by another, the result is a floating point number.
// Integer Division Divides one number by another, the result is a whole number. The decimal portion is truncated, not rounded.
% Remainder (Modulus) Divides one number by another and gives the remainder.
** Exponent Raises a number to a power.

You will use these math operators to create math expressions. A math expression performs a calculation and gives a value. The following is an example of a simple math expression:

12 + 3

The values on the right and left sides of the + operator are called operands. These are the values the + operator adds together.

Variables may also be used in math expressions:

hours = 40
payRate = 25.35
totalPay = hours * payRate

In the code above, hours * payRate is a math expression, and the result is stored in the variable totalPay.

Floating point and integer division

Python has two different division operators, / and //, which behave differently.

5 / 2 results in 2.5. The / operator performs floating point division.

5 // 2 results in 2. The // operator performs integer division. When integer division is performed, it is truncated, which means any fractional part is thrown away.

Change the values for num1 and num2 in the program below (copy from below or download the division.py and run in your IDE of choice) to see how the operators behave. Write down the difference between / and // in your notebook. What happens when num2 is assigned 0?

def main():
    num1 = 5
    num2 = 3

    print("num1 / num2 :", num1 / num2)
    print("num1 // num2 :", num1 // num2)

main()

Dividing a number by 0 will cause an error when the program is run - dividing by 0 is not allowed!

Order of operations

Operations that are enclosed in parentheses are performed first. Then, when two operators share an operand, the operator with the higher precedence is applied first. The precedence of the math operators, from highest to lowest, are:

  1. Exponentiation: **
  2. Multiplication, division, and remainder: * / // %
  3. Addition and subtraction: + −

Notice the multiplication (*), floating-point division (/), integer division (//), and remainder (%) operators have the same precedence. The addition (+) and subtraction (−) operators also have the same precedence. When two operators with the same precedence share an operand, the operators execute from left to right.

What will be the result of these mathematical expressions?

  1. (5 + 2) * 4
  2. 10 / (5 - 3)
  3. 8 + 12 * (6 - 2)
  4. (6 - 2) * (3 + 8) // 3
Show Solution
  1. 28
  2. 5.0
  3. 56
  4. 14 (Remember, // truncates any decimal portion of the answer)
