Numeric data types

Because different types of numbers are stored and manipulated in different ways, Python uses data types to categorize values in memory. When an integer is stored in memory, it is classified as an int (integer), and when a real number (a number with decimals, i.e. 3.24, -10.23333) is stored in memory, it is classified as a float.

  • A numeric literal that is written as a whole number with no decimal point is considered an int. Examples are 3, 125, and −19.
  • A numeric literal that is written with a decimal point is considered a float. Examples are 1.5, 3.14159, and 5.0.

When printing float types, we can specify the number of decimals to print using the format() function.  Predict what the program will print when executed - do you think format() will round or truncate decimal values? (Copy or download the format.py and run in your IDE of choice.)

def main():
    rate = .0755
    weight = 14.5678
    area = 345.44123

    print('rate:', format(rate, '.2f'))
    print('weight:', format(weight, '.3f'))
    print('area:', format(area, '.1f'))

main()

String data types

In addition to the int and float data types, Python also has a data type named str, which is used for storing strings in memory.

String Data Types


A string is a sequence of characters enclosed in either single ' or double " quotes.

firstName = "Julie"
lastName = 'Green'

You can create strings by combining other strings using the concatenation symbol + . Keep in mind, both operands must be of type string to use concatenation:

fullName = firstName + " " + lastName

Bug Alert: Numeric literals and string literals can look the same when they are printed, but they are stored differently in memory.


x = 2.3 # this is a float numeric type
y = "2.3" # this is a string with the characters 2 and . and 3
z = "4" # this is a string with the character 4, not the numeric value 4
