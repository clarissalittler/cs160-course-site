Setting Up a Python Interpreter

What's an interpreter?

The only way to learn how to code is to code! Coding can be difficult at first, but the more you practice, the easier it will become.

To write Python programs, you will need to use an interpreter: a program that reads code, understands what the code means, and then runs the code.

The good news: you have options, and none of them cost money.

The easy default: Online GDB

For this class, the simplest way to get going is Online GDB - it runs entirely in your web browser, so there's nothing to install and it works the same on a laptop, a library computer, or a lab machine. Just go to the site, choose Python as your language, and start typing. If you make a (free) account, you can save your projects and share them, which makes turning in and getting help with your work much easier.

The main downside? Ads. They're a little annoying, but they're the price of "free and zero setup."

If you're not sure what to pick, pick Online GDB. You can always add an offline option later.

Offline options: IDLE and PyCharm

If you'd rather work on your own machine - or you want to be able to code without an internet connection - you can install Python itself, which comes with a simple built-in editor called IDLE. IDLE is bare-bones but perfectly fine for everything we do in this course.

For something more fully featured, there's the Community Edition of a development environment called PyCharm, which is free to download and use. Make sure to scroll down and download the version labeled PyCharm Community Edition.

One caution about working offline: your files live only on that one computer. Make a habit of backing your work up to your file storage of choice (Google Drive, Dropbox, your email inbox) so a spilled coffee doesn't take your homework with it.
