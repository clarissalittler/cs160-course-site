  1. Input is received.
  2. Some process is performed on the input.
  3. Output is produced.

Comments and Output

Comments in your program

But first, an introduction to comments in Python comments. The output described above and below is for the benefit of whoever uses the program. The output may be friendly messages to the user, or the output may be the result of calculations, or whatever output the program is intended to produce. If you want to include messages in the program to yourself, or for the benefit of the next programmer who looks at your program, you'll add comments to the program.

When a Python program runs and the Python interpreter sees a # character (shift 3 on your keyboard, called the pound sign, the number sign, or the hash character) that isn't in quotes it will ignore that character and anything to the right of it on that line. This allows you, the programmer, to put messages into the program that the user will not see, but someone who is reading the actual program will be able to see.

Here's an example:

# here's an example of a comment in Python
x = 2 # here we are setting the variable x to have the value 2
y = x * x # compute x squared, store the result in y
print(y) # print the value stored in variable y

Comments are frequently used to describe what the program is intended to do, how it is supposed to do it, the programmer's name and the date it was last modified, etc. All of this is helpful to the next programmer (who might be you) to understand how the program works.

print() function

Output in Python is performed using print(). We send information to be displayed to print(), inside the parentheses. You can send multiple items to print(). Each of the items is called an argument.

Example of displaying multiple items:

print('a', 'b', 'c')

Items are displayed separated by a space unless you specify something different.

The program below is an example: name and age are variables - we will talk about variables next! (Copy or download the print_name.py file and run in your IDE of choice.)

def main():
    name = 'Dahlia'
    age = 20

    print('Hello,', name, 'you are', age, 'years old!')

main()

Did you notice the spacing when the sentence was printed? There is not a space after the comma, in the first string 'Hello,' but a space was printed between the comma and the 'S' in 'Stephanie'.  This is how print() works by default. 

Notice each argument is separated by a comma. We can change the default separator to any character we want, even no character. Modify the print statement and add a 6th argument: sep = '' as shown below:

print('Hello,', name, 'you are', age, 'years old!', sep='')

Run the program above. Your output should have problems now! Add extra spaces in the string literals to fix spacing.

Question: What is a character and what is a string literal?

We learned in Unit 1 that characters are stored in the computer as ASCII values. A string literal (or string) is a series of characters enclosed inside either single or double quotes, 'Hello' and "Hello" are both string literals.

Escape characters

An escape character is a special character that is preceded with a backslash (\), appearing inside a string literal. When a string literal that contains escape characters is printed, the escape characters are treated as special commands that are embedded in the string. For example, \n is the newline escape character. When the \n escape character is printed, it isn’t displayed on the screen. Instead, it causes output to advance to the next line. For example, copy and run the following program (Or download the escape_char.py file and run in your IDE of choice.):

def main():
    # \n is the newline escape character
    print('One\nTwo\nThree')

    # \t is the tab escape character
    print('One\t\tTwo\t\tThree')

main()
