Lesson 6 - Parameters and Return Values

At the end of this lesson, you will be able to:

  • Pass information into a function using parameters.
  • Get a result back from a function using return.
  • Explain the difference between printing a value and returning a value.

Functions that take information in

In the last lesson our functions did the exact same thing every time. The greet() function always said the same hello. That's a little rigid. What if we want greet to greet a specific person? We give the function a parameter - a variable, listed in the parentheses, that the function fills in with whatever we hand it when we call it:

def greet(name):
    print(f"Hello there, {name}!")

greet("Dahlia")
greet("Sam")

Now greet is far more useful. The value you put in the parentheses when you call it (like "Dahlia") is the argument; it gets handed to the parameter name inside the function. Same function, different result each time, depending on what you pass in.

A function can take more than one parameter - just separate them with commas. The order matters: the first argument fills the first parameter, and so on.

def introduce(name, age):
    print(f"This is {name}, who is {age} years old.")

introduce("Dahlia", 20)

Functions that hand a result back

Parameters send information into a function. The return statement sends a result back out. This is the move that makes functions genuinely powerful: a function can compute something and hand it back so the rest of your program can use it.

def square(n):
    result = n * n
    return result

answer = square(5)     # square hands back 25; we store it in answer
print(answer)          # 25

Step through it and watch the value travel: the argument 5 goes in as n, the function computes 25, and return hands it back to where the call happened, so it lands in answer.

Because a returned value is just... a value, you can use it anywhere you'd use a number - including in bigger expressions, like square(10) + square(2) in the last line above.

Bug Alert - print vs. return: These are not the same thing, and confusing them is the single most common function mistake. print shows a value on the screen and then it's gone. return hands the value back to your program so you can store it and keep using it. A function that prints its answer can't be used in a calculation; a function that returns its answer can. When in doubt, return the result and let the caller decide whether to print it.

Handing back more than one value

A function isn't limited to one answer - you can return several values by separating them with commas, and unpack them into several variables on the other side:

def min_and_max(a, b):
    if a < b:
        return a, b
    else:
        return b, a

smaller, larger = min_and_max(8, 3)
print(f"smaller: {smaller}, larger: {larger}")   # smaller: 3, larger: 8

That trick - pulling several values apart into several variables in one line - is called unpacking (or "destructuring"), and it's surprisingly handy. We're only getting a taste of it here; it comes back in a big way in Unit 6 when we work with tuples.

Try it! Write a function rectangle_area(length, width) that returns the area (don't print it inside the function!). Then call it, store the result in a variable, and print that variable with an f-string. Bonus: call it a second time with different numbers and add the two areas together.
