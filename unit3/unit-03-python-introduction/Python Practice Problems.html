Unit 3 Python Practice Problems

These problems start with straight-line input–process–output programs and end with one small counted loop. Here's the routine to follow for each one, and it's the same routine you'll use for the rest of the course:

  1. Write a sample run and the expected answer.
  2. Write the algorithm as comments or short pseudocode.
  3. Write and run the program.
  4. Test a normal case and a boundary or unusual case.
  5. Only then peek at the sample solution. Reading the answer first feels productive and teaches you very little.

You don't need def main() in this unit. If you've seen it in other Python code, don't worry about it: we start writing our own functions in Unit 4. For now, write these programs as a plain top-to-bottom sequence, using only the ideas from Lessons 1–5.

1. Profit estimate

A small shop estimates that annual profit will be 27 percent of total sales. Ask for projected sales and display the estimated profit. Label the result and format it as money.

Before you write any code, work out by hand what the profit should be for $1,000 in sales. That's your test case.

Show one solution
PROFIT_MARGIN = 0.27

total_sales = float(input("Projected total sales: $"))
profit = total_sales * PROFIT_MARGIN
print(f"Estimated profit: ${profit:,.2f}")

Putting 27 percent in a named constant means anyone reading the program can see the assumption right at the top. A real business estimate would also say where that number came from and when it should be revisited.

2. Meal, tip, and tax

Ask for the food charge, calculate an 18 percent tip and 7 percent tax, then display the food charge, tip, tax, and total. For this simplified model, both percentages are calculated from the food charge.

Test with a $20 meal: the tip should be $3.60, the tax $1.40, and the total $25.00.

Show one solution
TIP_RATE = 0.18
TAX_RATE = 0.07

food_charge = float(input("Food charge: $"))
tip = food_charge * TIP_RATE
tax = food_charge * TAX_RATE
total = food_charge + tip + tax

print(f"Food: ${food_charge:,.2f}")
print(f"Tip:  ${tip:,.2f}")
print(f"Tax:  ${tax:,.2f}")
print(f"Total: ${total:,.2f}")

3. Recipe scaler

A recipe makes 12 cupcakes from 1.5 cups sugar, 1 cup butter, and 2.75 cups flour. Ask how many cupcakes the user wants, then scale and display each ingredient.

Test 24 cupcakes, 6 cupcakes, and 0 cupcakes. Should your program allow someone to ask for 7.5 cupcakes? That's your call, but make it deliberately, by choosing int or float for the input.

Show one solution
RECIPE_SIZE = 12
SUGAR_CUPS = 1.5
BUTTER_CUPS = 1.0
FLOUR_CUPS = 2.75

desired_cupcakes = int(input("How many cupcakes? "))
scale = desired_cupcakes / RECIPE_SIZE

print(f"For {desired_cupcakes} cupcakes:")
print(f"Sugar: {SUGAR_CUPS * scale:.2f} cups")
print(f"Butter: {BUTTER_CUPS * scale:.2f} cups")
print(f"Flour: {FLOUR_CUPS * scale:.2f} cups")

4. Numbered community announcement

Ask for an event name and the number of reminder messages to create. Use a for loop to print numbered reminders from 1 through that number.

For the event Repair café with 3 reminders, the lines should be numbered 1, 2, and 3. Not 0, 1, and 2! Remember what range() does by default.

Show one solution
event_name = input("Event name: ")
reminder_count = int(input("How many reminders? "))

for number in range(1, reminder_count + 1):
    print(f"Reminder {number}: {event_name} is coming up!")

The + 1 is there because the stop value is never included. Test 1, 3, and 0 reminders. With 0 the loop body never runs at all and nothing prints, which might be exactly right or might be a case a bigger program would want to say something about.

5. Five-day running total

A neighborhood garden records the number of pounds harvested on each of five days. Use a for loop to ask for each day's amount, keep a running total, and display the total after the loop.

Show one solution
total_pounds = 0.0

for day in range(1, 6):
    pounds = float(input(f"Pounds harvested on day {day}: "))
    total_pounds += pounds

print(f"Five-day harvest: {total_pounds:.1f} pounds")

Same accumulator pattern as Lesson 5: set total_pounds up once before the loop, add to it inside the loop, and print it once afterward.
