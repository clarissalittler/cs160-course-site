Lesson 12 - Working with Strings

At the end of this lesson, you will be able to:

  • Access individual characters and substrings using indexing and slicing.
  • Use string methods to manipulate text — .upper(), .lower(), .strip(), .replace(), .split(), &c.
  • Format strings using f-strings.
  • Combine strings using concatenation and joining.

Strings Are More Than Just Text

You've already been using strings — every time you've put text in quotes, that's a string. You've printed them, stored them in variables, and even concatenated a couple together. But strings in Python can do way more than just sit there. They come with a whole toolkit of built-in methods that let you search through text, change capitalization, chop strings apart, and put them back together again.

Let's dig into that toolkit.

String Indexing

Here's something that might surprise you: strings are sequences. Each character in a string has a position — called an index — and Python starts counting at 0, not 1. So the first character is at index 0, the second is at index 1, and so on.

Think of it like a row of mailboxes, each with a number on it:

# The string "Portland" and its indices:
#  P  o  r  t  l  a  n  d
#  0  1  2  3  4  5  6  7

You access a character by putting the index in square brackets:

name = "Portland"
print(name[0])    # P
print(name[4])    # l
print(name[7])    # d

Python also lets you count backwards from the end using negative indices. -1 is the last character, -2 is the second-to-last, &c.

name = "Portland"
print(name[-1])   # d
print(name[-3])   # a
print(name[-8])   # P

Try it! Create a variable with your own name and use indexing to print the first letter and the last letter. Then try this: what happens if you try to access an index that's too big — like name[50]? Give it a shot and read the error message. It's a good one to recognize.

String Slicing

Indexing grabs one character. Slicing lets you grab a whole chunk. The syntax is string[start:end], where start is included and end is not included. (Yeah, that trips everyone up at first — you get used to it.)

name = "Portland"
print(name[0:4])   # Port
print(name[4:8])   # land
print(name[2:5])   # rtl

You can also leave out the start or the end to slice from the beginning or to the end:

name = "Portland"
print(name[:4])    # Port  (from the start up to index 4)
print(name[4:])    # land  (from index 4 to the end)
print(name[:])     # Portland  (a copy of the whole string)

There's even a third number you can add — the step. name[::2] grabs every other character:

name = "Portland"
print(name[::2])   # Prln
print(name[::-1])  # dnaltroP  (reversed!)

Try it! Store your full name in a variable. Can you slice it to get just the first three letters? What about just the last four? Try reversing it with [::-1] — does your name look funny backwards?

Useful String Methods

Strings come with a bunch of built-in methods — functions that belong to the string and do something useful. You call them with dot notation: my_string.method_name(). Here are the ones you'll use most often:

greeting = "  Hello, World!  "

print(greeting.strip())       # Hello, World!       (removes leading/trailing whitespace)
print(greeting.upper())       #   HELLO, WORLD!     (all uppercase)
print(greeting.lower())       #   hello, world!     (all lowercase)
print(greeting.replace("World", "Portland"))  #   Hello, Portland!

And a few more that are super handy:

message = "I love Portland food carts"

print(message.count("o"))          # 3  (counts how many times "o" appears)
print(message.find("Portland"))    # 7  (index where "Portland" starts)
print(message.startswith("I"))     # True
print(message.endswith("trucks"))  # False

Important — strings are immutable! That means you can't change a string in place. When you call name.upper(), it doesn't change name — it creates a new string and gives it back to you. If you want to keep the result, you need to assign it:

name = name.upper()

This catches a lot of new programmers off guard. If you call greeting.strip() but don't store the result anywhere, the stripped version just vanishes into thin air. The original greeting still has all its extra spaces.

Try it! Create a variable messy = " hElLo " and chain some methods together: first .strip() the whitespace, then .lower() the result. Can you do it in one line? (Hint: messy.strip().lower())

Splitting and Joining

Sometimes you need to break a string apart into pieces, or take a bunch of pieces and glue them together. That's what .split() and .join() are for.

.split() breaks a string into a list of smaller strings. By default it splits on whitespace (spaces, tabs, &c.):

sentence = "I love Portland food carts"
words = sentence.split()
print(words)  # ['I', 'love', 'Portland', 'food', 'carts']

You can also tell it what to split on by passing a separator:

data = "red,green,blue,yellow"
colors = data.split(",")
print(colors)  # ['red', 'green', 'blue', 'yellow']

.join() does the opposite — it takes a list and glues the items together with whatever string you call it on:

words = ['I', 'love', 'Portland', 'food', 'carts']

back_together = " - ".join(words)
print(back_together)  # I - love - Portland - food - carts

spaced = " ".join(words)
print(spaced)  # I love Portland food carts

(We haven't covered lists in detail yet — don't worry about them too much. Just know that .split() gives you one and .join() takes one.)

Try it! Take the string "apples, bananas, cherries, dates" and split it by ", " (comma-space). How many items do you get? Then join them back together with " and " between each item.

F-Strings: The Nice Way to Format

Back in the Data Types lesson, you saw that you can't just smash a string and a number together with + — Python complains about the types not matching. F-strings solve that problem beautifully.

An f-string starts with the letter f before the opening quote, and you put expressions inside curly braces {}. Python fills in the values for you:

name = "Clarissa"
city = "Portland"
temp = 52

# The old way (messy, lots of str() and +):
print("Hi " + name + ", it is " + str(temp) + " degrees in " + city)

# The f-string way (clean):
print(f"Hi {name}, it is {temp} degrees in {city}")

Both lines print the same thing, but the f-string version is much easier to read and write. No need to convert numbers to strings — the f-string handles that for you.

You can even put expressions inside the curly braces — not just variable names:

temp = 52
print(f"Double the temperature: {temp * 2}")   # Double the temperature: 104
print(f"Is it warm? {temp > 70}")               # Is it warm? False

price = 9.99
quantity = 3
print(f"Total: ${price * quantity:.2f}")        # Total: $29.97

That last one uses :.2f inside the braces to format the number to two decimal places — handy for displaying money.

Try it! Write an f-string that includes your name, your age, and your age doubled. Something like: "My name is Alex, I'm 22, and in double that's 44."

String Concatenation

You've seen this before, but let's make it official: you can combine strings using the + operator. This is called concatenation.

first = "Good"
second = "Dog"
result = first + " " + second
print(result)  # Good Dog

The catch — and you might remember this from the Data Types lesson — is that you can only concatenate strings with other strings. If you try to add a string and a number, Python will give you a TypeError:

# This will cause an error:
# print("The answer is " + 42)

# You'd need to convert the number first:
print("The answer is " + str(42))  # The answer is 42

Honestly, now that you know about f-strings, you'll probably reach for those instead of concatenation most of the time. F-strings are just easier. But it's worth knowing both approaches — you'll see concatenation in other people's code all the time.
