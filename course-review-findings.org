* About this review
- A lesson-by-lesson audit of every non-archive HTML file in CS 160 /Exploring
  Computer Science/ (Unit 0–10, ~136 files) on the =summerwork= branch.
- Findings are grouped into four categories per the request:
  - *(a) Factual problems* — incorrect or self-contradictory content; bad arithmetic; broken code; dead/wrong links.
  - *(b) Out-of-date information* — stale dates, dead tools/services, content overtaken by events.
  - *(c) Pedagogical issues* — confusing structure, missing scaffolding, unclear instructions, gen-ed-inappropriate leaps.
  - *(d) Quality problems* — typos, broken formatting, inconsistent naming/numbering, markup cruft.
- Each item is a checkbox so it can double as a fix worklist. Severity is marked =[high]=, =[med]=, =[low]=.
- *Important context:* this is the pre-rewrite =summerwork= content. Unit 9 (AI) is the
  13-lesson classical-ML version and Unit 10 (Cybersecurity) is the 5-lesson version,
  predating the generative-AI era. Instructor placeholder bios in Unit 0 are intentional.
  HTML is the intended format (content is pasted back into D2L), so "convert to markdown"
  is *not* a finding.
