# Quizzes (Units 1–10)

Draft quiz banks for every content unit, for building the matching **D2L quizzes**.
Units 1–4 and 6–8 each have 10 auto-gradable questions (8 multiple-choice and 2
true/false); Units 5, 9, and 10 have 12 (10 multiple-choice and 2 true/false). All are
aligned to that unit's lessons and learning objectives.

## Two files per unit

- **`Unit N Quiz.md`** — the questions only. Committed; safe to share with co-instructors.
- **`Unit N Quiz - Answer Key.md`** — questions *with* the correct answers and a one-line
  rationale each. **Git-ignored** (same rule as the Lab answer keys), so it stays out of
  any student-discoverable copy of the repo. Keep these locally or in a private space.

When you build the quiz in D2L, the answer key tells you which option to mark correct.
