# Quizzes (Units 3–7)

Draft quiz banks for the reorganized Python and computation units, for building the
matching **D2L quizzes**. Each unit has 10 questions: 6 multiple-choice, 2 true/false,
2 short-answer, all aligned to that unit's lessons and learning objectives.

## Two files per unit

- **`Unit N Quiz.md`** — the questions only. Committed; safe to share with co-instructors.
- **`Unit N Quiz - Answer Key.md`** — questions *with* the correct answers and a one-line
  rationale each. **Git-ignored** (same rule as the Lab answer keys), so it stays out of
  any student-discoverable copy of the repo. Keep these locally or in a private space.

When you build the quiz in D2L, the answer key tells you which option to mark correct.

## Composition (per unit)

| Unit | Title | Focus |
|---|---|---|
| 3 | Python: Algorithms, Variables, and Functions | pseudocode, variables/types, I/O & f-strings, arithmetic, functions, parameters/return |
| 4 | Making Decisions: Booleans, Conditionals, and Logic | comparisons, if/elif/else, and/or/not, nested decisions |
| 5 | Loops, Strings, and Randomness | while, for/range, string indexing & methods, loop patterns, random |
| 6 | Collections: Lists, Tuples, and Dictionaries | lists & indexing, looping, tuple unpacking, dictionaries |
| 7 | The Nature of Computation | good-algorithm requirements, one algorithm/many languages, search, Big-O, halting problem, Game of Life |
