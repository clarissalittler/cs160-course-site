## Unit 2 Quiz — The Internet

### Multiple Choice

**1.** Your cousin insists the internet is one giant computer owned by a single company. Which description is accurate?
- A) A single supercomputer that every device connects to
- B) A system of independently operated networks that exchange data through shared protocols
- C) A program pre-installed on a computer
- D) Another name for a web browser
**2.** A provider has two physically separate routes between two cities. A fiber cut closes one route, routing information updates, and packets continue over the other. What made continued service possible?
- A) Redundancy provided an alternate path, and routing systems selected it
- B) Compression made packets small enough to cross the broken fiber
- C) High throughput made the cut irrelevant
- D) Caching downloaded the rest of every live conversation in advance
**3.** Your laptop is streaming a playlist and loading a course page at the same time. Packets for both arrive at the same IP address. What lets your computer hand each one's data to the right program?
- A) The domain name, which DNS writes into every packet
- B) The routers, which deliver each packet straight to the program that asked for it
- C) A port number, which the transport layer (TCP or UDP) adds to identify the program
- D) The Wi-Fi connection, which keeps a separate radio channel for each app
**4.** Your browser says, "This site can't be reached. The server's IP address could not be found." Other sites load fine on the same laptop. Which part of the trip is the strongest suspect?
- A) Your Wi-Fi connection, because the laptop must be offline
- B) The web server, because it doesn't have the page you asked for
- C) The site's HTTPS certificate, because the connection isn't private
- D) DNS, the system that looks up the IP address that goes with a site's name
**5.** Which statement about HTTPS is most accurate?
- A) It makes any site using it honest and safe
- B) It protects web content in transit and helps authenticate the requested domain, but the destination site can still receive and log the content
- C) It hides all packet addresses, sizes, and timing from every network
- D) It is a content delivery network that caches pages near users
**6.** In June 2021, a software bug at the CDN provider Fastly was triggered by a valid customer configuration change, and many of its customers returned errors at once. What does this best illustrate?
- A) Every part of the internet is always fragile
- B) Shared infrastructure can improve everyday service but create correlated failures across otherwise unrelated sites
- C) Packet switching had been removed from those sites
- D) All affected sites had the same owner and content

**8.** An IP address in a log always identifies exactly one device and proves which individual person performed an action.
### Multiple Choice (continued)

**9.** Which pairing of app and transport protocol makes the most sense?
- A) Downloading an assignment PDF over UDP; a live video call over TCP
- B) Both over UDP, because it's always faster
- C) Downloading an assignment PDF over TCP; a live video call over UDP
- D) Both over TCP, because UDP loses data and can't be used by real apps
**10.** Maya switches to an internet plan with much higher advertised speed. Big game downloads now finish far sooner, but her online game still feels laggy every time she presses a button. What's the best explanation?
- A) The new plan raised her throughput, but lag is about latency, which the upgrade didn't change
- B) Her provider must be lying, since a faster plan always fixes lag
- C) Higher throughput always lowers latency, so the game's server must be down
- D) The game sends more data than any home connection can handle
