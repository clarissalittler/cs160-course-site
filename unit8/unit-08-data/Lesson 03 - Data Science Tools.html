Computational notebooks

Data scientists do most of their work in computational notebooks - think of them as lab notebooks for code, a single page where your Python, your notes, and your results all live together.

The most popular flavor is the Jupyter Notebook. We'll be using Google Colab, which stores your Jupyter Notebooks in your Google Drive.

Open up Google Colab and make yourself a notebook: click the 'New Notebook' button (or, if you're already in Colab, go to the 'File' menu and pick 'New Notebook').

Try it out: write a Python statement to print “Hello”, then click the run button.

Everything you make ends up in your Google Drive, in a folder called Colab Notebooks (Colab creates it for you).

Note: nobody expects you to become a Colab expert - or an expert in any of this unit's tools. The point is learning to find patterns in visualizations of data and pull something new out of them. All of the code has been written for you; your job is choosing the right visualization for the questions you want to answer!

Pandas

Pandas is the workhorse: an open-source data analysis and manipulation library built on top of Python - fast, powerful, and (once you get the hang of it) surprisingly friendly. Using Pandas, we'll convert comma-separated files (CSV) into dataframes - tables Python can actually work with. Pandas also has functions for creating charts and graphs to visualize the data.

Think of it as the supercharged version of what you did in Unit 6. There, you opened a CSV the hands-on way, with the csv module, and converted each column from text yourself, row by row. Pandas does that whole job in a single line - it reads the file into a table and works out the types for you - which is exactly why it's worth having done it the manual way first: you know what it's doing on your behalf.
