Unit 8 Summary

Wrap up

In this unit, you learned how data analysis helps turn raw data into useful information about the world. You learned how to use data visualization libraries in Python to find patterns inside datasets. We also investigated how misleading charts are used in the media to change opinion and the importance of using quantitative reasoning to spot misinformation.

Summary

  • We can develop insights and knowledge about our world from manipulating and visualizing data, in particular by finding patterns.
  • When investigating two columns of data we can observe patterns to see the relationship between data (correlation). 
  • We cannot know for certain the cause of the correlation.
