Unit 8 Overview

In this unit, you will learn about one key aspect of AI which is Data. You will learn the definitions of Data Mining and Data Storage. You will learn how data exploration and analysis helps turn raw data into useful information about the world. You will learn how to use data visualization libraries in Python to find patterns in datasets. We also investigate how misleading charts are used in the media to change opinion and the importance of using quantitative reasoning to spot misinformation.

Learning objectives

At the end of this learning module, you will be able to:

  1. Define Data Literacy, Data Mining, Data Storage, and Data Exploration.
  2. Create bar charts, histograms, scatter plots, and crosstab charts using Python libraries. 
  3. Draw conclusions from data by using quantitative reasoning and reading charts. 
  4. Explain the reasons that someone would create a bar chart, histogram, scatter plot, or crosstab chart in order to explore one or two columns of data. 
  5. Explain why data needs to be cleaned.
