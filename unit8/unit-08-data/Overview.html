Unit 8 Overview

This unit is about data - what it is, how it's organized, and how to pull honest answers out of it. We'll start close to home (your step count and Spotify Wrapped are data, it turns out), learn to spot the tricks that make misleading charts so effective in the news and your feeds, and then get our hands dirty: using Python libraries in pre-built notebooks to make bar charts, histograms, scatter plots, and crosstab charts of real datasets - and, just as important, to read them with appropriate skepticism. The star of the show is a dataset of 105 dog breeds, which turns out to have plenty to say. Everything here also sets up the next unit: modern AI is built by feeding enormous datasets into algorithms, so knowing how data works (and how it misleads) is the foundation for understanding what comes next.

Learning objectives

At the end of this learning module, you will be able to:

  1. Explain what data and datasets are, and classify data as categorical or quantitative (and quantitative data as discrete or continuous).
  2. Recognize common ways charts mislead, and use quantitative reasoning to question the charts you meet in media and everyday life.
  3. Create bar charts, histograms, scatter plots, and crosstab charts using Python libraries. 
  4. Draw conclusions from data by reading charts - including explaining why a correlation alone can't establish causation. 
  5. Explain the reasons that someone would create a bar chart, histogram, scatter plot, or crosstab chart in order to explore one or two columns of data. 
  6. Explain why data needs to be cleaned.
