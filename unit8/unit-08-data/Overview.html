Unit 8 Overview

This unit is about data: what it is, how it's organized, and how to draw conclusions from it that you can actually defend. We'll start close to home (your step count and your Spotify Wrapped are data, it turns out), then learn to spot the choices that make a misleading chart work on you in the news, in ads, and in your feed.

From there we'll use Python libraries in prepared notebooks to make bar charts, histograms, scatter plots, and crosstab charts from real datasets. The code is mostly supplied, so the work shifts from building a program to choosing the right chart and reading it without fooling yourself. Our running example is a dataset of 105 dog breeds, which has more to say than you'd expect.

This also prepares us for the next unit. Modern AI systems are trained on enormous datasets, so understanding how data is collected, organized, and sometimes misleading is part of understanding what those systems learn.

Learning objectives

By the end of this unit, you should be able to:

  1. Explain what data and datasets are, and classify data as categorical or quantitative (and quantitative data as discrete or continuous).
  2. Recognize common ways charts mislead, and use quantitative reasoning to question the charts you meet in media and everyday life.
  3. Create bar charts, histograms, scatter plots, and crosstab charts using Python libraries. 
  4. Draw conclusions from data by reading charts — including explaining why a correlation alone can't establish causation. 
  5. Explain the reasons that someone would create a bar chart, histogram, scatter plot, or crosstab chart in order to explore one or two columns of data. 
  6. Explain why data needs to be cleaned. 
  7. Explain how sampling and selection bias limit what a dataset can show, and choose between the mean and the median for a skewed column.

Lesson map

The six lessons in Unit 8
LessonCentral ideaQuestions to carry forward
1. Data All Around YouA dataset brings recorded observations together in rows and columns. What gets recorded, and who gets counted, shapes what we can learn from it.What does one row stand for? Which columns might help answer my question?
2. Reading Charts Without Getting FooledA chart can make a claim look convincing while leaving out useful context. The scale, time window, and choice of counts or rates all matter.What would this chart look like with a different baseline or a longer time window? Are the groups being compared fairly?
3. Notebooks and the Dog DatasetWe'll use a prepared notebook to load and explore a dataset about dogs. The code gives us a starting point for asking questions of the data.What does each row in the dog dataset describe? Which columns would I need to explore a question about breeds?
4. One Column at a Time: Bar Charts and HistogramsBar charts and histograms both show patterns in data, but they organize values differently. A histogram groups numbers into ranges before counting them.Is this column categorical or quantitative? Which chart and summary fit the question?
5. Two Columns at a Time: Scatter Plots and CrosstabsScatter plots and crosstabs let us look at two columns together. A relationship can be interesting without proving that one thing caused the other.Which two columns am I comparing? What other explanation might account for a pattern between them?
6. From Question to ConclusionA data analysis starts with a question, then moves through cleaning, choosing a chart, and explaining the result in numbers.Does the evidence actually answer the question? What would I need to know before applying the conclusion more broadly?
