Lesson 1 - Data and Dataset

At the end of this lesson, you will be able to:

  • Explain what is Data and Datasets.
  • Give examples of different types of Datasets.

Data

Data are observations or measurements (unprocessed or processed) represented as text, numbers, or multimedia. Data is one key aspect of AI.

Dataset

A dataset is a structured collection of data generally associated with a unique body of work.

Dataset Types

Text Dataset

  • Ticket Dataset
  • EHR Data & Physician Dictation Transcripts 
  • Document Dataset

Speech Dataset

  • Monologue Speech 
  • Dialogue Speech 
  • Acoustic Data
  • Natural Language Utterance

Image Dataset

  • Document Dataset  
  • Facial Dataset
  • Healthcare Data
  • Hand Gesture Data

Video Dataset

  • Human Posture Video Dataset 
  • CCTV/Surveillance Video Dataset
  • Traffic Video Dataset
