# Unit 8 Overview

![Unit 8 banner](img/banner.jpg)

Welcome to Unit 8! This is where things get really interesting --- we're diving into **data**, one of the key ingredients that makes AI actually work.

We'll explore what data mining and data storage really mean, how data exploration and analysis turn raw numbers into genuine insights about the world, and --- here's the fun part --- you'll get hands-on with Python's data visualization libraries to find patterns hiding in real datasets. We'll also investigate how misleading charts get used in the media to manipulate opinion, and why quantitative reasoning is your best defense against misinformation.

## Learning objectives

**After this lesson, you'll be able to:**

1. Define Data Literacy, Data Mining, Data Storage, and Data Exploration.
2. Create bar charts, histograms, scatter plots, and crosstab charts using Python libraries.
3. Draw conclusions from data using quantitative reasoning and chart reading.
4. Explain why you'd choose a bar chart vs. a histogram vs. a scatter plot vs. a crosstab chart to explore one or two columns of data.
5. Explain why data needs to be cleaned.
