Student dataset

We've been happily turning tables into charts, but there's a catch we've been glossing over: real data rarely shows up in chartable shape. What you can actually do with a dataset depends on how it was collected - and how carefully.

So before we go any further, let's talk about getting data into shape. Take a look at the student dataset below. Could we chart it as-is? What problems do you spot?

Show Solution
  • Data is of different types in a column. You cannot have a column with 'six' and 6.
  • Cells are missing data. 
  • 'i like food' is not a valid major.
  • Spelling inconsistencies: Junior vs Jr.

Cleaning data

Every dataset, big or small, can have problems like these - missing values, invalid entries, or two tables that record the same thing in two different ways. Fixing all of that before the analysis starts is called cleaning the data, and it's a bigger part of real data work than anyone likes to admit.

So when does data need to be cleaned?

  • Data is incomplete
  • Data is invalid
  • Multiple tables are combined into one

And how does data get "messy" in the first place?

  • Users enter in different types of data ("two", 2)
  • Users use different abbreviations to represent the same information ("CS", "Comp Sci", "Computer Science")
  • Data may have different spellings or inconsistent capitalization ("math", "Math")

The good news is you can head off a lot of this mess at collection time. Wherever possible, don't ask people to type in their answers - give them dropdown menus or checkboxes instead, and there's nothing to misspell.
