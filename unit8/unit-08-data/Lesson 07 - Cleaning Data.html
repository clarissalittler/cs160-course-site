Student dataset

We've been turning tables into charts, but there is a catch: real data rarely arrives in clean, chart-ready form. What we can do with a dataset depends on how it was collected—and how carefully.

So before we go any further, let's talk about getting data into shape. Take a look at the student dataset below. Could we chart it as-is? What problems do you spot?

Show Solution
  • Data is of different types in a column. You cannot have a column with 'six' and 6.
  • Cells are missing data. 
  • 'i like food' is not a valid major.
  • Spelling inconsistencies: Junior vs Jr.

Cleaning data

Any dataset can have problems like these: missing values, invalid entries, or two tables that record the same thing in different ways. Finding and addressing those problems before analysis is called cleaning the data, and it occupies a substantial part of real data work.

So when does data need to be cleaned?

  • Data is incomplete
  • Data is invalid
  • Multiple tables are combined into one

And how does data get "messy" in the first place?

  • Users enter in different types of data ("two", 2)
  • Users use different abbreviations to represent the same information ("CS", "Comp Sci", "Computer Science")
  • Data may have different spellings or inconsistent capitalization ("math", "Math")

Some problems can be prevented at collection time. When a field truly has a fixed set of choices, a well-labeled dropdown or checkbox can prevent spelling variants. But constrained controls can also exclude answers the designer failed to anticipate, so collection design has to balance consistency with an honest way to represent missing, uncertain, or unlisted values.
