# Archived Unit 1 nine-lesson sequence

This directory preserves the Unit 1 lessons that were active before the July 2026 five-lesson reorganization. The archive is intentionally retained as a source of examples, activities, explanations, and links while the revised sequence is evaluated.

The archived sequence is:

1. Computers and Information
2. Circle Squares and Binary Numbers
3. Decimal to Binary
4. Encoding Text
5. Black and White Images
6. Color Images
7. Lossless Compression
8. Lossy Compression
9. Intellectual Property

A `<base href="../../">` element was added to each archived page so its existing links to Unit 1 images and the site stylesheet continue to resolve from this deeper directory. Otherwise, the lesson content is unchanged. The Git history immediately before the reorganization is also available at commit `5d59e04`.
