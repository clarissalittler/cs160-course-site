Digital color images

Digital images are composed of tiny squares of color known as pixels (picture elements). In figure 1.11 below, you can see when we zoom into the picture of Mario, the image is made up of pixels of different colors.


Each of those tiny squares is a combination of the colors red, green, and blue, or RGB and each color is represented with 8 bits or the values 0 - 255. These colors are light, so when the color value is 0, that means there is none of that color light. Think of 0 as turning off the light switch and an RGB of (0, 0, 0) would be all offs, so the color black. RGB of (255, 255, 255) would be turning all the light on to full brightness, which would create the color white.

Look at figure 1.12 below. The RGB values are (255, 0, 150), the red is turned on 100%, there is no green, and the blue is turned on a little more than 50%.


What happens if we turn down the lights 50% to RGB(125, 0, 75)? Does the color get brighter (lighter) or darker? Think about what we are doing to the light! Try it for yourself - go to the RGB Calculator and enter the values.

A quick word on hex codes

If you've ever poked around in a design app or a web page, you've probably seen colors written in a cryptic style like #FF0096 instead of RGB(255, 0, 150). Good news: it's the exact same color, just wearing a different outfit. That style is hexadecimal - "hex" for short - a base-16 number system.

Base 16 means sixteen digits instead of the usual ten, so once we run out of 0-9 we borrow the letters A through F to stand for 10, 11, 12, 13, 14, and 15. Why would anyone want that? Because it lines up perfectly with bytes. Remember from Lesson 3 that one byte (8 bits) holds a value from 0 to 255 - and it happens that 0 to 255 fits in exactly two hex digits, 00 up to FF (FF being 255, the largest a byte can hold). So each color channel becomes a tidy 2-digit pair, and a full RGB color becomes six hex digits: #RRGGBB.

Our example color, RGB(255, 0, 150), breaks apart like this: 255 is FF, 0 is 00, and 150 is 96. Snap them together and you get #FF0096 - red, then green, then blue. Hex is really just a compact, human-friendlier shorthand for the bytes underneath: #FF0096 is a lot easier to jot down and text to a friend than 11111111 00000000 10010110.
