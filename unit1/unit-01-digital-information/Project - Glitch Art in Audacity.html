Small Weird Project — Glitch Art in Audacity

What you'll do: Take an image file, open it as audio in Audacity, apply sound effects, and export it back as an image. The result is glitch art — and it's a genuinely cool way to see encoding in action.

This project is NOT graded. It's just for fun and exploration. There's nothing to turn in. If you try it and it's cool, great. If you skip it, that's fine too.

Breaking Things on Purpose

This week's project is about breaking things on purpose. You're going to take an image, open it as if it were audio, mess with it, and see what happens. The result is called glitch art, and it's a genuinely cool way to see Unit 1's lesson about encoding in action.

Here's the core idea: a JPEG file is just a bunch of bytes — numbers, sitting in a row. Your computer knows it's a picture because the file extension says .jpg and the file's header bytes identify it as a JPEG. But what if you lied to a program and said "hey, these bytes are audio data"? The program would happily interpret them as sound waves. You could play your photo and hear it. (It sounds terrible, for the record — but that's part of the fun.)

And here's where it gets really interesting: if you apply audio effects — echo, reverb, pitch shifting — you're mathematically transforming those bytes. When you save the result and rename it back to .jpg, those transformations show up as visual glitches. Smeared colors, shifted bands, weird distortions. The data is the same bytes — but the effects you applied in "audio world" produce strange and often beautiful results in "image world."

What You'll Need

  • A JPEG image. Any photo will do — something from your phone, a landscape, a selfie, whatever. Make a copy first — you'll be destroying it.
  • Audacity — a free, open-source audio editor. Works on Windows, Mac, and Linux. Download it at audacityteam.org.

Step-by-Step

1. Get your image ready

Find or take a photo and save it as a JPEG (.jpg). Copy the file so you have a backup — we're about to mangle the original beyond recognition. Name your copy something like glitch-me.jpg.

2. Import it as raw audio

Open Audacity. Go to File → Import → Raw Data. Select your JPEG file. You'll get a dialog box with some options — set them like this:

  • Encoding: Unsigned 8-bit PCM
  • Byte order: No endianness (doesn't matter for 8-bit)
  • Channels: 1 Channel (Mono)
  • Sample rate: Anything is fine — 44100 is the default and works great

Click Import. You'll see a waveform appear. That's your image, interpreted as sound.

3. Listen to your photo

Hit the play button. That's what your image "sounds like." It's mostly static and noise, which makes sense — the bytes weren't arranged to be pleasant audio. But you're hearing the same data that your image viewer would show you as a picture. Same bytes, different interpretation.

4. Apply some effects

Select a portion of the waveform. Don't select the very beginning — we'll explain why in a second. Start your selection a bit into the file, maybe a quarter of the way in. Then try some effects from the Effect menu:

  • Echo — creates repeating patterns in the image
  • Reverb — smears and blurs things
  • Paulstretch — stretches things out dramatically
  • Change Pitch — shifts colors and bands around

Try one effect. Try stacking several. Go wild — you can't break anything that matters.

Don't edit the very beginning of the file! The first chunk of bytes contains the JPEG header — metadata that tells your computer "this is a JPEG, here's how to decode it." If you corrupt that header, the file won't open at all. You'll just get an error. Start your selection at least a little ways into the waveform — the further in you go, the safer you are.

5. Export the result

Go to File → Export → Export Audio. In the "Save as type" dropdown, choose Other uncompressed files, then set the header to RAW (header-less) and the encoding to Unsigned 8-bit PCM. Save it as something like glitch-me.raw.

Now rename the file from .raw to .jpg. (On Windows you might need to turn on "show file extensions" in File Explorer settings first.)

6. Open your creation

Double-click the renamed file. If all went well, you'll see your original image — but glitched. Smeared colors, banded distortions, shifted regions. It's art, honestly. Weird art, but art.

If the image won't open at all, you probably corrupted the header. Go back to your backup copy and try again, being more careful to leave the beginning of the waveform alone.

Experiment!

Try this:

  • Try different effects and different amounts. Subtle effects give subtle glitches; dramatic effects give dramatic ones.
  • Try it with a BMP file instead of JPEG — the results look different because the encoding is different. BMP stores pixels in a simpler, more direct way, so the glitches look more orderly.
  • Try it with a PNG file. What happens? (Hint: PNG uses compression, so the audio effects tend to completely destroy the file structure. You might not get a viewable image at all — and that's instructive.)
  • Try applying the same effect to different images. Do you get similar-looking glitches, or completely different ones?

What You Just Demonstrated

The same bytes can be interpreted as an image or as sound. The data doesn't change — the interpretation does. When you opened a JPEG in Audacity, nothing about the file changed. Audacity just read those bytes as audio samples instead of pixel data. And when you applied audio effects, you were doing math on those bytes — the same math that would create an echo in a song creates a visual pattern in a photo.

That's the core lesson of Unit 1: data is just numbers. The encoding — the agreed-upon interpretation — is what gives those numbers meaning. Change the interpretation, and the same pile of bytes becomes something entirely different.
