In binary it's the same idea, except each place value is a power of 2 instead of 10, and the only digits we're allowed are 0 and 1. That fits perfectly with where we just came from: a bit, like a circle-or-square, has exactly two states, so each column can only be "off" (0) or "on" (1).

Binary place values

Here are the first eight binary place values. Reading right to left, each one is double the one before it - 1, 2, 4, 8, 16, and so on - because every step up multiplies by 2:

27 26 25 24 23 22 21 20
128 64 32 16 8 4 2 1

Eight of these columns together make one byte, which is exactly why we like to write binary numbers in tidy groups of 8.

Reading binary: from binary to decimal

To turn a binary number into the decimal number we're used to, write the bits underneath the place values and add up every column that has a 1 in it. The 0 columns contribute nothing, so you can ignore them completely. Let's read 01001101:

128 64 32 16 8 4 2 1
0 1 0 0 1 1 0 1

The columns turned "on" (the shaded 1's) are 64, 8, 4, and 1, so we just add them up:

64 + 8 + 4 + 1 = 77

And that's the whole trick - 01001101 in binary is 77 in decimal. Notice we never actually multiplied anything; because each bit is only ever 0 or 1, "reading" a binary number is nothing more than adding up the place values that happen to be switched on.

Writing binary: from decimal to binary

Going the other direction - taking an everyday number and writing it in binary - we work from the biggest place value down. The recipe is: find the largest power of 2 that fits, subtract it, then keep going with whatever's left over. Let's turn 77 back into binary, walking down the place values 128, 64, 32, …, 1:

  • Does 128 fit in 77? No - 128 is bigger than 77. Write a 0.
  • Does 64 fit in 77? Yes. Write a 1 and subtract: 77 − 64 = 13.
  • Does 32 fit in 13? No. Write a 0.
  • Does 16 fit in 13? No. Write a 0.
  • Does 8 fit in 13? Yes. Write a 1 and subtract: 13 − 8 = 5.
  • Does 4 fit in 5? Yes. Write a 1 and subtract: 5 − 4 = 1.
  • Does 2 fit in 1? No. Write a 0.
  • Does 1 fit in 1? Yes. Write a 1 and subtract: 1 − 1 = 0. Done - there's nothing left over.

Reading the bits we wrote, from the top down, gives 01001101 - exactly the number we started with up in the reading example. The two directions are mirror images of each other, which means you can always check your work by converting back the other way.

Try it! Grab a scrap of paper and work these two out before peeking:

  • Convert the decimal number 42 into binary.
  • Convert the binary number 10110 into decimal.
Show answers

42 in binary: 32 fits (leaving 10), then 8 fits (leaving 2), then 2 fits (leaving 0). So the "on" columns are 32, 8, and 2, giving 00101010.

10110 in decimal: the on columns are 16, 4, and 2, so 16 + 4 + 2 = 22.
