Unit 1 Summary

Wrap up

In this unit, you learned how computers represent information. All information, including numbers, text, images, videos, and sound is stored as 0’s and 1’s. Images, videos, and sound files can be huge, but we can use lossless or lossy compression, depending on the situation. You also learned how to protect your digital work using copyright and creative commons licenses.

Key takeaways

  • All computers perform the same 4 tasks, input information, store information, process information, and output information.
  • Computers store all information as 1's and 0's called bits. This language of the computer is called binary and is a number system with 2 symbols.
  • Text is stored by giving every character a number — ASCII for basic English characters, and its modern extension Unicode (UTF-8) for everything else, emoji included.
  • Color is stored as amounts of red, green, and blue light. Each amount is stored as 8 bits and can be 0-255. RGB(0, 0, 0) is black - all light is turned off. RGB(255, 255, 255) is white, all light is turned on.
  • Digital information is growing bigger and bigger. To save space you can compress using lossless or lossy compression schemes. With lossless compression, no information is lost. With lossy compression, the removed bits are gone forever.
  • Copyright and Creative Commons Licenses can protect your digital work.
