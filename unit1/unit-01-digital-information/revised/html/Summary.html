Unit 1 Summary

Wrapping Up

We covered a lot of ground in this unit. We went from "what even is a bit?" all the way to debating intellectual property law — and everything in between.

Here's the big picture: all information in a computer — every number, every letter, every pixel of every photo, every frame of every video, every sound in every song — is stored as 0s and 1s. That's it. That's the whole trick. Everything else is just clever encoding schemes built on top of that foundation.

Key Takeaways

  • All computers perform the same four tasks: input information, store information, process information, and output information. Every computer, from your phone to a supercomputer, follows this same basic pattern.
  • Computers store all information as 1s and 0s called bits. The language of the computer is called binary — a number system with just 2 symbols. Everything else is built from there.
  • Text is stored using encoding schemes like ASCII, where each character gets mapped to a specific number (which is stored as bits, of course).
  • Color is stored as amounts of red, green, and blue light (RGB). Each channel gets 8 bits, giving values from 0--255. RGB(0, 0, 0) is black — all light off. RGB(255, 255, 255) is white — all light cranked to max. Remember: it's light, not paint, so the mixing rules are backwards from what you'd expect.
  • Digital information keeps getting bigger, so we compress it. Lossless compression squeezes files down without losing a single bit — you can always perfectly reconstruct the original. Lossy compression throws away some information permanently, but achieves much smaller file sizes. Which one you use depends on the situation.
  • Copyright and Creative Commons licenses protect your digital work. When you create something, you own it. And when you want to use someone else's work, you need to understand what they're allowing — and what they're not.

What's Next?

You now have a solid understanding of how computers represent and store information at the most fundamental level. In the next unit, we'll start looking at what computers actually do with all this information — how they process it, move it around, and make decisions. Things are about to get even more interesting.
