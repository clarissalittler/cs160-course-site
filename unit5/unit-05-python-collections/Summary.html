Unit 5 Summary

Wrap up

In this unit, you learned to work with collections - the containers Python uses to hold many values at once. You worked with strings character by character, built and modified lists, used the loop patterns that turn a pile of data into an answer, grouped related values together with tuples, looked things up by key with dictionaries, and combined these pieces to model real information like a table of names and scores.

Summary

  • A string is a sequence of characters: you can index it, slice it, loop over it one character at a time, and transform it with methods like .lower() and .strip().
  • A list is an ordered, changeable collection. You can access items by index, add to it with .append(), and change items in place.
  • A for loop is the natural way to visit every item in a collection, one at a time, without tracking an index yourself.
  • The accumulator pattern uses a variable created before a loop and updated inside it to build a running total or count; counting and filtering are variations on the same idea.
  • A tuple groups related values that belong together and shouldn't change, and tuple unpacking pulls those values back out into separate variables in one line.
  • A dictionary stores key-value pairs so you can look a value up by its key instead of its position - fast and readable.
  • Collections combine: a list of tuples or a list of dictionaries lets you model a whole table of real-world information.
