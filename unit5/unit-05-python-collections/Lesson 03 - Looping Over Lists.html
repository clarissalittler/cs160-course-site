Two ways to loop over a list

Lists and loops are made for each other. The simplest way is to let a for loop hand you each element directly:

nums = [2, -3, 10, -1, 7]

for value in nums:        # value becomes each element in turn
    print(value)

Sometimes, though, you need the index too (say, to print "item 0, item 1, ..." or to change elements). For that, loop over range(len(nums)) and use the index to reach each element with nums[index]:

def main():
    nums = [2, -3, 10, -1, 7]
    length = len(nums)

    for index in range(length):
        print(index, nums[index])

main()

Trace it slowly: in that second loop, index holds each number from range() - 0, 1, 2, ... - and nums[index] is how we reach the element at that position. index is the slot number; nums[index] is what's in the slot.

Looping Through Lists

Building a list from input

You can start with an empty list [] and append() to it inside a loop - this is how you collect an unknown number of items from a user. Here we keep asking for colors until they press Enter on an empty line:

def main():
    colors = []
    a_color = input("Enter a color: ")
    while a_color != '':
        colors.append(a_color)
        a_color = input("Enter a color: ")

    print(colors)

main()

(This is the accumulator idea - start with an empty container before the loop and build it up as you go - except here we're accumulating into a list instead of a running total. It's a pattern we'll make official in the next lesson.)

Building and Formatting a List

Another common shape - the one Week 5 Assignment uses - is to ask the user directly whether they want to keep going:

def main():
    colors = []
    answer = "yes"
    while answer == "yes":
        colors.append(input("Enter a color: "))
        answer = input("Add another? (yes/no) ")

    print(colors)

main()

Same accumulator pattern, different stopping signal: instead of watching for an empty line, the loop keeps going as long as the user answers yes.

A classic: finding the min and max

A very common task is finding the smallest or largest value in a list. The algorithm is simple but has one crucial trick: start by assuming the first element is the smallest (and largest), then loop through the rest, updating whenever you find something smaller (or larger).

# Finds the minimum in a list of numbers.
# Your turn: add the code to also find the maximum!
def main():
    nums = [3, -2, 4, 10, -6]
    print("list:", nums)

    smallest = nums[0]            # start with the first element
    length = len(nums)

    for index in range(length):
        if nums[index] < smallest:    # found something smaller?
            smallest = nums[index]    # remember it

    print("smallest:", smallest)

main()

(One aside: Python has built-in min() and max() functions that do this in one step - which is exactly why we named our variable smallest instead of min. Naming a variable min "shadows" the built-in, and any later call to min(...) crashes.)

Bug Alert: Don't initialize smallest or largest to a made-up number like 0 or 9999! If you set largest = 0 but all the numbers are negative, your "maximum" comes out as 0 - which isn't even in the list. Always start smallest and largest at nums[0], the first real element.
