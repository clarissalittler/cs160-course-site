1. Text transformation and count

Ask for a short phrase. Build a new lowercase string containing only letters and digits—ignore spaces, commas, periods, apostrophes, and other punctuation. Count how many characters remain and report whether the cleaned text is the same forward and backward.

Show one solution
phrase = input("Phrase to examine: ")
cleaned = ""

for character in phrase.lower():
    if character.isalnum():
        cleaned += character

print(f"Cleaned text: {cleaned}")
print(f"Elements examined: {len(cleaned)}")
print(f"Same forward and backward: {cleaned == cleaned[::-1]}")

This is a simplified text model. Document that visible symbols and Python elements can differ across writing systems.

2. Safely edit a changing list

Begin with an empty reading list. Repeatedly ask for a title until the user enters a blank line. Then ask for one title to remove. Remove it only if present, display the remaining titles with numbers beginning at 1, and handle an empty result explicitly.

Show one solution
titles = []
title = input("Title to add, or Enter to finish: ").strip()

while title != "":
    titles.append(title)
    title = input("Title to add, or Enter to finish: ").strip()

requested = input("Title to remove: ").strip()
if requested in titles:
    titles.remove(requested)
    print(f"Removed: {requested}")
else:
    print(f"Not found: {requested}")

if len(titles) == 0:
    print("The reading list is empty.")
else:
    for index in range(len(titles)):
        print(f"{index + 1}. {titles[index]}")

3. Transform, filter, and summarize

Given minutes = [12, 45, 28, 8, 33], build a new list containing hours, build another containing trips of 30 minutes or less, and report total, average, shortest, and longest trip. Put the average calculation in a function that returns None for an empty list.

Show one solution
def average(numbers):
    if len(numbers) == 0:
        return None
    return sum(numbers) / len(numbers)

minutes = [12, 45, 28, 8, 33]
hours = []
short_trips = []

for value in minutes:
    hours.append(value / 60)
    if value <= 30:
        short_trips.append(value)

print(f"Trip count: {len(minutes)}")
print(f"Total: {sum(minutes)} minutes")
print(f"Average: {average(minutes):.1f} minutes")
print(f"Shortest: {min(minutes)} minutes")
print(f"Longest: {max(minutes)} minutes")
print(f"Trips of 30 minutes or less: {short_trips}")

Run average([]) separately to verify the empty case rather than formatting None as a number.

4. Tuples, unpacking, and multiple returns

Write a function hours_and_minutes(total_minutes) that returns a two-element tuple containing complete hours and leftover minutes. Unpack and display its result for 135 minutes. Then create a list of three event tuples in the order (name, day, cost) and display them with loop unpacking.

Show one solution
def hours_and_minutes(total_minutes):
    hours = total_minutes // 60
    minutes = total_minutes % 60
    return hours, minutes

hours, minutes = hours_and_minutes(135)
print(f"135 minutes is {hours} hours and {minutes} minutes.")

events = [
    ("Repair Cafe", "Saturday", 0.0),
    ("Bike Workshop", "Tuesday", 10.0),
    ("Seed Swap", "Sunday", 0.0),
]

for name, day, cost in events:
    print(f"{name} | {day} | ${cost:.2f}")

Explain why the two returned values form a coherent fixed pair, and what each position in the event tuple means.

5. Records, schema, filter, and summary

Create at least four records for resources, books, recipes, games, plants, or another topic. Use a list of dictionaries with consistent keys, including one numeric field. Display every record, filter by one categorical field, and calculate one numerical summary. Write a four-row data dictionary before coding.

Show one example
resources = [
    {"name": "Tool Library", "area": "North", "category": "tools", "cost": 0.0},
    {"name": "Repair Cafe", "area": "Central", "category": "repair", "cost": 0.0},
    {"name": "Bike Workshop", "area": "North", "category": "transport", "cost": 10.0},
    {"name": "Seed Swap", "area": "East", "category": "garden", "cost": 0.0},
]

total_cost = 0.0
print("ALL RESOURCES")
for resource in resources:
    total_cost += resource["cost"]
    print(f"{resource['name']} | area: {resource['area']} | cost: ${resource['cost']:.2f}")

print("NORTH AREA")
matches = 0
for resource in resources:
    if resource["area"] == "North":
        print(resource["name"])
        matches += 1
print(f"Matches: {matches}")
print(f"Average listed cost: ${total_cost / len(resources):.2f}")
