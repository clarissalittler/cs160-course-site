Question #1

Write a program that asks the user for a word and counts how many vowels (a, e, i, o, u) it contains. Loop over the word one character at a time, and don't let capital letters fool you - "Apple" has two vowels, not one. Display the count.

Solution 
def main():
    # Get a word from the user
    word = input("Enter a word: ")

    # Count the vowels one character at a time
    vowels = "aeiou"
    count = 0
    for letter in word.lower():   # .lower() so capitals still match
        if letter in vowels:
            count += 1

    print(f"'{word}' has {count} vowels")

main()

Question #2

Write a program that lets the user type in test scores, one per line, until they press Enter on a blank line. Store the scores in a list. Once they're done, display how many scores were entered, the highest, the lowest, and the average. (Hint: build the list with .append(), and remember Python has len(), sum(), max(), and min() built in.)

Solution 
def main():
    scores = []   # start with an empty list

    # Keep asking until the user enters a blank line
    entry = input("Enter a score (blank to finish): ")
    while entry != "":
        scores.append(float(entry))
        entry = input("Enter a score (blank to finish): ")

    # Guard against an empty list (can't average nothing!)
    if len(scores) == 0:
        print("No scores were entered.")
    else:
        print(f"\nYou entered {len(scores)} scores.")
        print(f"Highest: {max(scores)}")
        print(f"Lowest:  {min(scores)}")
        print(f"Average: {sum(scores) / len(scores):.1f}")

main()

Question #3

A small gradebook is a list of tuples, where each tuple is a (name, score) pair:

gradebook = [("Dahlia", 92), ("Amit", 88), ("Rosa", 99), ("Kenji", 75)]

Write a program that loops over the gradebook and prints each student's name and score on its own line (use tuple unpacking - for name, score in gradebook:). Then find and print the name of the student with the highest score.

Solution 
def main():
    gradebook = [("Dahlia", 92), ("Amit", 88), ("Rosa", 99), ("Kenji", 75)]

    # Print every student, unpacking each tuple as we go
    print("Scores:")
    for name, score in gradebook:
        print(f"  {name}: {score}")

    # Track the best as we walk the list
    top_name = ""
    top_score = -1
    for name, score in gradebook:
        if score > top_score:
            top_score = score
            top_name = name

    print(f"\nTop score: {top_name} with {top_score}")

main()

Question #4

Write a program that counts how many times each word appears in a sentence, using a dictionary. Ask the user for a sentence, split it into words, and build a dictionary where each key is a word and each value is how many times that word showed up. Then print each word and its count. For example, "the cat sat on the mat" should report the twice and every other word once.

Solution 
def main():
    sentence = input("Enter a sentence: ")
    words = sentence.lower().split()   # split() breaks on spaces

    # Tally each word into the dictionary
    counts = {}
    for word in words:
        if word in counts:
            counts[word] += 1
        else:
            counts[word] = 1

    # Report the tally
    print("\nWord counts:")
    for word, number in counts.items():
        print(f"  {word}: {number}")

main()
