Lesson 3 - Patterns for Processing Collections

At the end of this lesson, you will be able to:

  • Recognize traversal, transformation, filtering, counting, accumulation, and min/max patterns.
  • Build a new list rather than accidentally destroying source data.
  • Separate collection processing from keyboard input and formatted display.
  • Test collection code with empty, one-item, typical, and boundary cases.

Most collection programs use a few recurring moves

A playlist, search page, gradebook, shopping cart, and transit app seem different, but they repeatedly perform the same jobs:

  • Traverse: visit every item.
  • Transform: produce a changed value for every item.
  • Filter: keep only items that match a condition.
  • Aggregate: combine many items into one result, such as a count or total.
  • Find an extreme: locate the smallest or largest item by some measure.

Recognizing the pattern helps you start from the logic instead of guessing syntax.

Traversal: perform one job for every item

hours = [1.5, 2.0, 0.5, 3.0]

for value in hours:
    print(f"Recorded study time: {value:.1f} hours")

The loop does not change the list. It visits and displays each element.

Transformation: build a corresponding collection

temperatures_f = [32, 50, 68, 77]
temperatures_c = []

for fahrenheit in temperatures_f:
    celsius = (fahrenheit - 32) * 5 / 9
    temperatures_c.append(celsius)

print(temperatures_c)

The result has one Celsius value for every Fahrenheit value. Building a new list preserves the source for comparison or later reuse. Replacing elements in the original may be appropriate, but it should be intentional.

Filtering: build a collection of matches

all_locations = ["online", "library", "online", "student center"]
in_person_locations = []

for location in all_locations:
    if location != "online":
        in_person_locations.append(location)

print(in_person_locations)

A filter does not change which items exist in the source; it produces a selected view. In a real interface, say what filter is active and how many matches were found. An empty result should say “No matching locations” rather than look broken.

Counting and accumulating

donations = [5.00, 12.50, 3.00, 20.00]
total = 0.0
large_donation_count = 0

for amount in donations:
    total += amount
    if amount >= 10:
        large_donation_count += 1

print(f"Total: ${total:.2f}")
print(f"Donations of at least $10: {large_donation_count}")

An accumulator begins with an identity value—0 for addition—and updates once per relevant element. A counter is an accumulator that adds 1 when a condition is met. Python provides sum(donations) and len(donations), but writing the loop once makes the state change visible and prepares you for more specialized summaries.

Minimum and maximum without a made-up starting value

wait_times = [18, 7, 24, 11]

if len(wait_times) == 0:
    print("No wait times were recorded.")
else:
    shortest = wait_times[0]
    longest = wait_times[0]

    for minutes in wait_times:
        if minutes < shortest:
            shortest = minutes
        if minutes > longest:
            longest = minutes

    print(f"Range: {shortest} to {longest} minutes")

Initialize from a real element, not from 0 or 999999. A made-up value may fail when the data changes. The empty-list branch is necessary because there is no first element to use.

Put processing in a function

def average(numbers):
    if len(numbers) == 0:
        return None

    total = 0
    for number in numbers:
        total += number
    return total / len(numbers)

result = average([4, 7, 10])
if result is None:
    print("No average is available.")
else:
    print(f"Average: {result:.1f}")

The function receives data and returns a result. It does not ask for input or decide how an entire report should look. That separation makes it easy to test:

  • average([]) should return None.
  • average([8]) should return 8.
  • average([4, 7, 10]) should return 7.

None represents the absence of a result. It is different from 0, which could be a real average.

Filters and summaries are choices about attention

A “top results” function decides what becomes visible. An average compresses variation into one number. A maximum highlights an extreme. None is inherently dishonest, but each leaves something out. When presenting a summary, label the measure, the unit, the number of records, and any filter. Ask whether missing values or excluded records systematically change the story.
