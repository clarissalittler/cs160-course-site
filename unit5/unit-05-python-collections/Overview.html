Unit 5 Overview - Collections, Data Models, and Interfaces

So far, most of our variables have held one value at a time: a name, a temperature, a score. That gets you surprisingly far, but think about almost any app on your phone. A playlist is a whole bunch of songs. Your contacts are dozens or hundreds of people, and each person is a bundle of facts (a name, a number, maybe an email). A map search gives back a list of places. The interesting programs are nearly always dealing with many things at once.

This unit is where our programs start doing that too, using collections: structures that stand for some small piece of the world. We'll look at strings as sequences of characters, build lists that grow and change, learn to spot the handful of loop patterns behind nearly every program that handles data, keep fixed groups together with tuples, and model named records with dictionaries. And then, in the last lesson, we'll turn around and ask what it means to model people this way: which facts about someone a program should store, what happens when a person doesn't fit the boxes we made, and how to build an interface that a real person can actually use.

All the required code is ordinary Python and runs in Colab, OnlineGDB, or another browser-based interpreter, so there's nothing to install.

Learning objectives

  1. Index, slice, traverse, and transform strings while recognizing limits of a simple character model.
  2. Create and modify lists and handle empty or missing values safely.
  3. Use traversal, transformation, filtering, aggregation, counting, and min/max patterns.
  4. Create, index, and unpack tuples for fixed groups, loop records, compound keys, and multiple-value returns.
  5. Represent one named record as a dictionary and several records as a list of dictionaries.
  6. Write a schema or data dictionary that explains field meanings and missing-value rules.
  7. Evaluate a text interface for privacy, inclusion, keyboard access, labels, errors, and recovery.

Five-lesson path

  1. Strings as Sequences: indexes, slices, traversal, transformation, normalization, and where the simple character model runs out.
  2. Lists and Changing Collections: create, update, add, remove, test membership, and understand why two names can point at one list.
  3. Patterns for Processing Collections: recognize the small set of loop patterns behind most information tools.
  4. Tuples, Dictionaries, and Records: use fixed positional groups, unpack returned and loop values, name fields that may change, document a schema, and choose a representation.
  5. Modeling People and Designing Interfaces: collect less, handle missing values honestly, label state and actions, and revise from usability evidence.

Learning activities and assessment

  1. Complete Lessons 1–5 and Python Practice Problems.
  2. Complete Unit 5 Quiz and the midterm covering Units 1–4.
  3. Complete Week 5 Assignment: an in-memory information tool using a list of dictionaries.
  4. Complete and share the Week 5 Activity Discussion: Break My Schema.

The assignment may be written in a Colab notebook, OnlineGDB, or another Python environment. You'll submit code, sample output, a small data dictionary, and one usability or accessibility observation along with the change it led to.
