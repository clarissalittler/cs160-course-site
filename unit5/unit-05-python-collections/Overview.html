Unit 5 Overview

So far your programs have mostly juggled one value at a time. In this unit you'll learn to work with collections - the containers Python gives you for holding many values at once. You'll start with strings (a sequence you can index, slice, and loop over character by character), then move on to lists, tuples, and dictionaries. Along the way you'll practice the loop patterns - running totals, counters, filtering - that turn a pile of data into an answer, and you'll combine collections to model real information like a table of names and scores.

Learning objectives

At the end of this learning module, you will be able to:

  1. Work with strings using indexing, slicing, and string methods. 
  2. Create and modify lists, and access their items by index. 
  3. Loop over a collection to process every item it holds. 
  4. Recognize and use common loop patterns (accumulators, counters, filtering). 
  5. Use tuples and tuple unpacking to group related values that belong together. 
  6. Store and look up data with dictionaries (key-value pairs). 
  7. Combine collections - lists of tuples, lists of dictionaries - to model real information.
