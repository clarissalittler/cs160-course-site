Lesson 1 - Working with Strings

At the end of this lesson, you will be able to:

  • Pull individual characters out of a string by index, and slice out pieces of it.
  • Loop over the characters of a string.
  • Use common string methods to transform text.

A string is a sequence of characters

You've been using strings since Unit 3 - storing them, printing them, joining them. Now that you can loop, it's the perfect time to learn how to reach inside a string. The key idea: a string is really an ordered sequence of characters, and Python lets you get at them by position.

Indexing: getting one character

Each character has a numbered position called its index, and - this surprises people - counting starts at 0, not 1. So in the word "Python", P is at index 0, y at index 1, and so on. You grab a character with square brackets:

word = "Python"
print(word[0])    # P   (the first character)
print(word[1])    # y
print(word[-1])   # n   (negative indexes count from the end)
print(len(word))  # 6   (len() tells you how many characters)

That last trick is handy: a negative index counts backward from the end, so word[-1] is always the last character, no matter how long the string is.

Slicing: getting a piece

To pull out a whole chunk, use a slice: word[start:stop]. Just like range(), the stop position is not included - the slice goes up to, but not including, it:

word = "Python"
print(word[0:3])   # Pyt   (characters 0, 1, 2 - not 3!)
print(word[2:])    # thon  (from index 2 to the end)
print(word[:2])    # Py    (from the start up to index 2)

Leave out the start and it begins at the beginning; leave out the stop and it runs to the end.

String methods

Strings come with a set of built-in methods - functions you call on a string by attaching them with a dot. You met two already (.lower() and .upper()). Here are the most useful ones:

phrase = "  Good Dogs  "
print(phrase.lower())        # "  good dogs  "
print(phrase.upper())        # "  GOOD DOGS  "
print(phrase.strip())        # "Good Dogs"   (trims spaces off the ends)
print(phrase.replace("o", "0"))  # "  G00d D0gs  "
print("banana".count("a"))   # 3   (how many times "a" appears)
print("banana".find("n"))    # 2   (index of the first "n")

Strings don't change - they hand back a new one. Notice the methods above return a new string rather than editing the original. phrase.upper() doesn't change phrase; it gives you a brand-new uppercased string. If you want to keep the result, store it: phrase = phrase.strip(). (This is why .lower() on user input is so handy for comparisons - you can clean up a copy without touching the original.)
