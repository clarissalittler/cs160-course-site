range() function

for loops can also:

  • increment by more than one
  • count backward by decrementing
  • allow the user to control the number of iterations

Instead of writing a list of values ourselves, we can use the range() function to generate the values for us. You can pass 1 - 3 arguments to range().

1 argument:

for num in range(5):   # generate 5 integers, starting with 0: 0, 1, 2, 3, 4
    print(num)

The above code is equivalent to:

for num in [0, 1, 2, 3, 4]: 
    print(num)

2 arguments:    

for num in range(start value, stop value):   
    print(num)     # all numbers from start value to 1 less than
                   # stop value will be printed 

Run the program below (Copy or download the for_loop_1.py and run in your IDE of choice) - try other integers as arguments. Try negative values, and values where the first argument is > second argument. What happens?

def main():
  for index in range(2, 10):
      print(index)

main()

Bug Alert:

Remember, for num in range(2, 10) will generate the sequence of numbers: 2, 3, 4, 5, 6, 7, 8, 9 and will NOT include 10!

3 arguments:

for num in range(start value, stop value, step value):   
    print(num) # numbers starting at start value, adds step value after each iteration,
               # stop value is an integer specifying at which position to stop (not including the stop value).

Run the program below (Copy from or download the for_loop_2.py and run in your IDE of choice) - try other integers as arguments. Can you step backward from 10 to 1?

def main():
    # step up by 2
    for index in range(2, 10, 2):
        print(index)

    print()

    # step down by 1
    for index in range(10, 1, -1):
        print(index)
        
main()
