Iteration Structures

Iteration structure

Iteration (Repetition) is an operation that causes looping, repeating a block of instructions.

Important facts about iteration:

  • Iteration structures make the computer repeat the code as necessary.
  • Iteration structures include condition-controlled loops and count-controlled loops.
  • A condition-controlled loop uses a true/false condition to control the number of times repeated.
  • A count-controlled loop repeats a specific number of times.
