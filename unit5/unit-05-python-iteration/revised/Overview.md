# Unit 5 Overview

![Unit 5 banner](img/banner.jpg)

Welcome to Unit 5! This is where your programs learn to be *persistent*.

Up to now, our code has been a one-shot deal --- it runs through, makes a decision or two, and that's it. But real programs need to do things *over and over*. Think about a login screen that keeps asking for your password until you get it right, or a game that keeps running until somebody wins. That's **iteration** --- also called repetition --- and it's one of the most powerful ideas in programming.

You'll learn two kinds of loops this unit: `while` loops (which keep going as long as some condition is true) and `for` loops (which repeat a specific number of times). You'll also use loops to do something genuinely practical --- **input validation**, where your program checks whether the user typed in something reasonable and politely asks again if they didn't.

## After this unit, you'll be able to:

1. Use `while` and `for` loops to perform repetition (iteration)
2. Use loops to perform input validation
3. Use pair programming to develop a program
