Unit 5 Summary

Wrap up

In this unit, you learned how to repeat a group of statements using an iteration structure. You learned how to use a condition-controlled loop, where the loop continues until a condition becomes False, and a count-controlled loop, to loop a set number of times. You learned to work with strings character by character, to build running totals and validate user input with common loop patterns, and to generate random numbers.

Summary

  • The while loop is a condition-controlled loop and will continue while a condition is True.
  • It is important to ensure the condition becomes False at some point in the loop, otherwise, you will create an infinite loop.
  • The for loop is a count-controlled loop and will iterate a specified number of times.
  • Use the range() function to generate a list of numbers to iterate through with the for loop.
  • Use a while loop to perform input validation. While the user input is incorrect, print an error and prompt again.
  • A string is a sequence of characters: you can index it, slice it, loop over it one character at a time, and transform it with methods like .lower() and .strip().
  • The accumulator pattern uses a variable created before a loop and updated inside it to build a running total or count; a sentinel value can be used to signal a loop to stop.
  • Random numbers can be generated using the randint() function after importing the random module. Use import random at the top of the program.
