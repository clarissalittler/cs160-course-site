The while loop is a condition-controlled loop. The statements in the loop will continue to execute while some condition is true.

The while loop has two parts:

  • A condition to test for true or false
  • Statement(s) block to be repeated while the condition is true

Some important things to consider:

  • In order for a loop to stop executing, something has to happen inside the loop to make the condition false.
  • An iteration is one execution of the body of a loop.
  • The while loop is a pretest loop, meaning it tests the condition before performing an iteration. If the condition is false to begin with, the statements in the loop will not execute at all.

Step through the program below:

The while loop will repeat the body of the loop as long as a logical expression is true. The body of the loop is the statement or statements that are indented 4 or more spaces to the right of the while statement. A logical expression is one that is either true or false like x > 3.

while loops are typically used when you don’t know how many times to execute the loop. For example, when you play a game you will repeat the game while there isn’t a winner. If you ever played musical chairs you walked around the circle of chairs while the music was playing.

Bug Alert: If the statements in the loop do not cause the condition to become false, the loop will go on forever (not really - your program would eventually crash with a stack overflow error!). This is called an infinite loop.:

num = 1
while num != 10:
     print(num)
     num = num + 2

def main():
    num = 0

    while True:
        num = int(input("Enter an integer: "))
        if num == 0:
            print("0 is neither + or -.\n")
        elif num > 0:
            print(num, "is positive.\n")
        else:
            print(num, "is negative.\n")

    print("Goodbye!")

main()
