Modules: borrowing code that already exists

You don't have to write everything from scratch. Python comes with a huge Standard Library - collections of ready-made functions, organized into modules, that you can pull into your program with import. Here are a few you'll run into:

The random module

To use a module, put import at the top of your program. The random module's most useful function is random.randint(a, b), which gives back a random whole number between a and b (both ends included):

# This program displays a random number in the range 1 through 10.
import random

def main():
    # Get a random number 1-10 and store it in 'number'
    number = random.randint(1, 10)
    print('The number is', number)

main()

Run it a few times - you'll get a different number almost every time. That unpredictability is what makes games fun (dice rolls, shuffled cards, enemy behavior) and is useful far beyond games.

Putting it all together: a guessing game

Here's a complete program that uses almost everything from this unit - a random answer, a while loop that runs until the guess is right, counters for the accumulator pattern, and input validation. (It also uses try/except, which is Python's way of catching errors gracefully - here, catching when someone types something that isn't a number. You don't need to master it yet; just notice it's there.)

import random

def main():
    answer = random.randint(1, 10)
    guess = 0
    too_high = 0
    too_low = 0

    print("Guess a number between 1 and 10!")
    while guess != answer:
        valid = False
        while not valid:
            try:
                guess = int(input("\nEnter guess: "))
                if guess < 1 or guess > 10:
                    print("Guess must be 1-10")
                else:
                    valid = True
            except:
                print("Not an integer!")

        if guess == answer:
            print("Correct!!")
        elif guess > answer:
            print("Too high!")
            too_high += 1
        else:
            print("Too low!")
            too_low += 1

    print(too_high, "of your guesses were too high.")
    print(too_low, "of your guesses were too low.")
    print("\nThank you for playing!")

main()
