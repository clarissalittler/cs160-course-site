Unit 5 Overview

In this unit, you will be learning about iteration (also called repetition), which is a programming construct for repeating blocks of statements while - or until - a condition is true. You'll use loops to build running totals, validate user input, and process text, since a string turns out to be a sequence you can loop over character by character.

Learning objectives

At the end of this learning module, you will be able to:

  1. Use while and for loops to perform repetition (iteration). 
  2. Work with strings using indexing, slicing, and string methods.
  3. Use loops to perform input validation.
  4. Use pair programming to develop a program.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

  1. Complete Lessons 1 - 5 and Python Practice Problems (LOs 1-4)
  2. Complete Quiz 5 (LOs 1, 2, 3)
  3. Complete and submit Lab 3 (LOs 1, 2, 3)
  4. Complete Midterm Exam (Unit 1-4 LOs)
  5. (Individual) Post to discussion Unit 5 Lesson 4 - Budget Program (LOs 1, 3, 4)
  6. (Individual) Post to discussion Unit 5 Lesson 2 - Tuition Program (LOs 1, 4)
