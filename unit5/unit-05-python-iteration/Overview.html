Unit 5 Overview

In this unit, you will be learning about iteration (also called repetition), which is a programming construct for repeating blocks of statements until a condition is true, or while a condition is true. You will use iteration to perform input validation - where you validate user input for correctness and prompt again if it is incorrect. 

Learning objectives

At the end of this learning module, you will be able to:

  1. Use while and for loops to perform repetition (iteration). 
  2. Use loops to perform input validation.
  3. Use pair programming to develop a program.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

    1. Complete Lessons 1 - 6 and Python Practice Problems (LOs 1-3)
    2. Complete Quiz 5 (LOs 1, 2, 3)
    3. Complete and submit Lab 3 (LOs 1, 2, 3)
    4. Complete Midterm Exam (Unit 1-4 LOs)
    5. (Individual) Post to discussion Unit 5 Lesson 2 - Budget Program (LOs 1-3)
    6. (Individual) Post to discussion Unit 5 Lesson 4 - Tuition Program (LOs 1-3)
