Unit 4 Summary

Your programs came into this unit as straight lines and left with a vocabulary and choices. A function tucks a whole process under a name. Parameters let each call bring its own input, and return lets the result flow back into the surrounding program. Boolean expressions answer yes-or-no questions; conditionals act on those answers; and while loops keep acting until an answer changes.

What to carry forward

  • def name(): defines a function; name() calls it. Defining does not perform the body.
  • A parameter is a local name in a definition; an argument is a value supplied by a call.
  • print displays to a person. return hands a value back so code can store or reuse it.
  • A function contract states expected inputs, returned result or visible effect, and relevant limits.
  • Comparisons such as ==, !=, <, <=, >, and >= produce Booleans.
  • = assigns; == compares.
  • An if/elif/else chain checks top to bottom and runs only the first matching branch.
  • and requires both conditions, inclusive or requires at least one, and not reverses a Boolean.
  • Test below, at, and above each boundary, and create at least one test for every branch.
  • A while loop needs initialization, a condition, and an update that provides a path to termination.
  • Use for when a count or sequence explains the repetitions; use while when a changing condition explains them.
  • Categories, thresholds, validation rules, and exits are design decisions that affect people. Technical correctness does not settle whether a policy is fair or a user experience is respectful.

Synthesis check

def describe_number(number):
    if number % 2 == 0:
        return "even"
    else:
        return "odd"

reply = ""
while reply != "quit":
    number = int(input("Enter a whole number: "))
    print(f"That number is {describe_number(number)}.")
    reply = input("Press Enter to continue or type quit: ").strip().lower()

See if you can point to everything at once: the function definition, the parameter, the arguments, the return values, the comparison, the branches, and the loop's initialization, condition, and update. Then name one input the program handles and one reasonable input it can't handle yet.
