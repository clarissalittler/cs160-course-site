Unit 4 Summary

Your programs came into this unit as straight lines and are leaving with a vocabulary and the ability to make choices. A function puts a whole process under one name. Parameters let each call bring its own input, and return sends the result back out to the program. Boolean expressions answer yes-or-no questions, if statements act on the answers, and while loops keep acting until an answer changes.

What you'll keep using

  • def name(): defines a function; name() calls it. Defining a function doesn't run it.
  • A parameter is the name in the definition; an argument is the value a call supplies for it.
  • print shows something to a person. return hands a value back to the program so it can be stored or used.
  • A function contract says what the function expects, what it gives back or does, and what it doesn't handle.
  • Comparisons such as ==, !=, <, <=, >, and >= produce Booleans.
  • = assigns; == compares.
  • An if/elif/else chain checks top to bottom and runs only the first branch whose condition is true.
  • and needs both sides true, or needs at least one (both is fine), and not flips a Boolean.
  • Test below, at, and above every boundary, and make sure at least one test reaches every branch.
  • A while loop needs an initialization, a condition, and an update that eventually makes the condition false.
  • Use for when a count or a sequence says how many times to repeat; use while when a changing condition does.
  • Categories, thresholds, validation rules, and exits are design decisions that land on real people. A program can be correct and still be unfair or unpleasant to use.

Synthesis check

def describe_number(number):
    if number % 2 == 0:
        return "even"
    else:
        return "odd"

reply = ""
while reply != "quit":
    number = int(input("Enter a whole number: "))
    print(f"That number is {describe_number(number)}.")
    reply = input("Press Enter to continue or type quit: ").strip().lower()

See if you can point to everything at once: the function definition, the parameter, the argument, the return values, the comparison, the branches, and the loop's initialization, condition, and update. Then name one input this program handles and one entirely reasonable input it can't handle yet.
