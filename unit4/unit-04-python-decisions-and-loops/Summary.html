Unit 4 Summary

Wrap up

In this unit, you learned the two big tools for controlling the flow of a program: decisions and loops. The if, if-else, and if-elif-else statements let a program choose what to do; relational and logical operators build the conditional expressions that drive those choices, each evaluating to a Boolean - either True or False. Then while and for loops let a program repeat work automatically, so you can process a whole sequence of values without writing the same line over and over.

Summary

  • Relational operators >, <, >=, <=, ==, and != are used to create conditional expressions.
  • The result of a conditional expression is either True or False.
  • The if statement is used to execute a group of statements if a condition is True.
  • The if-else statement is used to execute a group of statements if a condition is True or a different group of statements if the condition is False. Only one group will be executed.
  • Use the if-elif-else statement to create a list of conditions, the first condition to become True will execute, and the remaining will not be evaluated.
  • Logical operators and, or, and not combine true/false values to build more complex conditions.
  • Decisions can be nested inside other decisions, and a function that returns True or False can be used directly inside an if statement.
  • A while loop repeats a block of code as long as its condition stays True - handy when you don't know in advance how many times you'll need to repeat.
  • A for loop repeats once for each item in a sequence, and range(start, stop, step) generates the sequence of numbers to loop over.
  • Watch out for infinite loops: a while loop whose condition never becomes False will run forever.
