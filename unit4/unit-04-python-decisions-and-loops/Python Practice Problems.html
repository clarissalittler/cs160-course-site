Unit 4 Python Practice Problems

These problems follow the same path as the lessons: name an action, vary it, return a result, choose a branch, then repeat while a condition holds. Before you open any solution, trace at least one call or loop by hand and write down the tests your program has to pass, so that when you do look at a solution you have something of your own to compare it against.

1. Reusable event card

Define show_event(name, location, time). It should print the event's name and then its location and time, labeled. Call it for three different events. The function shouldn't ask for input; each call hands it everything it needs.

Show one solution
def show_event(name, location, time):
    print("--------------------")
    print(name)
    print(f"Location: {location}")
    print(f"Time: {time}")

show_event("Repair café", "Library room 2", "Saturday at 1 PM")
show_event("Open mic", "Student center", "Tuesday at 4 PM")
show_event("Study jam", "Online", "Thursday at 6 PM")

Contract: the function expects three strings and prints one labeled event card. It doesn't return anything.

2. Ticket price function

Define ticket_price(age, hour). A show before hour 17 is a matinee. Matinee prices are $6 for ages 12 and under, $7 for ages 65 and up, and $9 otherwise. Evening prices are $8, $9, and $12 for those same groups. Return the price; do not print inside the function. Test every category and at least the boundary ages 12, 13, 64, and 65.

Show one solution
def ticket_price(age, hour):
    if hour < 17:
        if age <= 12:
            return 6.00
        elif age >= 65:
            return 7.00
        else:
            return 9.00
    else:
        if age <= 12:
            return 8.00
        elif age >= 65:
            return 9.00
        else:
            return 12.00

age = int(input("Moviegoer's age: "))
hour = int(input("Showtime hour from 0 through 23: "))
price = ticket_price(age, hour)
print(f"Ticket price: ${price:.2f}")

Notice that the function doesn't do anything special for an age of -3 or an hour of 40. A complete specification would say what should happen for inputs like that, and then the function would need a branch for them.

3. Restaurant filters

A group needs restaurant suggestions. Ask whether anyone needs vegetarian, vegan, or gluten-free choices. Normalize each answer with .strip().lower(), then display every restaurant that meets the stated requirements:

  • Screen Door: none of the three accommodations
  • Grassa: vegetarian and gluten-free, but not vegan
  • Oven and Shaker: all three
  • Verde Cocina: vegetarian, but not vegan or gluten-free
  • Bamboo Sushi: all three
Show one solution
vegetarian = input("Vegetarian option needed? yes/no: ").strip().lower()
vegan = input("Vegan option needed? yes/no: ").strip().lower()
gluten_free = input("Gluten-free option needed? yes/no: ").strip().lower()

print("Restaurants that match:")

if vegetarian == "no" and vegan == "no" and gluten_free == "no":
    print("Screen Door")
if vegan == "no":
    print("Grassa")
print("Oven and Shaker")
if vegan == "no" and gluten_free == "no":
    print("Verde Cocina")
print("Bamboo Sushi")

Why separate if statements rather than an if/elif chain? Because several restaurants can match at once, and an elif chain stops after the first true branch. (Also: menus change. A real version of this would need dated, verified data and should tell people to check with the restaurant.)

4. Explainable category function

Define a function that accepts a numerical value and returns one of at least three labeled categories. You might classify how long a book takes to read, or the air quality on a smoky day, or anything else you can explain. Include an out-of-range branch if the input has meaningful limits.

Make a table of tests below, at, and above every threshold. In a comment, say who chose the thresholds, or say plainly that you made them up for practice.

Show one example
# Fictional practice categories, not medical or policy guidance.
def describe_focus_session(minutes):
    if minutes < 0:
        return "invalid duration"
    elif minutes <= 10:
        return "short"
    elif minutes <= 30:
        return "medium"
    else:
        return "long"

for test_minutes in range(9, 33):
    if test_minutes == 9 or test_minutes == 10 or test_minutes == 11 or test_minutes == 30 or test_minutes == 31:
        print(test_minutes, describe_focus_session(test_minutes))

The for loop at the bottom is review from Unit 3. It runs the boundary tests for us so we don't have to type six separate calls, while the function above it holds the rule being tested.

5. Yes/no validation

Ask whether the user wants a text description of an artifact. Keep asking until the normalized response is yes or no, then print a message that confirms the choice.

Show one solution
reply = input("Include a text description? yes/no: ").strip().lower()

while reply != "yes" and reply != "no":
    print("I didn't recognize that response. Please type yes or no.")
    reply = input("Include a text description? yes/no: ").strip().lower()

if reply == "yes":
    print("A text description will be included.")
else:
    print("No additional description was requested.")

Test YES, an answer with extra spaces around it, a made-up word followed by no, and a blank answer followed by yes.

6. Open-ended running total

Ask for volunteer-hour entries until the user enters a negative number as the sentinel. Display the total, which must not include the sentinel. Then explain why while says what's going on here better than a fixed for loop would.

Show one solution
total_hours = 0.0
hours = float(input("Hours, or a negative number to finish: "))

while hours >= 0:
    total_hours += hours
    hours = float(input("Hours, or a negative number to finish: "))

print(f"Total volunteer time: {total_hours:.1f} hours")

Test entering the sentinel right away, one entry followed by the sentinel, and several entries including a zero.
