if-elif-else statement

We can use an if-elif-else selection structure when we have more than one condition to test.  In the image below, when the statement executes, condition_1 is tested. If condition_1 is true, the block of statements that immediately follow is executed, up to the elif clause. The rest of the structure is ignored. If condition_1 is false, however, the program jumps to the very next elif clause and tests condition_2. If it is true, the block of statements that immediately follow is executed, up to the next elif clause. The rest of the structure is then ignored. This process continues until a condition is found to be true, or no more elif clauses are left. If no condition is true, the block of statements following the else clause is executed.

It is important to remember, when the testing starts, when the first condition evaluates to true, that block is executed and no more testing will be performed. The flow will jump outside the structure and continue on.

Input validation

What if the user enters a percentage of 104 or -99? Plan for user input errors and validate for good input. In the code below, move the first if condition to test if the grade is >= 90 down to the first elif, and replace with an if to validate if the grade is in the range of 0 to 100:

if grade < 0 or grade > 100:
     print("Invalid. Grades must be between 0 - 100.")

Run the program and test with both valid and invalid grades! (Copy from below or download the grades.py and run in your IDE of choice.)

def main():
    grade = float(input('Enter final grade percentage: '))
    
    if grade >= 90:
        print('\nYour grade is \'A\'. Please register for CS161.')
    elif grade >= 80:
        print('\nYour grade is \'B\'. Please register for CS161.')
    elif grade >= 70:
        print('\nYour grade is \'C\'. Please register for CS161.')
    elif grade >= 60:
        print('\nYour grade is \'D\'. You did not pass. Please register for CS160 again.')
    else:
        print('\nYour grade is \'F\'. You did not pass. Please register for CS160 again.')
        
    print('\nTime to register for next term now.')
