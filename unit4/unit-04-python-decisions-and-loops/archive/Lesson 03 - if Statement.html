if statement

The if statement is a conditional statement used to create a selection structure, which allows a program to have more than one path of execution. The if statement causes one or more statements to execute only when a Boolean expression is true.

Consider the following program - the if statement checks the gas gauge, and if the tank has less than 2 gallons of gas, a message is printed to get gas. 

if tank < 2:
     print('Time to get gas!')

The message will only print if the tank is low. If the tank is not low, the program continues.
