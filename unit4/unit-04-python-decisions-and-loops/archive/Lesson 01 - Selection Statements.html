Sequential structure

A control structure is a logical design that controls the order in which a set of statements execute. So far, we have used only the simplest type of control structure: the sequential structure. The sequential structure in figure 4.1 is a set of statements that execute in the order in which they appear - from top to bottom.

Three basic sequential operations:

  • Computation: a single numeric calculation
  • Input: gets data values from outside the algorithm
  • Output: sends data values to the outside world

Selection structure

Sometimes we want statements to be executed only under certain conditions. Programs like this require a different type of control structure. This can be accomplished with the selection structure shown in figure 4.2. Note, the first step in the figure would be a test that answers TRUE or FALSE, for example, "is X equal to Y?". This test is called a conditional expression.

Selection control structures use conditional statements to ask a question and select among alternative options:

  • Evaluate the true/false condition
  • If the condition is true, then do the first set of operations and skip the second set
  • If the condition is false, skip the first set of operations and do the second set

Regardless of whether the first or second set is executed, execution then continues with any statement(s) immediately following the two sets of statements, as indicated in figure 4.2 by the two arrows converging after the TRUE and FALSE sets.
