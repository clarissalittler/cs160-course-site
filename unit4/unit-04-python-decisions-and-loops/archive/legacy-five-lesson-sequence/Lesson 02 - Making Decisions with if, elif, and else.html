The if statement

The if statement is the simplest decision: it runs a block of code only if a condition is true, and otherwise skips right over it. You write the keyword if, a condition, and a colon - then indent the code that should run when the condition holds:

if-else: choosing between two paths

Often you want to do one thing if a condition is true and a different thing if it's false. That's if-else: exactly one of the two blocks runs, never both, never neither.

if-else Statements

if-elif-else: choosing among many paths

What if there are more than two possibilities - like letter grades A, B, C, D, F? You chain conditions with elif (short for "else if"). Python checks them in order, runs the first one that's true, and skips all the rest. The optional else at the end is a catch-all for "none of the above."

def main():
    grade = float(input('Enter final grade percentage: '))

    if grade >= 90:
        print("Your grade is an 'A'. Please register for CS161.")
    elif grade >= 80:
        print("Your grade is a 'B'. Please register for CS161.")
    elif grade >= 70:
        print("Your grade is a 'C'. Please register for CS161.")
    elif grade >= 60:
        print("Your grade is a 'D'. You did not pass. Please register for CS160 again.")
    else:
        print("Your grade is an 'F'. You did not pass. Please register for CS160 again.")

main()

if-elif-else Statement

Validating input: the grade program happily accepts -5 or 200, which aren't real percentages. A good habit is to check for bad input first and handle it before the real logic:

if grade < 0 or grade > 100:
    print("Invalid. Grades must be between 0 and 100.")

(That or is next lesson's topic - for now, just read it as plain English: the grade is bad if it's below 0 or above 100.)

An if-statement is a tiny piece of policy. Every condition you write draws a line and treats the two sides of it differently. When a bank writes if credit_score > 700: to decide who gets a loan - or an insurer, a landlord, or an admissions office writes something like it - that one line hardens a human judgment call into an automatic rule that runs the same way on everyone, no exceptions and no appeal. And the threshold came from somewhere: someone picked 700, using data that already reflects who has had access to credit in the first place. As you start writing conditions, it's worth asking our three questions: who benefits from where this line is drawn, who's harmed by landing on the wrong side of it, and who got to decide the cutoff?
