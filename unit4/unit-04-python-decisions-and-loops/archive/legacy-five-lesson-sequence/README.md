# Legacy five-lesson Unit 4 sequence

This directory preserves the active Unit 4 lessons from immediately before the July 2026 refactor. That sequence began with Booleans and decisions and ended with both loop types. The replacement sequence begins by defining functions, builds parameters and return values, then introduces Boolean questions, decisions, and condition-controlled repetition; counted `for` loops now begin in Unit 3.
