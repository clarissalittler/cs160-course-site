Unit 4 Overview - Functions, Decisions, and Repetition

Unit 3 gave you a direct path from an idea to a small running program. This unit makes those programs reusable and responsive. You will name a group of steps as a function, vary each call with parameters, return results, ask Boolean questions, choose among branches, and repeat while a condition remains true.

The technical thread and the social thread are inseparable here. A function name can clarify or conceal behavior. Parameters determine which variations a tool permits. Comparisons create boundaries. Conditional branches turn human rules into automated outcomes. Validation can support users or trap them. We will test not only whether the program follows its rules, but also what those rules mean.

Learning objectives

At the end of this unit, you will be able to:

  1. Define and call functions, including functions with parameters and return values.
  2. Write and test Boolean expressions using comparisons and logical operators.
  3. Use if, elif, and else to create reachable, understandable branches.
  4. Use while for input validation or condition-controlled repetition and explain termination.
  5. Choose between for and while based on the reason repetition stops.
  6. Test functions, boundaries, branches, and loops with normal, boundary, and invalid cases.

Five-lesson path

  1. Functions as Named Actions: turn a meaningful or repeated block into a new verb and call it more than once.
  2. Parameters and Return Values: vary calls and hand computed results back to the program.
  3. Boolean Questions and Comparisons: create yes-or-no values and test the boundaries.
  4. Decisions and Logical Operators: choose among paths and translate compound rules into inspectable code.
  5. while Loops and Validation: repeat until a condition changes while preserving a clear way out.

Learning activities and assessment

  1. Complete Lessons 1–5 and the Python Practice Problems.
  2. Complete Unit 4 Quiz.
  3. Complete one Week 4 creative-programming route: the ColabTurtle project or a text-first quiz/oracle or branching-radio-play notebook.
  4. Complete and share the Week 4 Activity Discussion: Personality Quiz.

Every Week 4 assignment route asks you to define an original function, call it more than once, and make at least one meaningful conditional choice. Parameters and loops give you ways to make the artifact richer, but the medium—visual drawing or text-first interaction—is your choice.
