Unit 4 Overview

This unit is about two of the most powerful ideas in all of programming: how to make your programs decide, and how to make them repeat. First you'll learn to alter the flow of control using conditional statements - questions with two possible answers, true or false, yes or no. You'll write if, if-else, and if-elif-else statements using comparison and logical operators, and see how logic gates direct the flow of information inside the processor. Then you'll teach your programs to repeat work automatically with while and for loops - so that a handful of lines can do the work of hundreds.

Learning objectives

At the end of this learning module, you will be able to:

  1. Alter the flow of a program using the selection structure (if, elif, else). 
  2. Create conditional expressions resulting in boolean results (true or false). 
  3. Explain how logic gates direct the flow of information. 
  4. Make use of logical operators to build complex boolean expressions. 
  5. Use while and for loops (with range) to repeat actions and process sequences of values. 
  6. Develop a program using pair programming.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

  1. Complete Lessons 1 - 5 and Python Practice Problems (LOs 1-6)
  2. Complete Quiz 4 (LOs 1, 2, 4, 5)
  3. Complete and submit Week 4 Assignment (LOs 1, 2, 4, 5)
  4. Complete and share the Week 4 Activity Discussion: Personality Quiz
