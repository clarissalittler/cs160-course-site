Unit 4 Overview

In this unit, you will learn how to alter the flow of control in your programs by using conditional statements - questions with two possible answers - true or false, yes or no. You will create conditional statements, if, if-else, and if-elif-else, using relational operators. You will also learn how logic gates are used in the processor to direct the flow of information.

Learning objectives

At the end of this learning module, you will be able to:

  1. Learn how to alter the flow of programs using the selection structure. 
  2. Create conditional expressions resulting in boolean results (true or false). 
  3. Develop a program using pair programming. 
  4. Explain how logic gates direct the flow of information. 
  5. Make use of logical operators to build complex boolean expressions.

Learning activities

You are expected to do the following tasks to achieve the above objectives:

    1. Complete Lessons 1 - 6 and Python Practice Problems (LOs 1-5)
    2. Complete Quiz 4 (LOs 1, 2, 4, 5)
    3. Complete and submit Assignment 2 (LOs 1, 2, 4, 5)
    4. (Partner) Post to discussion Unit 4 Lesson 5 - Practice Program (LOs 1-3, 5)

    If you have questions, you can post them in the Course Lobby or send your instructor an email.
