# Unit 4 Overview

![Unit 4 banner](img/banner.jpg)

Welcome to Unit 4! This is where your programs start getting *smart*.

Up until now, everything we've written has been strictly sequential --- the computer just plows through your code line by line, top to bottom, no questions asked. That changes this week. We're going to teach our programs how to make decisions by asking questions that have exactly two possible answers: **true** or **false**, **yes** or **no**.

You'll learn how to write conditional statements --- `if`, `if-else`, and `if-elif-else` --- using relational operators. You'll also get a look at how logic gates work inside the processor to direct the flow of information. It's honestly pretty cool how everything connects.

## After this unit, you'll be able to:

1. Alter the flow of programs using the selection structure
2. Create conditional expressions that produce Boolean results (`True` or `False`)
3. Develop a program using pair programming
4. Explain how logic gates direct the flow of information
5. Use logical operators to build complex Boolean expressions
