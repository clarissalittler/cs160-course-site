Unit 4 Summary

Wrap Up

In this unit, we learned how to alter the flow of our programs using selection structures. The if, if-else, and if-elif-else statements let us make decisions — our programs can now choose what to do based on conditions. We used relational operators to create conditional expressions that boil down to a Boolean result: either True or False.

That's a big deal! Before this unit, our programs just marched straight through from top to bottom. Now they can branch, react, and handle different situations. That's where things start to get interesting.

Key Takeaways

  • Relational operators (>, <, >=, <=, ==, and !=) are used to create conditional expressions.
  • The result of a conditional expression is always either True or False — nothing in between.
  • The if statement executes a group of statements only if a condition is True.
  • The if-else statement gives you two paths: one group of statements runs if the condition is True, and a different group runs if it's False. Only one group ever executes.
  • The if-elif-else statement lets you chain together a list of conditions. The first condition that evaluates to True wins — its block runs, and the rest aren't even checked.
