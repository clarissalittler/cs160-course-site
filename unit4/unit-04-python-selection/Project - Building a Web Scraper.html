What You'll Need

You'll need two Python libraries: requests (for fetching web pages) and beautifulsoup4 (for parsing HTML). Install them by running this in your terminal or in a Google Colab cell:

pip install requests beautifulsoup4

If you're using Google Colab, put an exclamation mark in front: !pip install requests beautifulsoup4. (Colab might already have them installed, but it doesn't hurt to run it anyway.)

The Code

Here's a complete, working web scraper. We're going to use a website called books.toscrape.com, which is a practice site specifically designed for people learning to scrape. (More on why that matters in a minute.)

Copy this into your Python environment and run it:

import requests
from bs4 import BeautifulSoup

url = "http://books.toscrape.com/"
response = requests.get(url)
soup = BeautifulSoup(response.text, "html.parser")

# Find all book listings on the page
books = soup.find_all("article", class_="product_pod")

for book in books:
    title = book.h3.a["title"]
    price = book.find("p", class_="price_color").text
    print(f"{title} - {price}")

Run it. You should see a list of book titles and prices printed out — data that was just sitting on a web page, now neatly extracted by your code.

What's Happening Here?

Let's walk through it piece by piece.

requests.get(url)

This sends an HTTP GET request to the website — the exact same kind of request your browser sends when you visit a page. (If you did the Unit 2 project, you typed one of these by hand!) The server sends back the HTML, and requests stores it in response.

BeautifulSoup(response.text, "html.parser")

This takes the raw HTML text and parses it — meaning it builds a structured representation that Python can navigate. Think of it like turning a big wall of text into a neatly organized tree you can search through. The variable soup now contains the entire page in a format Python can work with.

soup.find_all("article", class_="product_pod")

This searches through the parsed HTML for every <article> tag that has the CSS class product_pod. On this particular site, each book listing is wrapped in one of these tags. The function returns a list of all matches — one per book.

The for loop

This is a for loop — it goes through each book one at a time. You haven't formally learned for loops yet (that's Unit 5), but the idea is straightforward: "for each book in the list, do the following." If you used turtle graphics in Assignment 1, you've already seen this pattern.

Extracting the data

book.h3.a["title"] navigates down into each book's HTML to find the <h3> tag, then the <a> (link) tag inside it, and grabs the title attribute. book.find("p", class_="price_color").text finds the paragraph with the price and grabs its text content. This is essentially what Google does — at a much, much larger scale.

The Connection to Unit 4

So where do if-statements and functions come in? Real scrapers are full of them. What if a book listing is missing a price? What if the title is blank? You'd use selection statements to handle those cases:

for book in books:
    title_tag = book.h3.a
    price_tag = book.find("p", class_="price_color")

    if title_tag and price_tag:
        title = title_tag["title"]
        price = price_tag.text
        print(f"{title} - {price}")
    else:
        print("(incomplete listing, skipping)")

And you'd use functions to organize the logic into reusable pieces — one function to fetch a page, another to extract book data, another to save results. The building blocks from this unit are exactly what real-world scraping code is made of.

Web scraping etiquette — this matters. Don't hammer a server with thousands of requests per second. Check if a site has a robots.txt file (try visiting http://books.toscrape.com/robots.txt). Some sites explicitly prohibit scraping in their terms of service. books.toscrape.com is a practice site specifically designed for learning — always use practice sites when you're learning. Don't scrape your bank, your school's website, or a site that asks you not to.

Experiment!

Try this:

  • Change the URL to page 2: "http://books.toscrape.com/catalogue/page-2.html". Do you get different books?
  • Each book has a star rating. Can you figure out which HTML element contains it? (Hint: look at the class attribute of one of the <p> tags inside each book. You might want to add print(book) inside the loop to see the raw HTML for one listing.)
  • Try printing just the books that cost less than a certain amount. You'll need to strip the pound sign from the price and convert it to a number — then use an if statement to filter. This is Unit 4 in action!
  • Visit http://books.toscrape.com/ in your actual browser, right-click on a book title, and select "Inspect Element." You'll see the same HTML structure your code is navigating. It's not magic — it's just reading HTML.
