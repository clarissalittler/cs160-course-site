Lesson 8 – Functions: Parameters and Arguments

At the end of this lesson, you will be able to:

  • Define functions that accept parameters.
  • Call functions with arguments.
  • Explain the difference between a parameter and an argument.
  • Write functions with multiple parameters.

Making Functions Flexible

In the last lesson, we wrote functions that always do the exact same thing every time you call them. That's useful—but a bit limiting. Think about print(). If it could only ever print one fixed message, it'd be pretty useless, right? The whole point of print() is that you give it different things to print: print("Hello"), print(42), print(name).

The stuff you put in the parentheses is what makes the function flexible. And now it's time to learn how to do that with your own functions.

Parameters: The Input to Your Function

Let's start with a simple greeting function. In Lesson 7, we might have written something like this:

def greet():
    print("Hello! Welcome to CS 160!")

That greets everyone the same way. But what if we want to greet different people by name? We add a parameter:

def greet(name):
    print(f"Hello, {name}! Welcome to CS 160!")

greet("Clarissa")
greet("Marcus")
greet("Priya")

Output:

Hello, Clarissa! Welcome to CS 160!
Hello, Marcus! Welcome to CS 160!
Hello, Priya! Welcome to CS 160!

See what happened? We put name inside the parentheses in the function definition. That's a parameter—it's a variable that acts as a placeholder. It says "when someone calls this function, they'll give me a value, and I'll call that value name."

When we write greet("Clarissa"), the string "Clarissa" is the argument—it's the actual value we're passing in. Python takes that argument and assigns it to the parameter name, and then the function body runs with name set to "Clarissa".

Here's the vocabulary in a nutshell:

  • Parameter = the variable name in the function definition. It's the slot.
  • Argument = the actual value you pass when you call the function. It's what fills the slot.

Don't stress too much about memorizing which is which—honestly, most programmers use the words interchangeably in casual conversation. But it's good to know the distinction.

Try it! Write a function called compliment that takes one parameter, name, and prints something like "Hey [name], you're doing great!" Call it with three different names.

Multiple Parameters

Functions aren't limited to a single parameter. You can have as many as you need—just separate them with commas:

def introduce(name, city, food):
    print(f"Hi, I'm {name} from {city}.")
    print(f"My favorite food is {food}.")

introduce("Clarissa", "Portland", "pho")
introduce("Sam", "Eugene", "tacos")
introduce("Kenji", "Bend", "ramen")

Output:

Hi, I'm Clarissa from Portland.
My favorite food is pho.
Hi, I'm Sam from Eugene.
My favorite food is tacos.
Hi, I'm Kenji from Bend.
My favorite food is ramen.

Three parameters, three arguments each time. Python matches them up by position—the first argument goes to the first parameter, the second to the second, &c.

Try it! Write a function called describe_pet that takes two parameters: animal and name. It should print something like "I have a dog named Biscuit." Call it a few times with different pets.

Order Matters

Since arguments are matched to parameters by position, the order you pass them in matters. Watch what happens if we mix things up:

def describe_pet(animal, name):
    print(f"I have a {animal} named {name}.")

describe_pet("Biscuit", "dog")

Output:

I have a Biscuit named dog.

Oops. Python doesn't know that "Biscuit" is a name and "dog" is an animal—it just puts the first argument into the first parameter and the second into the second. So order matters.

There's a way around this, though. You can use keyword arguments—you explicitly say which parameter each argument goes to:

describe_pet(name="Biscuit", animal="dog")

Output:

I have a dog named Biscuit.

Now Python ignores the position and matches by name instead. Keyword arguments are especially handy when a function has a lot of parameters and you want to be extra clear about what's what.

Functions + If Statements

Now things start to get really interesting. We can combine parameters with the if/elif/else logic you already know:

def check_temperature(temp):
    if temp > 80:
        print("It's hot! Stay hydrated.")
    elif temp > 60:
        print("It's nice out! Enjoy.")
    else:
        print("Bring a jacket!")

check_temperature(75)
check_temperature(45)
check_temperature(92)

Output:

It's nice out! Enjoy.
Bring a jacket!
It's hot! Stay hydrated.

The function does different things depending on what you pass it. That's the real power here—one function, many behaviors.

Try it! Write a function called check_age that takes one parameter, age. If the age is 18 or over, it prints "You can vote!" Otherwise, it prints "You'll be able to vote in X years." (where X is 18 minus their age). Test it with a few different ages.

Default Parameters

Sometimes you want a parameter to have a "normal" value that gets used most of the time, but you still want the option to override it. That's what default parameters are for:

def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Clarissa")            # uses the default greeting
greet("Clarissa", "Hey")     # overrides the default
greet("Marcus", "Howdy")

Output:

Hello, Clarissa!
Hey, Clarissa!
Howdy, Marcus!

The greeting parameter has a default value of "Hello". If you don't pass a second argument, Python uses the default. If you do pass one, it uses what you gave it instead.

Common Mistake: Parameters with default values must come after parameters without defaults. This is fine: def greet(name, greeting="Hello"). But this will cause an error: def greet(greeting="Hello", name). Python needs the required parameters first.

Try it! Write a function called order_coffee that takes two parameters: size and milk with a default value of "oat". It should print something like "One large coffee with oat milk, coming up!" Test it with and without specifying the milk.

Putting It Together

Let's write a slightly more complete example that uses multiple parameters and an if-statement:

def print_ticket(name, age, movie):
    print(f"--- Movie Ticket ---")
    print(f"Name:  {name}")
    print(f"Movie: {movie}")
    if age < 12:
        print("Price: $8.00 (child)")
    elif age >= 65:
        print("Price: $9.00 (senior)")
    else:
        print("Price: $14.00 (adult)")
    print("--------------------")

print_ticket("Clarissa", 35, "Everything Everywhere All at Once")
print_ticket("Theo", 8, "Moana 2")

Three parameters, some if/elif/else logic, nice formatted output. This is starting to look like real code—because it is. Functions with parameters are one of the core building blocks of every program you'll ever write.
