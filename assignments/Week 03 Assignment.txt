The purpose of this coding assignment is to assess your command of the problem-solving, computational thinking, and programming skills introduced in this unit. The notebook walks you through turtle graphics step by step — moving the turtle, turning, lifting the pen, changing colors, and using for-loops to repeat things — and then asks you to draw a simple picture of your own in the final code cell.

== Requirements ==

Your drawing (the code you write in the final "Coding Week 3 Assignment" cell) must:

  1. Run without errors when the notebook is run top to bottom (Runtime > Run all is a good way to check)
  2. Start with initializeTurtle() and use at least 6 turtle commands from the tutorial (forward, backward, right, left, goto, penup, pendown, color — any mix)
  3. Use at least one for-loop to repeat part of the drawing
  4. Be recognizably intentional — a shape, a scene, a pattern, a doodle with a plan. It doesn't need to be fancy (the heart example at the bottom of the notebook shows how far a few commands can go), but a single stray line or the untouched starter cell won't cut it
  5. Be your own drawing — not a copy of the heart example or the hexagons from the tutorial

== Grading ==

  4 (Exceeds): Notebook runs top to bottom without errors, the drawing uses at least 6 turtle commands and at least one for-loop, and the picture is clearly intentional. Code is readable (sensible spacing, maybe a comment or two saying what each part draws).

  3 (Meets): Drawing runs and meets most of the requirements, but may be missing one element (say, no for-loop) or have minor issues like a stray line or leftover experiment code.

  2 (Progressing): Code shows real turtle work but has errors that stop it from running, or the drawing is too minimal to tell what was intended.

  1 (Beginning): An attempt was made — some turtle commands are there — but the code doesn't run or doesn't produce a drawing.

  0: Not submitted, or the final cell is untouched.
