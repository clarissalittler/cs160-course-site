== What every route needs ==

Whichever notebook you pick, your program should:

  1. Run without errors from top to bottom. (Runtime > Restart session and run all is the real test, because it catches code that only worked thanks to a leftover variable.)
  2. Use at least six meaningful Python instructions from the tutorial.
  3. Use at least one for-loop to repeat a part of the artifact on purpose.
  4. Be a new thing that you made. Leaving the starter cell as-is, or pasting in the tutorial's finished example, doesn't count.
  5. Use readable names, and include enough words, labels, or description that I can tell what you were going for.

The details for each medium are inside the notebooks. In the turtle route, the six instructions are turtle commands and you add a short text description of the drawing or a narrated command log. In the text routes, headings, numbered lines, or spoken labels make the structure clear, and you submit a complete sample output.

== Grading ==

  4 (Exceeds): The notebook runs top to bottom, uses at least six meaningful instructions and a for-loop, and produces something clearly intentional that a reader can understand. Code uses sensible names and is easy to follow.

  3 (Meets): The program runs and meets most of the requirements, but one thing is missing or has a minor issue, like an underdeveloped repeated section or leftover experiment code.

  2 (Progressing): The code shows real work, but errors stop it from running all the way through, the loop is missing, or the result is too minimal to tell what it was meant to be.

  1 (Beginning): An attempt was made, but the code doesn't yet run or produce a complete artifact.

  0: Nothing was submitted, or the final assignment cell is untouched.

If you don't get a 4, read the feedback, revise, and resubmit for full credit. You have unlimited resubmissions. You need at least a 1 on this assignment to unlock the Final Exam.
