Question 2: Debug a Program

Take the following Python program, which has a problem (well, more than one), and ask the LLM to explain what's wrong with it and fix it. This is a program that implements the Sieve of Eratosthenes — a classic algorithm for finding prime numbers. You don't need to already know how the algorithm works; what we want to see is how the LLM handles debugging.

After the LLM gives you a fixed version, test both whether it runs and whether its answers are correct. Then ask the LLM to reorganize the code so it has a main function that asks the user for the limit on the console.

def sieve_of_eratosthenes(limit):
    if limit < 2:
        return []

    # Initialize a list of boolean values. All numbers are initially assumed to be prime.
    is_prime = [True] * (limit + 1)
    is_prime[0:2] = [False, False]  # 0 and 1 are not prime numbers

    # Iterate through the numbers and mark their multiples as non-prime
    for number in range(2, limit**0.5 - 1):
        if is_prime[number]:
            for multiple in range(number*number, number, limit + 1):
                is_prime[multiple] = False

    # Collect all prime numbers
    primes = [number for number, prime in enumerate(is_prime) if prime]

    return primes

# Example usage
limit = 200
primes = sieve_of_eratosthenes(limit)
print(primes)

Check the result: The function should return every prime number up to and including an integer limit. Use the cases below on the repaired function and the console version. Write down both the list you expected and the list you got, because a program can run without errors and still give the wrong answer. You don't need to handle non-integer input for this assignment.

Question 3: Test for Hallucination

In Lesson 5, we talked about hallucination — the tendency of LLMs to generate text that sounds completely plausible but is wrong. That can happen because a language model writes by following patterns it learned, not by looking facts up. Some tools also search the web or double-check their work, which helps, but the answer can still be wrong, or can say a source claims something it doesn't.

For this question, you're going to put that to the test. Ask the LLM to explain a concept from this course — pick any topic from Units 1–9. Binary numbers, say, or how sorting algorithms work, whatever interests you. Then compare its explanation to what you learned in the lessons.

a. What topic did you ask about, and what was your prompt?

b. Was the LLM's explanation accurate? Did it get anything wrong or leave anything important out?

c. Were there any differences between what the LLM said and what the course taught? (It's completely okay if there aren't — just explain what you checked and how you verified it. What matters is how you checked, not whether you caught it in a mistake.)
