Week 4 Rubric — Functions and Decisions

This rubric applies equally to the turtle drawing, quiz/oracle, and branching-radio-play routes. Score each row independently. Half-points are welcome. Add the five scores (20 points possible), then divide by 5 for the 0–4 assignment score.

Criterion 4 — Complete and effective 3 — Mostly demonstrated 2 — Partly demonstrated 1 — Beginning evidence 0 — No evidence
Execution and intentional artifact Runs top to bottom and produces a complete, recognizably new artifact. Runs with a minor interruption or produces a nearly complete artifact. Substantial code runs or the intended result is partly produced despite errors. Some relevant submitted code runs or clearly begins an artifact. Starter is untouched or no relevant work.
Original function Defines an original, coherent function whose body performs meaningful work. Function is useful with one minor design/syntax issue. Function definition is recognizable but incomplete, overly narrow, or partly broken. Attempts a relevant function definition. No original function evidence.
Function reuse Calls the function more than once to perform genuinely repeated work. Multiple calls are present but differ little or one call has an issue. One successful call plus an attempted reuse, or multiple partially working calls. One relevant call is attempted. No call evidence.
Meaningful conditional An if/elif/else decision works and visibly changes what the program does. Conditional works with a minor logic gap or limited effect. Decision structure is recognizable but only partly works or affects a small part. Attempts a relevant condition or branch. No conditional evidence.
Clarity, accessibility, and reflection Readable names/labels make meaning accessible without color/layout alone; representation/sample run and reflection are complete. All are present with one minor gap. Two areas provide useful evidence or all are partially developed. One area provides useful evidence. None are provided.

Partial-credit notes: score functions and conditionals from the code evidence even if a separate error stops the complete run. Parameters and extra branches are optional and cannot be required for full credit.
