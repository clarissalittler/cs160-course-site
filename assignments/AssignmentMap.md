# Weekly Assignments — week by week

One unified class of graded deliverable: a single **Week N Assignment** per unit, weeks 1–10.
(Previously split into two interleaving schemes, "Lab 1–6" and "Assignment 1–4", which was confusing. Collated here so week number = unit number.)

The assignment-specific analytic rubrics are in [`rubrics/`](rubrics/README.md). Each rubric awards partial credit across five independent criteria and converts its 20-point total to the course's 0–4 scale.

## Canonical sources
What students see, and the source of truth in this repo:

- **Weeks 1–2:** the `.html` handout.
- **Weeks 3–4:** the `.txt` D2L wrapper lists three first-class routes. The turtle route uses the linked live Drive notebook; text-first routes use the generated notebooks in `drafts/` through Colab's GitHub opener. The `.qmd` files are editable sources and the `.ipynb` files are generated student notebooks. Sync the live turtle notebook deliberately after source changes.
- **Week 5:** `Week 05 Assignment - Information Tool.txt` plus the generated notebook (in-memory list-of-dictionaries tool, schema, collection operations, and usability revision). The former tuple-database assignment is preserved in `archive/`.
- **Week 6:** `Week 06 Assignment - Persistent Data Tool.txt` plus the generated notebook (CSV persistence, conversion/quality reporting, filter/summary, tests, provenance, and change log). The former data-tracker assignment is preserved in `archive/`.
- **Week 7:** `Week 07 Assignment - Algorithm Efficiency.md` (solutions in `Week 07 Assignment - Solutions.md` — instructor-only, git-ignored, don't post).
- **Week 8:** `Week 08 Assignment - Quantitative Reasoning.md` — students find their own dataset on Data Is Plural. Old QR v2025 PDF superseded, in `archive/`.
- **Week 9:** `Week 09 Assignment - Working with Large Language Models.html` — old ChatGPT-only v2025 PDF superseded, in `archive/`.
- **Week 10:** `Week 10 Assignment - Mini-Zine.md` — old v2025 PDF superseded, in `archive/`.
- **Optional Review:** `Optional Review - Evaluating Code by Hand.html` (solutions `Optional Review - Evaluating Code by Hand - Solutions.md` — instructor-only, git-ignored).
