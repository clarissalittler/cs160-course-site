== Common Requirements ==

Every route must:

  1. Run without errors when the notebook is run from top to bottom
  2. Define at least one original function rather than reuse a tutorial function unchanged
  3. Call that function more than once so it performs genuinely repeated work
  4. Use at least one meaningful if, elif, or else decision that changes what the program draws, says, calculates, or does
  5. Produce a new, recognizably intentional artifact
  6. Include readable words, headings, labels, comments, or a short description so the result's meaning does not depend only on color or spatial layout

The media-specific details and starter patterns are explained inside each notebook. Parameters, extra branches, validation, and additional loops are optional style challenges rather than requirements for only one medium.
