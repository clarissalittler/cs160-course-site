== Common Requirements ==

Every route must:

  1. Run without errors when the notebook is run from top to bottom
  2. Define at least one original function rather than reuse a tutorial function unchanged
  3. Call that function more than once so it performs genuinely repeated work
  4. Use at least one meaningful if, elif, or else decision that changes what the program draws, says, calculates, or does
  5. Produce a new, recognizably intentional artifact
  6. Include readable words, headings, labels, comments, or a short description so the result's meaning does not depend only on color or spatial layout

The media-specific details and starter patterns are explained inside each notebook. Parameters, extra branches, validation, and additional loops are optional style challenges rather than requirements for only one medium.

== Grading ==

  4 (Exceeds): The notebook runs top to bottom, defines and repeatedly calls an original function, uses a meaningful conditional choice, and produces a clearly intentional, understandable artifact. Code uses sensible names and is easy to follow.

  3 (Meets): The program runs and meets most requirements, but one element is missing or has a minor issue—for example, the function is called only once, the condition does not affect the artifact, or leftover test code interrupts the result.

  2 (Progressing): The code shows real work, but errors prevent a complete run, there is no original reusable function or meaningful decision, or the result is too minimal to communicate an intention.

  1 (Beginning): An attempt was made, but the code does not yet run or produce a complete artifact.

  0: Nothing was submitted, or the final assignment cell is untouched.

If you do not receive a score of 4 (Exceeds), read the feedback, revise, and resubmit for full credit. You have unlimited resubmission attempts.
