Question 1: Trinary Computing

Eureka! We've invented an entirely new kind of computer! This one is built on trinary logic instead of binary so each trinary-bit, or trit, can actually count the numbers 0, 1, 2 instead of just 0 and 1. We can now write numbers as a sequence of trits.

For example we can convert the number 37 to 1101 in trits (1×27 + 1×9 + 0×3 + 1×1)
or the number 24 to 220 in trits (2×9 + 2×3 + 0×1)

Now answer the following questions to help a newcomer to trit-computing get acquainted with how they work.

a. What is the trinary number 21201 in decimal?

b. What is the decimal number 380 in trinary?

c. How many individual things can you count with a 5-trit number?

d. What's the largest number you can represent with 5-trits? (Hint: it's the number 22222)

Hint for Questions 2 & 3: These questions ask you to figure out how many bits you need to represent a certain number of things. You don't need to know logarithms to do this — you just need one key idea:

With n bits, you can represent 2n different things.

So the trick is: figure out how many total things you need to represent, then find the smallest n where 2n is big enough. Just try powers of 2 until you get there:

Worked example: Suppose you need to represent 203 different characters. You need the smallest n where 2n ≥ 203. Try n = 7: 27 = 128 — not enough. Try n = 8: 28 = 256 — that works! So you'd need 8 bits, and the maximum number of characters you could define with 8 bits is 256.

Question 2: ASCII + Western European Characters

The original ASCII character set required only 7 bits to represent a North American keyboard's characters, numbers, and symbols. Assuming all 128 patterns of 7 bits are already defined:

a. How many bits (in total) would be needed to represent those 128 patterns plus approximately 75 Western European characters?

b. What is the maximum number of unique characters that could be represented in that many bits?

You must answer both questions correctly to receive full credit.

Question 3: Full Unicode Character Set

Suppose we wanted to represent the original 128 ASCII characters plus 128 extended characters, plus approximately 17,000 characters in Arabic, Armenian, Bengali, Bopomofo, Cyrillic, Devanagari, Georgian, Greek and Coptic, Gujarati, Gurmukhi, Hangul, Hebrew, Hiragana, Kannada, Katakana, Lao, Latin, Malayalam, Oriya, Tamil, Telugu, Thai, and Tibetan, plus approximately 52,000 CJK (Chinese, Japanese, Korean) ideographs.

a. What is the minimum number of bits needed to represent these characters?

b. What is the maximum number of unique characters that could be defined using that number of bits?

You must answer both questions correctly to receive full credit.
