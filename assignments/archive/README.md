# Archived assignments

This folder preserves assignments superseded by course revisions. They remain available for instructor reference and possible reuse but are not the active student-facing Week 5–6 assignments.

- `Week 05 Assignment - Tuple Database.txt` used a list of tuples as the required core representation. The replacement information-tool assignment uses named dictionary records and treats tuples as optional.
- `Week 06 Assignment - Data Tracker.txt` was the earlier CSV tracker. Its load/save core is preserved and expanded in the persistent-data-tool assignment with provenance, quality reporting, tests, separated responsibilities, and change history.

The archived PDF assignments are earlier versions from the previous assessment scheme.
